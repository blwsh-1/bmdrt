## 0. 一句话结论

v6 的三条路径在**代码/数据层面确实彼此独立**（`sigma_floor` 只依赖 `zmax=f(Z)`，
`include_L` 只依赖 `detect_L(f,Z)`，`deinduce_for_drt` 只喂 DRT 预判），
但在**后验几何层面间接耦合**：`include_L` 改变 `Zt.imag` → 改变虚部残差 →
改变 `σ_im` 后验与地板是否贴住。因此审查意见「先冻结电感、只动噪声模型」的顺序是对的。
F0–F3 的结果见 §2，六项解锁条件判定见 §3。

**本轮定案**：F0–F3 的 8 组（quick）**没有任何一组通过六项解锁条件**；已有正式档
（3000/1000/3 链）的 F3 两组也只到 `CONDITIONAL`。因此**第 5 步 `include_L` 消融不启动**。
`sigma_floor=1e-4` 只能定位为「无噪/近无噪 ECM 谱的数值正则化候选值」——
它把树深触顶压到 0%，但有效噪声标准差有 85–90% 由人为地板给出，
并不是被数据约束出来的测量噪声；`config.json` 继续默认 `0.0`。

## 1. 只读审计（不改模型）

### 1.1 噪声参数化：与审查意见逐字一致

`bm_core.make_model(..., sigma_floor: float = 0.0)`（`bm_core.py:195–318`）：

| 项 | v6 实际实现 | 审查意见的引述 | 核对 |
|---|---|---|---|
| 默认 | `sigma_floor=0.0`，走原来的 `s_re/s_im ~ LogNormal(log(0.01·zmax), 1)` | 「F0 原始基准」 | ✅ 逐位等价，未改 |
| 地板尺度 | `floor = sigma_floor * zmax` | `σ_floor / Z_max` | ✅ |
| 基量先验 | `LogNormal(log(0.01·zmax), 1.0)` | `LogNormal(ln(0.01 Z_max), 1)` | ✅ **未更换先验分布** |
| 有效 σ | `s_re = deterministic(b_re + floor)`，`s_im` 同理 | `σ_eff = σ_floor + σ_base` | ✅ shifted LogNormal |
| 似然 | `Normal(Zt.real, s_re)` + `Normal(Zt.imag, s_im)` | 绝对噪声口径 | ✅ 实/虚两路独立 |
| 落盘 | `save_out` 把 `res["s"]` 全部数组写进 `real_*_samples.npz` | — | ✅ 因此 `b_re/b_im` 可读 |

**一个有用的既有设施**：`s_re`/`s_im` 是 `deterministic`，样本文件里同时保留
`s_re_base`/`s_im_base`。所以「σ 后验是否堆积在人为下限」**不需要重跑、也不需要改模型代码**，
直接读 `.npz` 即可 —— 这正是审查意见解锁条件第 5 项要的量。本轮就据此实现。

`zmax = jnp.max(sqrt(Zr² + Zi²))`，**只由数据决定**，与 `include_L`、DRT 通道、`K` 都无关。

### 1.2 `detect_L / include_L` 的完整传递路径

```
config.json  fit.include_L = null
   │
   ├─ bmdrt.process_one / test_ecm._run_forced  →  bm_real.run(include_L=None)
   │
   └─ bm_real.run:1585  if include_L is None:  include_L = detect_L(f, Z)
                        detect_L: bm_real.py:205
                          hi = np.argsort(f)[-3:]
                          return mean(Z.imag[hi] > 0) >= 0.5
   │
   ├─(a) _kk_check(f, Z, include_L=...)      → Lin-KK 门禁
   │        · include_L is False 时不估 L_est（bm_kk.py:498）
   │        · 影响 KK 的归因文案 / 高频残差归因分支
   │
   ├─(b) fit_one → B.fit(include_L=...) → make_model
   │        · include_L=True 时采 L ~ LogNormal(log(1e-6), 2.0)
   │        · Zt = R_inf + Σ Z_HN + jωL                ← 唯一的模型结构变化
   │
   └─(c) 全部后处理：model_z / loglik_matrix / z_band / PPC /
          param_corr / sample_params / save_out
```

`detect_L` **只读数据、不改写数据**；它改变的是「似然里有没有 `jωL` 这一项」。
在 797 / 1139 上实际判定都是 `include_L=False`，且已核验**跨全部地板档一致**
（`real_*.json` 的 `include_L` 字段），满足「每组实验固定 `include_L`」。

### 1.3 DRT 去电感通道独立，未扩展

```
kk['L_est']（bm_kk.estimate_L，是 KK 的稳健估计，**不是** BM-DRT 的 L 参数）
```

`drt` 配置段、`prescreen_stage`。

### 1.4 三条路径的耦合判定

| 交叉 | 代码 / 数据层 | 后验几何层 | 说明 |
|---|---|---|---|
| `include_L` ↔ `sigma_floor` | **无连接** | **有（间接）** | `floor` 只依赖 `zmax=f(Z)`；但 `jωL` 改变 `Zt.imag` → 改变虚部残差 → 改变 `σ_im` 最优值与地板是否贴住。上一轮 797 的对照实测：`include_L` False→True 使 `σ_im/zmax` 从 `8.12e-3` 掉到 `4.22e-8`。 |
| `include_L` ↔ `deinduce` | **弱，且被自愈** | 无（DRT 不进似然） | `kk_check(include_L=False)` 时不估 `L_est`；但 `deinduce_for_drt(L_est=None)` 会自己再调 `_kk_estimate_L`（`bm_real.py:273`），估计值不变，所以 DRT 通道实际不受影响。 |
| `deinduce` ↔ `sigma_floor` | **无连接** | 间接但**跨档恒定** | DRT 预判通过 `init_values(pk, pres, K)` 影响 NUTS 播种起点；但该起点只依赖数据，不依赖 `sigma_floor`，所以四档用的是同一个初值，不构成混淆。 |
| `sigma_floor` ↔ K 选择 | 无 | 潜在有 | 本轮**固定 K = 真值 K**，按审查意见「第一轮不要同时进行 K 扫描」，把这个混淆源关掉。 |

**结论**：数值上三条可独立控制；但 `include_L` 与噪声模型的耦合只体现在后验几何上，
正好就是审查意见担心的「残差变小了，但后验更难采样」。所以冻结电感的顺序是对的。

### 1.6 独立诊断：`detect_L` 是否有明显错误（只读，不改模型）

审查意见明确允许「只读审计和独立诊断」。上一轮已在全数据集上量化过，结论复述：

- 7462 条谱中 **2672 条（35.8%）真值含 `L`**；`detect_L` 投 `False`（漏检）**1786 条 = 66.8%**。
- 漏检原因不是随机噪声：`f0` 较高的快 CPE 会把高频 `Im Z` 压成负值，
  而 `detect_L` 只看「最高 3 点虚部是否为正」。797 即典型（真值 `L=0.118 µH`，
  1 MHz 处 `ωL` 占 `|Z|` 的 29%，仍判 `False`）。
- 试过替代判据「高频 `Im Z` 随 f 上升」→ **不可用**：65% 的**不含 L** 谱误报
  （任何 `CPE(n<1)` 的虚部也往 0 靠，同样「上升」），误报比漏检更糟。

**本轮不据此改任何代码。** 它只是说明：第二轮消融必须分「真值无 L / 明显 L / 弱 L」
三类，否则 `detect_L` 的误判与 `L ↔ 快分量` 简并会混在一起 —— 与审查意见 §三一致。

**三个关键发现：**

1. **797 上地板只压住了实部通道，虚部通道根本没被地板约束。**

   想把 `σ_im` 定在真实的结构残差上，而不是地板上。这正是 §1.4 说的
   「`include_L` ↔ 噪声模型在后验几何层间接耦合」的直接读数：缺 `jωL` 留下高频虚部

2. **严格的 `σ ≤ 1.1×floor` 阈值会漏判。** 797 的 F1–F3 被判 `PASS（未贴地板）`，

   本轮**没有事后改判定门槛**（避免看到结果再改标准），只加了这一列诊断量，
   并把分歧显式写进报告；阈值修订留到第 4 步之前预先登记，见 §3.5。
3. **1139 对地板的响应非单调，且中间档出现近乎完全的参数简并。**
   触顶 `27.9% → 51.2% → 25.1% → 0%`，bulk ESS `156 → 37 → 78 → 588`，
   F1/F2 还冒出 6 对 `|ρ|≈1.00` 的强相关
   （`ln R_inf / ln w_1 / φ_1 / ln τ_1` 四者几乎共线），到 F3 又全部消失。
   说明小地板不足以把后验从简并脊上推下来，反而多了一个截断边界；
   **不能在 F1 与 F2 之间插值找「最优地板」**，也不能把 F1 的变差归因于随机性以外的东西
   而不做正式档复验 —— 这正是 `w6JByu`（正式档 F1/F2）要回答的问题。

### 2.4 参数 / 分量稳定性

- 两谱四档的 `f0` / `w` / `φ` 逐位一致（Δlog10 f0 = 0，Δw/w = 0%，Δφ = 0），`K` 不变。
- `R_inf`：797 `0.05085 → 0.05097`（+0.24%），1139 `727.7 → 729.1`（+0.19%），相对真值仍准。
  但正式档 `1e-3` 会把 797 推到 `0.06323`（**+24.6%**）、1139 到 `802.4`（+10.2%），
  所以 `1e-4` 是「不推偏参数」的上界，不只是「压住触顶」的下界。
- σ 先验位置从 F0 的 `−12.1σ/−12.8σ` 移到 F3 的 `−4.4σ/−4.5σ`：后验仍被推到
  原 LogNormal 先验的极左尾，说明**先验本身与近无噪数据不匹配**，地板只是截断症状。
- 797 的 PPC `0.938 → 0.917`；1139 的 `rms/σ` 从 0.45 掉到 0.01，是因为分母 σ
  被抬高，**不是拟合变好**，不要当成收益。

797 的三对强相关（`ln R_inf ~ ln w_1` ρ=−0.99、`ln τ_2 ~ ln w_2` ρ=+0.95、
`ln R_inf ~ ln τ_1` ρ=+0.91）**在 F0 就存在**，跨四档稳定，正式档 F3 仍存在 ——
属于 HN 参数化与 `R_inf` 之间的结构性权衡，**不是地板引入的**；F1 临时多出的
`ln w_2 ~ φ_2`（ρ=−0.90）才是地板附近新增的。这一点对解锁条件第 6 项很重要：
地板解决不了它，而本轮又冻结了模型结构。

## 3. 六项解锁条件判定

### 3.1 判定口径（写死在 `sweep_sigma_floor.py`，本轮未改）

| 检查项 | 门槛 | 判定 |
|---|---|---|
| ① R̂ | ≤ 1.01 | 超了 = FAIL |
| ② Bulk / Tail ESS | 均 ≥ 400 | 任一不足 = FAIL |
| ③ Divergences | 0 | 非 0 = FAIL |
| ④ Tree-depth saturation | < 1% | ≥1% = FAIL |
| ⑤ 噪声后验 | 不堆积在人为下限 | `stack_max ≥ 0.10` = COND；`< 0.10` = PASS；F0 = N/A |
| ⑥ 参数相关性 | 无严重且无法解释的简并 | 有 `|ρ|>0.9` = COND（需人工解释） |

`PASS` = 达标；`COND` = 有条件（贴地板但已明确声明为数值正则化，或强相关需人工解释）；
`NOT YET` = 至少一项 FAIL，**不允许进入第二轮 `include_L` 消融**；
`CONDITIONAL` = 无 FAIL 但有 COND。

### 3.4 相关性第 6 项的人工解释

797 的三对简并在 F0（无地板）就存在、跨四档稳定、正式档仍在，且物理上可解释：
`R_inf` 与权重 `w_1` 的此消彼长、慢分量 `τ_2 ↔ w_2` 的幅度—时间常数权衡、
`R_inf ↔ τ_1` 的直流—弧起点耦合。它们**不是地板引入的**，但也确实严重（ρ≈−0.99），
且本轮冻结了 HN 参数化与 `R_inf` 先验，所以只能记为 `COND`，不能记为 `PASS`。
1139 F1/F2 的 6 对 `|ρ|≈1.00` 则是小地板下的完全简并，F3 消失 —— 属另一类现象，
必须用正式档 F1/F2 复验，不能只凭 quick 档定性。

### 3.5 指标缺陷：⑤ 的阈值需要在第 4 步之前预先登记

`stack = mean(base ≤ 0.1×floor)` 是「硬贴地板」判据，很严：只要后验中位数
`base/floor ≈ 0.17` 就会判 `未贴地板`，尽管此时有效 σ 里 85% 是人为地板。
本轮**没有看到结果后回头改门槛**（那会让判定失去意义），而是：

- 在报告里新增只读诊断列 `floor 占 σ_eff = median(floor/(floor+base))`；
- 在报告说明里写明「>50% 应保守声明为数值正则化」；
- **保持 `_unlock()` 的硬判定不变**，把分歧原样暴露出来。

建议在第 4 步正式档回归**之前**把 ⑤ 预先改为双条件，例如
`stack_max < 0.10` **且** `share_max < 0.50` 才判 PASS，
并把「COND 必须显式声明为数值正则化」写进报告。改完后再用 `--regen`
重出报告，不需要重跑采样。**本轮先不改，等审查意见确认口径。**

### 3.6 结论

> **第 3 步判定：未解锁。** 不启动第 5 步 `include_L` 配对消融。

- `sigma_floor=1e-4` 在 797 / 1139 上能把触顶压到 0%、不推偏参数，
  是目前唯一同时满足「触顶」与「参数稳定」的候选值；但它**只适用于无噪 / 近无噪谱**，
  且本质是数值正则化，不是测量噪声估计。
- `config.json` 保持 `fit.sigma_floor = 0.0`；不设全局默认值，不推广到真实 EIS 数据。
- 0.5% 噪声数据上 `1e-4` 基本 inactive，反而暴露出 R̂≈1.84 / bulk ESS≈3 的
  另一类采样问题；这**不能**用「地板太小」解释，也不能靠加大地板解决。
- 按审查意见「噪声地板把树深触顶率降到零，不等于后验已经健康」，本轮实测完全支持这句判断。
