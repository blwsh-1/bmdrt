## 0. 一句话结论

第一份意见的核心指控**成立**：Lin-KK 确实已经前移，但「电感识别」和「电感扣除」不是一回事——`estimate_L()` 只估算，`prescreen_stage()` 仍在用原始 Z。已实现独立数据通道。

本轮补完 σ 地板扫描后又多出两条结论，都写进 §3.4–§3.6：

- `1e-4` 是两条测试谱上都能把树深触顶压到 0% 的**最小**档；`1e-3` 压不出更多，只把 `R_inf` 推偏 10–25%；`1e-5` 在 1139 上**比 1e-6 更糟**。地板不单调，`R̂` 也完全不能用来选它。

## 2. 已实施：DRT 去电感数据通道

### 2.1 设计

```
Z_DRT = Z_raw − jωL_est   →  只喂 drt.prescreen()（K 候选 + 初值）
Z_raw                     →  喂 BM-DRT 的似然（不改）
```

这条边界是硬的：预处理可以为 DRT 提供更合适的输入，但不能改变 BM-DRT 的原始数据似然。否则后验不再是「给定观测」的后验。

### 2.2 四道检查（不能无条件扣）

按意见要求加了可信度判断，实现在 `bm_real.deinduce_for_drt()`：

| 检查 | 条件 | 不过时 |
|---|---|---|
| 有感抗点 | 最高 5 点里 ≥3 个 `Im Z > 0` | 用原始 Z |
| 稳定性 | `ImZ/ω` 的 `(p90−p10)/median ≤ 35%` | 保留原始 Z，标记电感干扰 |
| 占比 | `ω_max·L / \|Z(f_max)\| ≥ 0.5%` | 扣了白扣，跳过 |
| 不过扣 | 扣完**最高 3 点** `Im Z ≥ −2%·\|Z\|` | L 估大，保留原始 Z |
| 有收益 | DRT 高频段相对残差至少降 20% | 保留原始 Z |

第 5 条对应意见里的「比较扣除前后的高频残差」。判据用的是 **DRT 自己的残差**，不是另造一个平滑基准——DRT 就是下游消费者，「扣 L 有没有用」该由它的拟合能力回答。

### 2.3 实测效果

真实 2E 谱（f = 1–1e5 Hz）：

| 谱 | L_est | `ImZ/ω` 离散度 | f_max 处占比 | DRT 高频残差 |
|---|---|---|---|---|
| 2EMC1-1_0005mA | 6.06e-8 H | 7% | 87.3% | 48.54% → **14.65%**（降 70%） |
| 2EMC1-2_0005mA | 4.32e-8 H | 1% | 96.9% | 63.90% → **12.54%**（降 80%） |
| ecm_00797（合成） | — | — | — | **不扣**：最高 5 点 Im Z 全为负，无感抗尾 |
| 2EMC1-1_0750mA | — | — | — | KK 门禁先判 `fail`，未进入此环节 |

注意最后一条：0750mA 的 Lin-KK 中段残差 10.7%、ac1 实/虚 0.75/0.92 判系统性 → `gate` 模式直接拒绝定 K。去电感通道**不会**绕过门禁。

### 2.4 实施中修正的一处判据方向错误

初稿的过扣检查用「top-5 点的最小 `ImZ/|Z|`」，在 2EMC1-1_0005mA 上给出 −4.78% 并误判「L 估大」。

**这是方向性错误**：`ImZ/ω` 在**高频段下沿**本来就会偏低（容性/弛豫贡献还没衰减完），那里扣完必然剩负值，那是物理不是过扣。过扣只可能出现在**最高频**——那里 ωL 占优，L 估大了才会把 `Im Z` 压穿。

改成 top-3 后：0.00 / +1.13 / +1.49 %，正常通过。

## 3. 已实施：σ 噪声地板（可配置，默认关闭）

### 3.1 为什么不设成默认

按第二份意见，**不把 `1e-4` 当默认值**。理由被数据支持：

- 它是人为下界，不是从数据估出来的测量噪声；
- 真实噪声低于它时后验会被人为截断；
- 加噪后 797 的 `R_inf` 从 +0.1% 恶化到 **+299%**，1139 从 −0.04% 到 **+50%**——噪声模型一动，部分参数明显变化。

所以做成 `fit.sigma_floor`（默认 `0.0`，**行为与改动前逐位一致**）+ `--sigma-floor`。

```python
if sigma_floor > 0:
    floor = sigma_floor * zmax
    b_re = numpyro.sample("s_re_base", dist.LogNormal(jnp.log(0.01 * zmax), 1.0))
    b_im = numpyro.sample("s_im_base", dist.LogNormal(jnp.log(0.01 * zmax), 1.0))
    s_re = numpyro.deterministic("s_re", b_re + floor)   # 落盘的是**有效** σ
    s_im = numpyro.deterministic("s_im", b_im + floor)
```

`s_re` 用 `deterministic` 落盘，保证报告里的 σ 就是似然里真正用的那个，不是基量。

1. **`1e-4` 是「刚好压住漏斗」的最小档**；`1e-3` 多压不出任何东西，只把 `R_inf` 推偏 10–25%。

同时要承认代价：1139 在 `1e-4` 下 `rms/σ=0.01`，噪声模型变成**过度离散**（σ≈35 Ω 而实际残差 0.35 Ω）。参数仍然准（`R_inf` +0.15%），但「σ 有物理意义」这件事已经不成立了。所以 `1e-4` 只能当**数值正则化**用，不能当噪声估计报出去。

### 3.5 扫描中发现的另一件事：漏斗有两个独立来源

原本把 σ 塌陷都归给「无噪数据 + 似然无下界」。1139 证实这一半是对的（它不含结构问题，`L` 项只占 `|Z|` 的 0.0005%，照样在 1e-6 档 `div=180`、`R̂=1.499`）。但 797 的形态不同，是**模型缺项**造成的：

| | 797 | 1139 |
|---|---|---|
| `rms_re` | **9.3e-08**（机器精度） | 2.03e-02 |
| `rms_im` | **2.56e-02** | 3.05e-01 |
| `σ_re/zmax` | 1.30e-06 | 9.20e-06 |
| `σ_im/zmax` | **7.72e-03** | 5.86e-06 |

797 的 `σ_re` 与 `σ_im` 差 **6000 倍**，而 1139 两者同量级。差别在 `include_L`：797 真值含 `L=1.18e-7 H`（1 MHz 处 `f·L ≈ 0.118 Ω`，占该点 `|Z|` 的 29%），但 `detect_L()` 投了 `False`——它只看最高 3 点的 `Im Z > 0`，而 797 的高频 `Im` 被 `f0≈2.3e5 Hz` 的快 CPE 压成负值（`Im(1 MHz) = −0.32`）。

`jωL` 只进虚部 → 缺了它，**实部仍可精确表示**（`rms_re` 到机器精度）、**虚部留下结构残差**（`rms_im=0.026`）→ `σ_re→0`、`σ_im` 去吸收结构误差。这不是噪声模型的问题，是模型结构的问题，地板只是把症状盖住。

用真值正演可确认数据里确实有 `L`：`ω=f` 口径下含 `L` 的相对残差 2.4e-3，不含 `L` 是 5.1e-2（高频端 29.5%）。

#### `detect_L()` 在数据集上的漏检率

| 项 | 数量 |
|---|---|
| 可解析谱 | 7462 |
| 真值含 `L` | 2672（35.8%） |
| 其中高频出现过 `Im Z>0` | 952（35.6%） |
| **`detect_L` 投 `False`（漏检）** | **1786（66.8%）** |
| 漏检且 `f_max·L/\|Z\|` > 1% | 414 |
| 漏检且 > 5% | 175 |
| 漏检且 > 20% | 75 |

顺手试过一个「更聪明」的替代判据——看高频 `Im Z` 是否随 `f` 上升（感性特征）。**结果不能用**：它在 65% 的**不含 L** 的谱上误报，因为任何 `CPE(n<1)` 的虚部也在往 0 靠，同样"上升"。漏检率虽从 66.8% 降到 21.7%，但误报 3116 条，比漏检更糟。

所以正确路径不是再找一个启发式符号判据，而是**似然比较**：`include_L=False/True` 各拟合一次比 `elpd`，或先拟合再对高频 `Im` 残差回归 `ω` 看 `L` 是否显著。

### 3.6 但把 `include_L` 打开以后，事情反而变坏了

按上面的思路做了对照（`test_include_L.py`，797，K=2，quick 档，只改 `include_L` 与地板两个旋钮）：

| `include_L` | 地板 | σ_re/zmax | σ_im/zmax | `rms_re` | `rms_im` | 触顶 | R̂max | tail ESS | 分级 |
|---|---|---|---|---|---|---|---|---|---|
| False | 0 | 5.69e-08 | **8.12e-03** | 4.11e-09 | **2.56e-02** | 53.4% | 1.028 | 362 | 0 |
| False | 1e-4 | 1.17e-04 | 7.51e-03 | 1.58e-05 | 2.55e-02 | **0%** | 1.009 | 246 | 1 |
| True | 0 | 8.37e-08 | **4.22e-08** | 7.50e-09 | **3.47e-09** | 45.6% | **1.449** | 65 | 0 |
| True | 1e-4 | 1.17e-04 | 1.16e-04 | 5.50e-06 | 4.40e-06 | 0% | **1.841** | 75 | 0 |

三件事同时被证实：

1. **σ 不对称确实 100% 来自缺 `L`**：`σ_im` 从 8.12e-03 掉到 **4.22e-08**（5 个量级），`rms_im` 从 2.56e-2 掉到 **3.47e-9**。实部几乎不动（4.11e-09 → 7.50e-09）。这条闭环了。
2. **但漏斗不是缺 `L` 造成的**：触顶 53.4% → 45.6%，几乎没动。补上 `L` 之后两条 σ 一起塌到 1e-8，漏斗照旧。所以地板要解决的问题与 `include_L` 无关。
3. **补上 `L` 让采样变得更差**：R̂max 1.028 → **1.449**（floor=0）、1.009 → **1.841**（floor=1e-4）。

第 3 条值得单独看。`L=True, floor=1e-4` 的逐参数诊断：

| 参数 | R̂ | bulk ESS | tail ESS |
|---|---|---|---|
| `R_inf` | 1.013 | 275 | 349 |
| `L` | 1.012 | 304 | 387 |
| `W` | 1.004 | 467 | 585 |
| `v` | **1.837** | **3** | 194 |
| `ln_tau` | **1.841** | **3** | 76 |
| `phi` | **1.838** | **3** | 75 |

`L` 和 `R_inf` 自己收敛得很好（R̂≈1.01），崩掉的是**第二个分量**的 `v`/`ln_tau`/`phi`——bulk ESS 只有 3。

原因是新引入了一个真实的**近简并**：快分量 `f0=232 kHz`，窗顶 `f_max=1 MHz`，只高出 0.63 decade，弧还没展开；在这段里「`jωL`」和「一个更快的 RCPE」几乎是同一个函数形状。加上 `L` 之后，模型有了两条路去解释同一段高频虚部，第二个分量的后验直接塌了。

所以结论要改：

> **不要单独去修 `detect_L`。** 在这条谱上，`detect_L` 投 `False` 反而起了保护作用——它避开了 `L ↔ 快分量` 的简并。正确的顺序是先解决噪声模型（地板或更好的 σ 先验），把漏斗消掉、让后验几何健康，**再**回头做 `include_L` 的似然比较；顺序反了就是拿一个残差问题换一个收敛问题。

顺带一个单位陷阱：`L_uH` 落盘的是模型口径（`ω=2πf`）下的值，`0.0188 µH`；数据集正演用的是 `ω=f`，对应 `0.118 µH`。两者差 `2π`。真实测量数据不存在这个问题，但拿 ECM 数据核对时别直接比。

**本轮不改 `detect_L`，也不改 `include_L` 的默认策略。** 这三点（`detect_L` 判据、`include_L` 决策、地板定值）互相耦合，必须一起做，并且要重新标定阈值。

## 5. 已实施：多分量扩散弱识别 —— 并**修正了上一份报告的一条结论**

### 5.1 上一份报告写错了

原报告 §5.3 说「`hn_warburg_signature` 在 4382 上漏判」。复核后**不成立**。

补算合成阻抗的 Nyquist 斜率（半无限 Warburg 应为 `d(−Im Z)/d(Re Z) = +1`）：

| 对象 | 45° 连续段 | Nyquist 斜率 |
|---|---|---|
| 4382 **实测数据** | 0.00 decade | **+0.404** |
| 4382 拟合模型 | 0.00 decade | **+0.381** |

数据本身在 1–2e5 Hz 内就不是 45°——`Rs_Ws` 的 `Ws` 是**有限长** Warburg，45° 段在窗口之外，窗内已经走平。模型把 +0.404 复现成 +0.381，复现得很准。所以逐分量判 `no` 是**正确的**。

### 5.2 但判据确实有一条路径没覆盖

`looks_like_warburg()` 的前提是「Warburg 表现为单个分量的 R–τ 退化脊线」。K≥2 时模型可以改用「多个 φ≈0.5 的分量拼 45° 段」，这条路径它看不到——不是 4382 的问题，是判据的覆盖问题。

按第二份意见补了两个函数（`bm_diff.py`）：

- `warburg_band_slope(f, Zs)`：查合成阻抗的 Nyquist 45° 直线，返回最长连续段长 / 频段 / 斜率；
- `warburg_multicomponent(sig, band)`：≥2 个分量 `φζ∈0.5±0.04` 且峰位在窗内，**且**有 ≥0.5 decade 的 45° 段，才给 `weak`。**永远不给 `strong`**，也不改 K 选择。

### 5.3 实施中修正的两个 bug

1. **`resid` 被重复归一化。** `drt()` 返回的 `resid` 已是相对量（`(Z_fit−Z)/|Z|`），初稿又除了一次 `|Z|`，在 `|Z|≈0.03 Ω` 的 2E 谱上把残差放大成 1917%。修正后 48.54% → 14.65% 才是真值。
2. **`np.log` 与 `np.log10` 混用。** 初稿用 `np.log(|Z|)` 配 `np.log10(f)`，斜率被乘了 `ln10`（−0.5 变成 −1.13），判据完全失效。

### 5.4 判别力实测

| 情形 | 45° 段 | Nyquist 斜率 |
|---|---|---|
| 纯半无限 Warburg | 5.00 dec | +1.000 |
| Warburg + 大 `R_inf=500` | 5.00 dec | +1.000 |
| 单个 `R‖CPE(n=0.5)`，峰在带内 | 1.27 dec | +0.929 |
| 单个 `R‖CPE(n=0.5)`，峰在带下 | 0.00 dec | — |
| 单个 `R‖CPE(n=0.8)` | 0.08 dec | +0.995 |
| 4 个 `R‖CPE(φ=0.5)` 离散化 Warburg | 0.51 dec | +0.884 |
| 6 个 `R‖CPE(φ=0.5)` 离散化 Warburg | 0.68 dec | +0.888 |

两点必须记住：

- **`R_inf` 不影响判据**（第 1、2 行都是 5.00 dec）——这正是用 Nyquist 而不是 `d log|Z|/d log f` 的原因。
- **有限个分量拼不出长段干净 45°**：K=6 也只有 0.68 decade。所以阈值取 0.5 而不是 1.0，否则这条判据永远不触发。
- 单个 `R‖CPE(n=0.5)` 也能给出 1.27 dec，**所以「≥2 个分量」这道前置条件不能省**。

## 8. 追加实施（第一份意见的两条遗留）

### 8.1 扩散尾判据改为双条件，并改名为 `diffusion_tail_candidate()`

原实现只凭 `log|Z| ~ log f` 斜率落在 `[-0.85, -0.20]` 就输出 `f_cut`，归因文案直接写「低频 −45° 扩散尾」。这确实是过度断言——**那个斜率既不充分也不必要**。

**先说清楚一件事：相位判据单独也不够。** 我原本打算用「Nyquist 45°」直接当签名，实测立刻被推翻：

| 谱 | `\|Z\|` 斜率 | Nyquist 斜率 | Re 跨度/`\|Z\|` | 45° 稳定度 | 判定 |
|---|---|---|---|---|---|
| `caseE`（**无**扩散元件） | −0.03 | **+1.02** | 10.1% | 0.75 | 不判（幅度挡掉） |
| `caseE_warburg`（真值含 `Ws`） | −0.02 | +0.80 | 3.0% | 0.25 | 不判（保守漏报） |
| `caseF`（含 L） | +0.00 | 无定义 | 0.5% | — | 不判 |
| `caseF_wo`（`Wo`） | −0.54 | **+21.37** | 1.7% | 0.00 | 不判 |
| `caseG_wo_only`（`Wo`+噪声） | −0.81 | **−29.88** | 1.5% | 0.00 | 不判 |
| 合成 `2(jω)^(−1/2)` | −0.50 | +1.00 | 61.0% | 1.00 | **候选** |
| 合成 `10+2(jω)^(−1/2)` | −0.11 | +1.00 | 29.3% | 1.00 | 不判（`R_inf` 压平） |
| 阻塞 `R+1/(jωC)` | −1.00 | 无定义 | 0.0% | — | 不判 |

三处修正：

1. **`caseE` 是关键反例**：一条还没闭合的弧，下降段必然经过 45°，跨度占 `|Z|` 的 10%、逐点稳定度 1.00。只看相位就会判成扩散尾。
2. **比值法在 `Re` 饱和时失效**：`caseF_wo` / `caseG` 的 `d(−Im)/d(Re)` 炸成 +21 / −30，符号还随 `frac` 翻转（`caseF_wo` 在 `frac=0.10` 时是 −25.7，`0.25` 时是 +17.9）。改成**对 `Re` 做最小二乘**求斜率，并加 `Re` 跨度下限（1%·`|Z|`）——`Re` 不动时返回 `None`（斜率无定义），而不是「斜率 = 0」。阻塞电极现在正确报「无定义」。
3. **`R_inf` 淹没的短尾与未闭合弧，在最低 25% 段形态相同**：`10+2(jω)^(−1/2)` 是 Ny +1.00 / `|Z|` −0.11，`caseE` 是 Ny +1.02 / `|Z|` −0.03。本地判据**无法**区分，区别只在「45° 能持续多宽」。所以这一层只输出 `amp_ok` / `phase_ok` 两个量，持续性交给 `bm_diff.warburg_band_slope()` 的频段判据，不在 KK 门禁里硬判。

接口变化：

- 新函数 `nyquist_slope_low()` 返回 `(slope, re_span_rel, stability)`。
- `diffusion_tail_cut()` → `diffusion_tail_candidate()`，返回 dict（`f_cut` / `slope_z` / `slope_ny` / `ny_span` / `ny_stability` / `amp_ok` / `phase_ok` / `is_candidate` / `why`）。`is_candidate` 明确标注**必要不充分**。
- 旧名保留为弃用包装，回传 `(f_cut, slope_z)`，语义不变。
- 归因文案不再把「加串联电容后低频变好」说成扩散尾：`add_cap` 能吸收多种端部效应（`caseF_wo` 低频 23.4% → 1.3%），它只说明「端部有东西」，不说明「是扩散」。

**验收：5 个样例谱的 KK 分级完全没变**（`ok/ok/ok/ok/warn`），纯 Warburg 合成谱给出候选，阻塞电极报「斜率无定义」。改判据不动分级，说明它只影响措辞与后续路由。

### 8.2 `_residual_structure()` 去掉等间距假设

`ac1 = corrcoef(x[:-1], x[1:])` 隐含「相邻频点等间距」。改为先按 `log f` 间距筛选：只保留间距在 `[0.5, 2]` 倍中位数内的相邻对，并输出 `n_pairs` / `spacing_uniform`；可用对少于 3 时退回旧行为（避免稀疏网格被判成「非等间距」而失效）。

复核：6 个样例谱（干净 / 鼓包 0.10R·0.20R·0.40R / 漂移 0.25R / 加噪 Wo-only）的 KK 标定**逐条不变**——它们都是对数等间距，筛选是 no-op；`fail` 路径仍正常触发。

### 9.2 三个新发现

1. **地板只截断实部漏斗，没管到虚部结构残差。** 797 四档 `σ_im/zmax` 恒在
   `7.5e-3`，`base_im/floor` 从 763 降到 74；`σ_re` 却被从 `5.7e-8` 抬到 `1.17e-4`。
   这是「`include_L` ↔ 噪声模型在后验几何层间接耦合」的直接读数，
   也说明「先冻结电感」的顺序成立。
2. **严格 `σ≤1.1×floor` 阈值会漏判。** 新增只读诊断量
   `floor 占 σ_eff = median(floor/(floor+base))`：797 F1–F3 为 80–85%，
   1139 F1–F3 为 89–93%，即有效 σ 大部分由人为地板给出，本质是数值正则化。
   本轮**没有事后改硬判定门槛**，只加诊断列并写明保守解读；阈值修订须在第 4 步前预先登记。
3. **1139 对地板非单调**：触顶 `27.9→51.2→25.1→0%`，F1/F2 出现 6 对
   `|ρ|≈1.00` 的完全简并、bulk ESS 掉到 37/78，F3 又消失。不能在 F1/F2 之间插值找
   「最优地板」；正式档 F1/F2 补跑（`--tag f0f3full`）已启动用于复验。

另外：0.5% 加噪数据上 `1e-4` 的 `floor 占 σ_eff` 只有 2–4%、基本 inactive，
但 797 的 R̂≈1.84 / bulk ESS≈3 依然存在 —— **加噪数据另有一类采样问题，
不能靠地板解决**。

  以及在跑之前预先登记第 ⑤ 项的双条件门槛。
