# 我们的算法怎么运作、DRT 前做了哪些预处理、还缺不缺

> 代码基线：`D:\eis训练数据\bmdrt\`（bm_real.py / bm_core.py / drt.py / bm_diff.py / convert_2e.py / batch_2e.py）
> 结论基于 2026-11-05 通读代码；**本次未修改任何代码**

---

## 一句话结论

**不是"预处理做得不够"，而是"错配"**：算法把本该在**数据层**解决的有效性/结构问题，几乎全部推到了**模型层**（加 L 元件、加扩散元件）和**事后诊断层**（残差趋势、峰位出窗、端部堆积）。代价是那些数据本身有问题的谱，最后被 `select_k` 的降级路径照常输出成"K 和参数"的结论。

最值得补的只有一项：**前置 K-K 体检 + 低频截断/扩散对照分支**。电感扣除和手工剔点都不建议做。

## 1. 算法怎么运作

`bm_real.py:2-36` 的文件头把分工写得很清楚，是三层，不是一条流水线：

```
① 预处理 + 传统 DRT 预判断  (drt.py, Tikhonov 反卷积, 毫秒级)
       │  只用原始 Z，不碰 HN 参数
       │  产出：K 的候选范围 / NUTS 初值 / 端部堆积报警
       │  ★ 不定 K、不当额外观测、不进似然
       ▼
② BM-DRT 贝叶斯拟合  (bm_core.py, numpyro/NUTS)
       │  似然只用原始 (Z', Z'')，DRT 输出一个字节都没进来
       │  K 是给定值，在 ① 给的范围内逐个扫
       ▼
③ 模型比较与诊断  (PSIS-LOO + 一批硬指标)
          elpd 选 K；judge() 输出文字建议（但不进 select_k）
```

### ① 传统 DRT 预判断 —— `drt.py`

- 模型：`Z(ω) = R_inf + ∫ γ(lnτ)/(1+jωτ) dlnτ`（`drt.py:9`）
- 离散化：lnτ 上等距的 M=60 个三角基函数，τ 网格覆盖测量窗口并**两侧各留 1 decade** 吸收窗口外尾巴（`drt.py:75-88`）
- 求解：`lsq_linear` + **非负约束** + 二阶差分平滑算子 L，按 `|Z|·σ` 比例加权，σ 默认 0.5% 相对噪声（`drt.py:93-118`）
- λ 自动选：**残差比准则**（取"残差不超过最优值 1.05 倍的最强正则化"，`drt.py:162-180`）。注释明确写了为什么不用 discrepancy：数据里有电感时 γ 非负表示不了，χ² 永远降不到 2n，会一路退到最弱正则化、γ 全是毛刺
- `prescreen()`（`drt.py:223-249`）过滤窗口外伪峰：**峰位须落在测量频段内 + 面积 ≥ 总面积 2%**
- `prescreen_stage()`（`bm_real.py:1127-1147`）打印峰位/面积、端部堆积（`edge_low_frac`/`edge_high_frac` > 0.5 时报警"峰数可能被低估"）

### ② BM-DRT 贝叶斯拟合 —— `bm_core.py`

对齐 Liu & Ciucci, *Adaptive Distribution of Relaxation Time Analysis Using Bayesian Mixtures*, J. Phys. Chem. C **2025**, 129, 20268–20281（doi:10.1021/acs.jpcc.5c04766）。

- 基底：**Havriliak–Negami**，`Z_HN(ω) = R/[1+(jωτ)^φ]^ζ`
  - ζ=1 且 φ<1 → ZARC（R‖CPE）；φ=1,ζ=1 → Debye；φ=1,ζ=1/2 → Gerischer
  - 本实现 φ∈(0.5,1)，严格 Debye/Gerischer 不在参数空间内（`bm_core.py:18-28`）
- 权重：stick-breaking，`v_k ~ Beta(1,α)`，α 默认固定 0.5（`bm_core.py:235-243`）
- 采样参数（`bm_core.py:218-292`）：`R_inf`、`W`（总极化电阻）、`ln_tau`、`phi`、`zeta`（bm_real 默认钉死 1.0）、`v`、可选 `L`、可选扩散 `Rw`/`Rwo`+`tauD`、`s_re`、`s_im`
- **似然**：`Normal(Zt.real, s_re)` + `Normal(Zt.imag, s_im)`，**绝对噪声**，σ 由 LogNormal(0.01·zmax, 1.0) 采样（`bm_core.py:284-292`）
- 电感：`Z += jωL`，`L ~ LogNormal(log(1e-6), 2.0)`（`bm_core.py:280-282`）
- 扩散：可选 `Ws` 半无限 Warburg / `Wo` 有限长阻挡 Warburg，默认 `None`
- 采样：NUTS，默认 3000 warmup / 1000 samples / 3 chains；`--quick` 为 800/400/2（`bm_real.py:67-69, 1246-1249`）

### ③ 模型比较与诊断

- 逐**频率点**联合对数似然（`bm_real.py:354-378`）：同一频率的实部+虚部必须一起留出，不能摊成 2n 个独立观测，否则 LOO 泄漏、elpd 系统性高估
- PSIS-LOO → elpd，配对比较（`compare_models`）
- `select_k()`（`bm_real.py:697-775`）四条规则：
  1. 硬性剔除：grade=0 / **P(峰位出窗)>0.5** / 峰位诊断 NaN / φζ>1 超 1% / Pareto-k>0.7 超 10% / LOO 不可用
  2. 剩下的按 elpd 最大
  3. 简约优先：差值 < max(2, dse) 取更小 K
  4. **全部被剔除时** `pool = ok or usable or list(res_list)`（`bm_real.py:752`）——降级到"相对最好"，并打印"不能当结论"
- 诊断：R̂/ESS/divergences/树深度触顶、rms/σ、残差 acf、平滑趋势的白噪声零分布百分位、PPC 覆盖、分频段残差、碎片、**HN↔Warburg 退化指纹**（`bm_diff.hn_warburg_signature`）
- `judge()`（`bm_real.py:916-997`）把诊断翻成建议，但**只输出文字，不参与 select_k**

**关键设计意图**（`bm_real.py:29-35`）：不让 DRT 定 K。案例 F 的实证是：DRT 在 λ=17 把两个相距 3 倍的峰合并成一个，若照 K_drt 拟合，rms/σ=0.95、PPC=0.90 全部"合格"，只有残差 acf=0.70 暴露漏了一个过程。所以 DRT 只给候选范围和初值，K 必须由模型比较定。

## 2. DRT 前到底做了哪些预处理

### ✅ 已做（三层）

> 实测 117 条谱全部是原表真 Im Z，`imag_flipped=0`，无需翻号。

**B. 读入时 —— `bm_real.load_spectrum()`（`bm_real.py:100-188`）**

- 自动识别分隔符（`,` `\t` `;` 空白）、表头列名归一（去 Ω/ohm/单位）
- 支持 `Zre/Zim` 或 `|Z|/phase`（相位 deg→rad 自动判断）
- kHz/MHz 自动 fscale、zscale
- **过滤非有限值、f≤0**；按频率升序排序；**重复频率点取平均**（`173-183`）
- `detect_L()`（`191-194`）：最高 3 个频点投票 `Im Z > 0` 判定是否要开电感项

**C. DRT 反演内部 —— `drt.py`**

- τ 网格 ±1 decade 吸收窗口外尾巴（等于"用网格外推"代替"截断数据"）
- 按 |Z| 比例加权（σ=0.5% 兜底）、非负约束、二阶差分正则化
- λ 自动选（残差比准则，专门为"模型本身有系统偏差"设计）
- `prescreen` 过滤窗口外伪峰 + 面积 <2% 的峰
- 端部堆积报警

### ❌ 没做（对照上一轮整理的 UP主/文献 SOP）

| 环节 | 状态 | 证据 |

| **高频电感扣除（Z − jωL 或 Z-HIT）** | 没有 | 只有 `detect_L` 判定 + **贝叶斯模型内**加 `jωL`；`drt.py:25-30` 明确承认"电感在高频给出负的 γ，非负约束把它压成 0，贡献被 R_inf 吸收 → **R_inf 不能当 Rs 用**" |
| **低频扩散尾截断 / mask** | 没有 | 无任何截断；扩散只作为可选**模型项**（`--diffusion Ws/Wo`）和事后 HN↔Warburg 指纹诊断 |
| **异常点剔除 / 低频漂移点遮掩** | 没有 | `load_spectrum` 只过滤非有限值和 f≤0；`batch_2e.py` 也无额外清洗 |
| **Z-HIT 重构** | 没有 | — |
| **噪声口径统一** | 不一致 | 传统 DRT 用**相对**噪声 0.5%·|Z|；贝叶斯似然用**绝对** σ_re/σ_im（采样） |

## 3. 有没有必要补？逐项判断

### 3.1 K-K 验证 —— **有必要，而且是当前最值得做的一项**（但理由和纯 DRT 不同）

纯 DRT 流程里 K-K 是为了防止噪声被反卷积放大成伪峰。我们这里 DRT **只做预判**，不进似然、不定 K，所以"伪峰"的危害被削弱了——但 K-K 的价值反而更实在：

- 日志里 full 档 **18/117 条 `P(峰位出窗)>0.5`**，其中 5 mA 组 **13/13 全出窗**，而且这 8 条 `grade=2、div=0、R̂<1.005`——**采样完美但峰位照样出窗**。这说明它不是采样问题，是数据/模型结构问题：模型在拿"窗口外分量"去吸收低频段没被正确表达的东西。
- 如果前置 K-K 能把这些谱标成"数据不满足线性/时不变"，就能在拟合**之前**区分"数据不合格"和"模型不合格"，而不是让它们跑到 `select_k` 里被硬剔除、再被 `pool = ok or usable or res_list` 降级路径照常输出 K、参数、图和等效电路图（日志里已记录的算法问题 #1）。
- 换句话说：**加 K-K 是修根因，不是给 select_k 打补丁**。

但要诚实说清局限：K-K 只能验证因果/线性/时不变/有限，**不能告诉你该截哪个频点**；Lin-KK 在只有 5 decade（1 Hz–100 kHz）的有限频段上对外推敏感，M 的选择（μ<0.85）也有主观性。所以它应该做成**"标记 + 触发敏感性分析"**，而不是硬拒绝。

### 3.2 电感扣除 —— **对贝叶斯拟合不必做（甚至不该做）；对传统 DRT 预判可以做**

- 贝叶斯模型已显式含 `jωL`，108/117 条自动开 L，`detect_L` 三点投票在日志里被验证很稳（108/117 全 3/3 票，去掉最高频点 0 条翻转）。**在模型里加 L 比事先扣除更干净**：扣除要先估计 L，估计误差会被写进数据、且丢失不确定性。
- 但 `drt.py` 的预判 DRT **没有 L**，电感被压进 `R_inf`，导致 R_inf 高估、端部堆积、λ 选择被迫从 discrepancy 改成残差比准则。这会污染 K_drt 候选范围和 NUTS 初值。
- **建议做一个局部、零风险的改动**：只在 `prescreen_stage()` 里把 `Z − jωL`（L 用高频点粗估或取自一次快速拟合）喂给 `drt()`，**贝叶斯似然仍用原始 Z + L 元件**。两条路径物理一致，互不干扰。

> 这也解释了日志里"高频相邻 |Z| 跳变 >20% 共 109/117"——已确认那抓的是**感抗上升沿**，不是离群点，不该当异常点删。

### 3.3 低频扩散尾截断 —— **有必要，但要成对做（截断 + 扩散对照），不能盲目截**

证据链：full 档 **37 条端部堆积**、**18 条"原始 0 峰"**、**18 条峰位出窗**，C 档 18 条里 17 条有端部堆积提示。`drt.py:147-149` 与 `bm_real.py:1143-1146` 都明确写了"γ 在网格边界仍很高 = 窗口外还有未分辨的弛豫"。

这正是上一轮 UP主/文献说的"低频 45°尾不适合 DRT，需扣掉或交 DCT"在我们算法里的对应症状。但我们的数据只有 5 decade、低频 5 点 Re 相对起伏中位 16%，信息本来就少，**直接砍点会丢掉唯一的低频约束**。正确形态是一个前置分支：

```
端部堆积 / P(峰位出窗) / 低频漂移 触发
   ├─ 截断敏感性：去掉 1~2 个最低频点重跑，看 K 和峰位是否稳
   ├─ 强制 --diffusion Ws/Wo 做对照（而不是让某个 HN 分量冒充 Warburg）
   └─ 若 K 随截断漂移 → **拒绝定 K**，标注"低频未分辨"，而不是给个数字
```

`bm_diff.hn_warburg_signature` 已经能识别"单个 HN 把半无限 Warburg 逼近到 1e-6、峰位跑到窗口外 8 个量级"的指纹（日志问题 #5），只差把它接到 `select_k` 里做决策——目前 `judge()` 只打印不决策。

### 3.4 手工异常点剔除 —— **不建议**

- 日志已明确否定了"109/117 有高频离群点"这个判断：那个判据抓的是感抗上升沿。删了会丢真实高频信息。
- 上一轮文档里的实证（ZView 移除部分点后 DRT 双峰变单峰）恰恰说明**手工删点能改变结论**，主观性太大。
- 贝叶斯似然里 σ_re/σ_im 是采样的，对孤立离群点已有一定鲁棒性。真要做，也必须做成可复核、带敏感性分析的规则，而不是手工挑点。

### 3.5 噪声口径不一致 —— **至少要在报告里说明**

传统 DRT 用相对噪声 0.5%·|Z|，贝叶斯似然用绝对 σ_re/σ_im（从 LogNormal 采样，中位约 0.01·zmax）。因为 DRT 不进似然，实际影响有限；但 `summary` 里同时出现 `lam_drt` 和 `rms_re/sigma_re` 时容易误读成同一套噪声。建议只在文档中澄清，不必改代码。

## 5. 与上一轮 DRT 文献 SOP 的对照

| UP主/文献 SOP | 我们的算法 | 评价 |
|---|---|---|
| 文件清洗（删表头、只留三列） | ✅ `convert_2e.py` 做得更严谨（还带相位/幅值自检） | 优于通用做法 |
| 虚部符号统一 | ✅ 用 `|Z|`/phase 反算自动判定 | 优于人工判断 |
| K-K 验证 | ❌ 无 | **主要缺口**；但项目里已有 `lin_kk` 可复用 |
| 高频电感"不能简单删点，要还原圆弧" | ⚠️ 未扣除，改为模型内加 `jωL` | 思路等价且更适合贝叶斯；但传统 DRT 预判仍受污染 |
| 低频扩散尾扣掉 / 交 DCT | ⚠️ 不截断，改为可选扩散元件 + 事后指纹 | 模型层处理更完整，但缺"事前拒绝定 K"的决策分支 |
| 分频域 RRDRT/DRT/DCT | ⚠️ 只有 HN + 可选 Ws/Wo，无独立电感解析 | 我们的 HN 基底更灵活，但把电感交给单个 L 参数 |
| 残差图 + Bode 交叉验证 | ✅ 更强：分段残差、趋势零分布、PPC、acf、LOO | 明显优于通用做法 |
| 正则化参数可复核 | ✅ λ 残差比准则自动选、写进 json | 优于手调 |

**总体判断**：我们的"数据工程层"和"事后诊断层"比通用 DRT 教程严谨得多；**缺的是"数据有效性准入层"**。这不是方法落后，而是架构上把这一层的功能分散到了模型项和诊断里，导致数据问题最终被表达成模型结论。补上 K-K 前置体检 + 低频决策分支，就能把这条链路闭合。

## 6. 后续补充：低频不用 DCT

详见 `低频数据是否用DCT_结论.md`。要点：

- **DCT 不是"低频专用工具"**，而是把**导纳 Y(ω)** 对电容时间做反卷积（Maxwell 并联组合）；严格对应低频扩散的是 **DDT（扩散时间分布，传输线核）**。四者适用边界由阻抗渐近行为决定：DRT/DDC 在低频发散时于高 τ 失效，DCT 在高频阻抗→0 时于低 τ 失效（DeCarbon 2026 综述）。
- 我们全在阻抗域、参数化贝叶斯混合，**引入 DCT 会与现有似然/LOO 口径不兼容**；且 `bm_diff` 的 Warburg 族元件已具备低频表达能力，缺的是开关与决策，不是新反卷积工具。
- **关键代码事实**：`batch_2e.py:101-106` 的批量命令没有 `--diffusion`，`report_2e.py:172-173` 明确写"低频 −45° 尾需单独跑 `--diffusion Ws/Wo` 对照，**本批没做**"。所以 117 条谱的低频全靠 HN 硬扛，正是 `bm_diff.py:10-18` 警告的"单个 HN 把峰推到窗口下方 8 个量级冒充 Warburg"退化——这才是 37 条端部堆积 / 18 条峰位出窗的机理。
- 因此上一轮 P0 建议应具体化为：**把 `bm_real.py:884` 的"先加 --diffusion Ws 做对照"从一句打印升级成决策**，把 `diffusion` 纳入 `select_k` 的模型比较维度（同一套逐点似然 + PSIS-LOO 比较 none/Ws/Wo），而不是引入 DCT。
