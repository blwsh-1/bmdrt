| 上一轮我说的 | 订正 |

## 1. 拓扑归属（数值断言，不是嘴上分类）

三类各 1000 条，文件名 = 拓扑串 + 参数真值。按 `-` 串联 / `,` 并联 / `[]` 分组、
`Z_P = Q/(i·2πf)^n` 重建真值谱；再用 **`bm_top.z_cpe` 的窗口幅值参数化**
（`Q_ours = Q_data/ω_ref^n`）把同一套参数写进我们的嵌套骨架：

| 类 | 拓扑串 | 归属 | 与 `z_nested` 骨架重建的最大相对误差 |
|---|---|---|---:|
| 涂层 | `R1-[P2,R3-[P4,R5-P6]]` | **nested L=2**，最内层 `R5 + CPE(P6)` | 1.56e-15 |
| 钝化 | `[P1,P2-R3]-R4` | **nested L=1**，最内层 `CPE(P2) + R3` | 1.12e-15 |
| 腐蚀 | `R1-[R2,P3]` | `Rs + (R ∥ CPE)` = ZARC，`voigt K=1` 可表示 | 9.27e-16 |

1e-15 = 机器精度，说明**骨架和参数化都对齐了**，`Q_ours = Q_data/ω_ref^n` 可直接换算。

**但关键在元件类型**：`bm_top.z_nested` 的最内层 `branch` 只有
`R_ad ∥ L_ad`（`z_rl_parallel`）或 `R_L + L_ad`（`z_rl_series`），**两者都是感抗（负 γ）**；
而这批涂层/钝化谱的最内层是**容性 CPE**。所以：

> 涂层/钝化的**嵌套骨架完全对**，但最内层元件类型不对 → 严格说仍在我们两族之外。
> 这正是 `NESTED_TOPOLOGY_PROJECT.md` §9.4.27.3 记的「C3 混合拓扑、两族不相交」缺口，
> 本轮用真值数据把它坐实了。**要正确拟合这批谱，需要的是 nested 骨架 + 容性最内层**
> （把 `branch` 换成 CPE，或补第三个 CPE 层），不是简单"选用 nested 档"。
> 本轮**不改模型**：§13/§14 验收尚未过线，且这轮是只读标定。

频点 60、频率降序 26337→0.001 Hz（7.4 dec），脚本统一转升序。

## 2. 零分布与真值噪声：0.50 线有效，但「噪声」必须限定为 i.i.d.

`acf` 用项目口径 `max(acf_max(res.real), acf_max(res.imag))`、滞后 1–5、原始残差。

**白噪声蒙特卡洛（20000 次/档）**：

| n | p95 | p99 | P(acf ≥ 0.50) |
|---:|---:|---:|---:|
| 50（我们真实谱） | 0.370 | 0.430 | 0.0008 |
| 60（这批合成） | 0.341 | 0.397 | 0.0001 |
| 121（NaOH） | 0.248 | 0.290 | 0.0000 |

复现 §13.3 的 0.28–0.40 ✓，且 0.50 线在高斯白噪声下过线率 **< 0.1%**，非常保守。

**真值噪声 realization**（`Z_obs − Z_true`，即「模型完美时」的残差；每类 300 条）：

| 类 | 相对误差中位 | acf 中位 | acf 最大 | **P(acf ≥ 0.50)** | 频率重排后中位 | 重排后 P≥0.50 |
|---|---:|---:|---:|---:|---:|---:|
| 涂层 | 1.95% | 0.301 | 0.562 | **0.013** | 0.225 | 0.000 |
| 钝化 | 3.66% | 0.411 | 0.842 | **0.267** | 0.190 | 0.000 |
| 腐蚀 | 2.85% | 0.354 | 0.668 | **0.077** | 0.219 | 0.000 |

另：§4 P4 抽样的 8 条谱上，真值噪声 Rwp 中位为 9.41 / 8.32 / 6.92%。
Rwp 是 RMS，被重尾尾部拉高（中位相对误差只有 2–4%、p95 可达 28%），两者不矛盾。

三个结论：

1. **×4 缩放 acf 逐条差 = 0.00e+00**：尺度不变性成立，幅度不是 acf 的自变量。
2. **频率随机重排后，三类过线率全部归零**、acf 中位降到 0.19–0.225（回到白噪声带）。
   所以钝化 26.7% 的过线**完全来自噪声的频率相关结构**，与重尾/幅度无关。
   抽一条涂层谱看：虚部 lag1=0.354、实部 lag3=0.328，而与 log f 的线性相关只有
   −0.05 / +0.243 → 是**局部/振荡型相关**，不是简单单调漂移。
3. 对 §18 规则 2 的**边界补充，不是推翻**：§18 写「随机测量噪声单独无法制造高 acf」，
   那里的噪声是 i.i.d. 高斯相对噪声（N 组 4%，Δacf=+0.000）。本轮说明该结论只在
   **独立同分布**下成立；带频率相关结构的噪声，即使模型完美，也能让 0.50 线过线。
   这与 §19 的 S3 机制（平滑 = 相关）同型。**§18/§19 原文不动。**

## 3. §19 S3 注入：跨数据源定性一致，定量不是普适常数

同一公式 `Z = Z_noisy + 1j·a·|Z_true|·sin(2πt)`，`t` 为 log f 归一化；每类 12 条。

| 类 | a=0.05 | a=0.15 | a=0.30 |
|---|---|---|---|
| 涂层 | 0.879（12/12 过线） | 0.976（12/12） | 0.987（12/12） |
| 钝化 | 0.474（5/12） | 0.767（11/12） | 0.894（12/12） |
| 腐蚀 | 0.875（11/12） | 0.968（12/12） | 0.977（12/12） |
| §19.5 参照（G/T2c） | 0.616 | 0.919 | 0.960 |

「5% 平滑振荡足以把 acf 推过 0.50」在**独立数据源上成立**，涂层/腐蚀甚至更敏感
（基础噪声本身已带相关，再叠正弦很快饱和）。但**最小过线幅度因谱型而异**：
涂层/腐蚀 0.05、钝化 0.15。所以 §19 的 `S3/a=0.05` 是一个**构造下的结果**，
不能当成跨体系普适常数写进判据。

## 4. 分族对照：你提醒的「不要跑错模型」，答案是两族都不完全对

每类抽 8 条，用**确定性加权最小二乘**（σ=|Z|，实虚联合）分别拟合
`voigt K=1/2/3`（串联对称 ZARC）与 `bm_top.z_nested(parallel/series, L=1/2)`。
`z_nested` 用的是我们的生产正演函数，但**拟合器是 LS 代理，不是 `fit_top` 的 NUTS；
voigt 也不是 `bm_core.fit` 的 ζ 自由 HN**。此表只用于量化模型失配的量级，不参与任何判定。

| 类 | 真值上界 Rwp / acf | 模型 | Rwp 中位 | acf 中位 | acf≥0.50 |
|---|---|---|---:|---:|---:|
| 涂层（nested L=2） | 9.41% / 0.293 | voigt K1 | 15.60% | 0.889 | 8/8 |
| | | voigt K2 | 10.24% | 0.819 | 8/8 |
| | | **voigt K3** | **8.52%** | **0.292** | **0/8** |
| | | **nested_parallel_L2** | **9.71%** | **0.782** | **8/8** |
| | | nested_series_L2 | 9.52% | 0.774 | 8/8 |
| 钝化（nested L=1） | 8.32% / 0.417 | voigt K1 | 19.17% | 0.833 | 8/8 |
| | | voigt K3 | 8.00% | 0.442 | 3/8 |
| | | nested_parallel_L2 | 7.94% | 0.473 | 3/8 |
| 腐蚀（voigt K=1 族内） | 6.92% / 0.398 | 全部 7 个模型 | 6.30–6.58% | 0.379–0.438 | 0–2/8 |

**族内对照先验证实验没跑偏**：腐蚀谱上所有模型都贴到噪声底（6.3–6.6%）、
acf 0.38–0.44 ≈ 真值上界 0.398，没有谁能"凭空"制造或消除结构。

**涂层谱上 acf 从 0.292 到 0.889，全看用哪个模型**——这是本轮最该记住的一条：

- `nested L=2`（骨架对、最内层元件错）：Rwp 9.71% ≈ 噪声底 9.41%，**幅度对了但结构不对**。
  抽一条看残差：lag1=0.538、lag2=0.397 连续同号衰减，分段相对残差实部均值
  +0.0055 → −0.0141 → −0.0328 单调漂移 → 典型的**跨频段平滑系统性失配**，
  正是 `acf` 设计要抓的东西。
- `voigt K=3`（10 个自由度的过参数化）：Rwp **8.52% 低于噪声底 9.41%**，
  即**把噪声也拟合掉了一部分**；低频段残差只剩 1.76%，lag 序列无连续同号，
  acf 掉到 0.292。**acf 低不等于模型对**，只是失配被打散成不相干小残差。
- 高频段两者都是 16.8% 左右（17 点窗口端部），与模型无关 → 与
  §18/§19「查整谱频响/校准，不是重测高频几点」的方向一致。

所以「不要跑错模型」在这批数据上的真实含义是：

> 拿 voigt K=1 跑嵌套谱 → 大幅失配、acf 0.889；
> 拿 nested L=2 跑 → 骨架对但仍缺容性最内层、acf 0.782；
> 拿过参数化 voigt K=3 跑 → acf 0.292 但那是过拟合。
> **没有一个是"正确的模型"**；要正确拟合得先补 `z_nested` 的容性支路（§1）。

## 5. 对既有结论的影响（只能写成边界补充）

- **§18/§19「卡 acf 的是数据不是 ECM」**：那两节的 G 组由**我们自己的** nested 模型生成、
  用同一模型拟合，族内零失配，acf 只能来自数据 → 结论在族内**仍成立**。
  本轮补的是**族外**情形：一旦生成族与拟合族不重合，模型失配本身就能把 acf
  从 0.29 推到 0.89。因此该结论**不能无条件外推**到新体系/新数据源。
  这补上了 §17 四电路反事实没覆盖的情形——那四个都是族内变体、且在真实谱上做的；
  本轮是在**已知真值的合成谱**上换族，两者不可直接并表，方向互补。
- **§13 `0/3`、§14 `4/14`、§17 `0/10`、§18/§19.5 结果**：全部原样保留，
  不改判、不改阈值、不放宽验收线、`bmdrt.py` 继续不接 nested。
- **R24**：上一轮体检里合成谱 Lin-KK 重建残差 acf 中位 0.401、Rwp 5.3–11.0%，
  与本轮真值噪声（acf 0.30–0.41、Rwp 8–12%）同量级 → 有限阶重建基本贴到噪声底，
  没有引入超出噪声本身的额外结构。本轮**未重跑 Lin-KK**，R24 原文保留，
  这里不构成新证据。
- **0.50 线本身**：白噪声过线率 <0.1%、重排后归零 → **没有理由改这条线**。
  需要改的是措辞：判据假设的是「残差里不该有结构」，而"结构"既可来自数据偏差，
  也可来自模型失配、也可来自数据生成过程自带的相关噪声。三者当前无法从单个
  acf 值区分。

## 6. 边界 / 没做的事

- 本轮全部 `exploratory`。合成谱是 `inferred` 级构造数据，**噪声是人为生成过程给的，
  不是真实仪器噪声**；26.7% 这类数字不能读成"0.50 线对真实谱的假阳性率"。
- P4 是 LS 代理，**不是 NUTS、没有先验、没有 K 选择、没有 R̂/ESS/div 门禁**，
  数值不可与 `real_*.json`、`*.nested.json` 直接比。
- 未跑 NaOH（14 个不同电位、无同状态重复）→ **R18 仍未解决**；相位噪声底仍缺。
- 未做 B（拓扑真值下的 TP/FP / 拒答正确性）、未做 C（NaOH 跨电位归因）、
  未跑 3000 条 NUTS、未训分类器、未扩 `layers=3`、未改任何模型族。
- 合成谱 7.4 dec / 60 点与真实谱 50 点 / 0.1–1e5 Hz 不同，端部与窗口外不可辨识
  结论不能照抄。
