## 0. 结论先行

1. **能批调**。`run_bm_drt_programmatic` 是纯函数，7 条谱全部跑通，
   单条约 35–273 s。上一轮列的"前置障碍"不存在。
2. **同源确认，差异不在算法**。它的 BM-DRT 就是 Liu & Ciucci 2025 的
   HN 混合 + NUTS，和 `bm_core` 同源。真正不同的两处是**模型族内容**
   （它没有电感项、Warburg 是并联混合、分量幅度彼此独立）与**判据**
   （它没有任何 MCMC 诊断或质量标记）。
3. **"它给区间、我们给降级"是真的，但不是一一对应**。7/7 条谱它都返回
   `ok=True`、完整 q05/q95 区间和参数摘要，`result` 里**没有任何
   status/warning/quality 字段**；我们 `refused`（`kk=fail`）的 2 条它照样给数。
   反过来，`AZ3` 我们降级是因为 R̂/ESS 采样诊断（它根本不测），而
   `3E-1_OER_exp1_0005mA` 我们报数、它的残差 acf 却是 0.786。
   **判定标签不同源，稳定一致的是残差结构，不是"谁判坏"。**
4. **本轮最有价值的副产品是 §5.2：acf 跨模型族几乎完全一致**
   （5 条有我方产物的谱，Pearson r = 0.9975；原按 4 条算为 0.9971，
   见 §5 勘误；ADAPT 一律高 0.002–0.082，
   `acf=0.50` 分界无交叉）。换一套独立实现、不同先验、不同 σ 口径、
   不同分量结构，残差自相关排序不变 → 这比 `M6_VALIDATION_PLAN.md` §17
   的"四电路反事实"更外部地支持 §18/§19 的归因：**卡 acf 的是数据，
   不是我们挑的 ECM**。
   **但只能写"支持"，不能写"证明"**：ADAPT 在坏谱上 Rwp 29–82%，
   它自己也没拟合好，"数据有整谱偏差"与"外部拟合失败"在本轮分不开。
5. **战略判断不变**（`EXTERNAL_BASELINE_ADAPT_ECM.md` §5）：不做更好用的
   EIS 工具、不发新 DRT 算法论文；"什么时候 DRT 结论不可信"这条路上
   多了一条可引用的外部证据，而且它同时说明**我们的门禁抓的是别人
   不报的那部分信息**。

## 1. 前置障碍已解除：能脱离 GUI 批调

`src/adapt_ecm/run_bm_drt_simple.py:146` 的
`run_bm_drt_programmatic(freq, Z, ...)` 是给 GUI 写的无对话框入口：

- 签名只吃 `freq` / `Z` 两个数组，返回纯 dict（含 `Z_fit`、q05/q95 区间、
  `parameter_summary`、DRT 曲线）；不 import Tk、不画图、不开文件对话框。
- 依赖 `jax` / `numpyro` / `pandas`，本机 `/d/autoeis_env` 已具备
  （jax 0.6.2、numpyro 0.19.0、numpy 2.2.6）。
- GUI 默认值与 runner 默认值逐项一致
  （`EIS_DRT_WORKBENCH_BM_DRT.py:3707-3720`）：Warburg **On**、
  `k_hn=5`、`k_warburg=2`、`warmup=500`、`samples=800`、`chains=1`、
  `seed=0`、`tau_points=300`。所以本轮用 runner 默认参数对它是公平的。
- 单条 50 点谱约 2.5–3.5 min（单链 NUTS，CPU）。

## 2. 同源确认，以及真正的模型差异

骨架确实同源：都是串联 K 个 HN + stick-breaking 权重 + NUTS，
都出自 Liu & Ciucci 2025。**"我们用贝叶斯 DRT"不是优势**，这点不变。
但实现细节的差异比上一轮从 README 推测的更大：

| | 我们 `bm_core.make_model()` | ADAPT-ECM `bm_drt_helpers` |
|---|---|---|
| 分量幅度 | `W·π_k`，**全部分量共享一个 W** | `π_k · w_k`，每个分量独立 `HalfNormal(3)` |
| HN 指数 | φ∈(φ_lo,1)、ζ∈(0.3,2) 且 ζ 自由 | φ∈(0.05,1)、α∈(0.05,1)，各自独立 |
| τ 先验 | `Uniform`（测量窗 ±pad_dec） | `Normal(log_tau_center, log_tau_sd)`，宽高斯 |
| stick-breaking | `Beta(1,α)`，α 可采可固定 | `Beta(1, alpha_dp)`，`alpha_dp~Exponential(1)` |
| 噪声 σ | LogNormal(0.01·zmax,1) / 固定 / **逐点** | `HalfNormal(0.08)` 两个标量，作用在 `Z/P90(|Z|)` 上 |
| 电感 | `iωL` 串联，默认由 `detect_L` 决定 | **BM-DRT 模型族里没有电感项** |
| 扩散 | Ws / Wo 串联相加 | `p_W_fraction` 加权**并联混合**的 Warburg 幂律项 |
| 组件数 K | 谱内 K 选择 + elpd 比较 + 门禁 | 固定 `k_hn=5`（用户设上限），靠 stick-breaking 压掉多余分量 |
| 拟合曲线 | 逐样本算 Z 再逐点取分位中位 | 同（`posterior_predictions`），**这一条一致** |

感抗那一行是实质差异，不是实现风格：它的 HN 与 `1/(iωτ)^α` 都是负虚部项，
`R∞` 是实数，**整个模型族无法产生 `Im Z > 0`**。它的 GUI 另有感抗策略
（`drt_helpers.py:32-36`：保留全部 / 加串联电感 / 直接丢弃感抗点），
但那些用在 Simple/Bayesian DRT 与 Lin-KK 上，BM-DRT 的 programmatic
入口没有对应参数。我们的 18 条 AZ31 低频是感抗
（见 `WS_CRITERION_PLAN.md`），因此这一族在我们这批谱上先天缺项。

## 3. 它到底有没有「拒答」：源码事实

上一轮说"它给区间、我们给降级"，现在可以按行号核实：

- `run_bm_drt_simple.py:231-241`：`mcmc.run(...)` 之后直接
  `mcmc.get_samples()`，没有 `print_summary`、没有 `extra_fields`、
  没有 `gelman_rubin` / ESS / divergence 检查。单链默认，本来也算不出 R̂。
- 返回的 `result` dict（同文件 `:262-296`）只有数值与设置，
  **没有任何 status / warning / quality / converged 字段**；本轮脚本用
  `has_quality_flag` 逐条实证。
- GUI 侧 `EIS_DRT_WORKBENCH_BM_DRT.py:9392` 写死 `"ok": True`，
  只要函数没抛异常。
- GUI 里出现的 `Status: fit converged`（`:9912`）指 **ECM 的 least_squares
  拟合收敛**（`scipy.optimize` 的 `success`），不是 MCMC 收敛；批处理计数
  `ok_count`（`:9984`）也是这个。
- README "Output Philosophy"（残差画出来、λ 选择可见、给不确定性带）
  确实是**透明化**，不是拒答；这一点上一轮的判断成立，且要补一句：
  **没有证据说它藏失败**，该画的都画了。
- 论文标题里的 `CI-admissibility` 在这个发行包里**只出现在两条引文**
  （`:4683`、`:4694`），代码与 README 没有对应判据实现。不能据此说论文没做，
  只能说这个软件包里没有。
- Lin-KK 是独立 tab，不是 BM-DRT 的前置门禁；`kk_lin_test.lin_kk_fit`
  扫 M 取第一个 `mu ≤ 0.85`（与我们 `bm_kk.py:189` 的肘部准则同类）。

对照我们这边：`bm_real.py:2730` 的 gate 模式在 `kk.status == "fail"` 时
**无条件拒绝定 K、本次不做拟合**；只有 `unavailable` 才在默认非 strict 下
fail-open，并且必须打显著警告 + 落 `kk_performed=false`。
`R̂≤1.05 / div=0 / acf≤0.50` 是 `M6_VALIDATION_PLAN.md` §14.3 的预注册线，
超限降级而不是删掉。

## 4. 对照口径（不另造阈值）

- `Rwp[%] = sqrt(mean(|dZ|²/|Z_obs|²))·100`，实虚联合、不除 √2
  （与 `bm_ref_rwp.py` 一致）。
- `acf = max(acf_max(d.real), acf_max(d.imag))`，滞后 1–5 取最大绝对值，
  与 `bm_real.py:1086`、§14.3 的 M-b 同口径；结构线 `acf ≤ 0.50`。
- 区间宽度 = `(q95 − q05)/|Z|` 的逐点中位（它自己的 posterior 分位带）。
- 我们侧判定**直接读已落盘的 `out/<样本>/real_<样本>.json`，不重跑拟合**：
  `kk=fail` 或 `K is None` → `refused`；`grade_fail` 非空 → `degraded`；
  其余 → `reported`。
- 谱集 7 条，覆盖我们三种判定状态 + 端部元件 + 低频感抗。
  `archive/AZ31-4Li.txt` 是六列 `index,f,Zre,Zim,...` 导出，
  `load_spectrum` 会误读成 `n=49, f=1–49 Hz`，**故意排除**。

### 5.2 acf 跨模型族一致（本轮最重要的结果）

有我方产物的谱，两边 `acf` 同口径、可直接配对（第 5 条为上面的勘误补入）：

| 谱 | 我们 | ADAPT | Δ |
|---|---:|---:|---:|
| `2EMC1-1_0005mA` | 0.785 | 0.811 | +0.027 |
| `3E-1_OER_exp1_0005mA` | 0.743 | 0.786 | +0.043 |
| `AZ3` | 0.380 | 0.427 | +0.047 |
| `Blank_0.1KBr...` | 0.381 | 0.463 | +0.082 |
| `AZ31-4Li_100`（勘误补入） | 0.909 | 0.911 | +0.002 |

**5 条 Pearson r = 0.9975**（原报告按 4 条算的 r = 0.9971），ADAPT 一律
略高 0.002–0.082，**排序完全相同**，且 `acf=0.50` 的分界没有任何交叉。
`AZ31` 是两套完全不同模型族、不同 σ 口径下 Δ 仅 0.002 的一对，
把这条归因又推硬了一点。特别看两处：

- `AZ3` / `Blank` 两边都拟合得很好（Rwp≈0.5%），acf 仍同序且都 <0.50；
- `2EMC1-1_0005mA` 我们 Rwp 低而 ADAPT 已到 29%，acf 只差 0.027
  → **acf 对"哪个模型、拟合得多好"不敏感，更像由数据本身决定**。

这比 §17 的四电路反事实更外部：那次换的是我们自己 ECM 库里的电路，
这次换的是独立实现、不同先验、不同 σ 口径、不同分量幅度结构、还多一个
Warburg 混合的结论。**"卡 acf 的是数据不是模型"这条归因得到了独立支持。**

必须同时写明边界：ADAPT 在坏谱上 Rwp 29–82%，它自己也没拟合好，
所以"数据整谱频响/校准偏差"与"外部拟合失败"在本轮**分不开**。
本轮只能说"支持"，不能说"证明"；也不据此改 §13/§14 任何结论。

### 5.3 三条它没报、但产物里看得见的信号

1. **模型族表达不了感抗**。HN、`1/(iωτ)^α`、`R∞` 的虚部恒 ≤0，
   所以观测有 11–20 个 `Im Z>0` 的 2E/3E 谱，`Z_fit` 的对应点数
   **全部是 0**。`AZ31-4Li_100` 观测最大 +1174.7 Ω，拟合一个正虚部点都没有，
   低频段 Rwp 121.0%，`sigma_re` 后验被推到 **635.6 Ω**（`AZ3` 是 0.081 Ω）。
   它给的不是"窄到骗人"的区间（`CI_re=0.718`，其实很宽），而是
   **没有任何一句话告诉你模型缺项**。
2. **链退化的迹象没有被拦下**。三条最差的谱耗时 35 / 62 / 37 s，
   而正常谱是 171–273 s；`sigma_re` 后验分别是 0.0071 / 0.00075 Ω
   （相对几十 Ω 的残差完全不合理）与 635.6 Ω（另一端）。
   `result` 里没有 divergence / ESS / R̂，GUI 又写死 `ok=True`，
   于是"采样没动"和"采样成功"在产物层面**不可区分**。
3. **DRT 主峰顶到 τ 网格上界**。`2EMC1-1_0005mA` 与 `2EMC1-2_0750mA`
   的 `gamma_total_q50` 峰位都恰等于 `tau_max = 15.89 s`
   （`ratio = 1.0000`），即主弛豫跑到测量窗外、模型定位不了。
   我们这边有 `p_tau_out_max` / `comp_unresolved` guard 专门抓这种情况，
   它那边没有任何等价提示。

### 5.4 回答上一轮 §6 的三问

| 问题 | 答案 |
|---|---|
| 选出的 K / 峰位 τ 是否一致？ | **不可直接比**。它是固定 `k_hn=5` 的过参数化混合、没有 K 选择，我们按谱选 K 且 `refused` 时根本不报 K；本轮不做等价映射。能比的是峰位：两条 2E 谱的峰顶到 τ 网格上界（§5.3-3），属于"窗口外不可辨识"，与我们的 `comp_unresolved` 结论定性一致。 |
| 后验区间宽度是否量级一致？ | **不是一回事**。两边都是逐样本算 Z 再逐点取分位（做法一致），但它的 σ 是 `HalfNormal(0.08)` 的相对标量、我们支持绝对/逐点 σ（R17）。容性谱 `CI_re≈0.002`，坏谱 0.028–0.718。**R17 的警告仍然成立：σ 口径不同，区间宽度不能当跨族证据。** |
| 它给区间、我们给降级的，是不是同一批？ | **不是一一对应，但方向大致一致**。我们 `refused`/`degraded` 的 4 条里，3 条 ADAPT acf >0.50；`AZ3` 是例外（我们因 R̂/ESS 降级，它 acf 0.427）。反过来 `3E` 我们 `reported`，它 acf 0.786。**共同信号是 acf 排序，不是判定标签**——因为两边门禁测的根本不是同一件事：我们是 Lin-KK 事前数据自洽性 + MCMC 采样诊断，它是事后无门禁。 |

### 5.5 不能从本轮推出的话

- 不能说"ADAPT-ECM 算法比我们差"：坏谱上的 29–82% 是**默认设置遇上
  感抗谱型**的结果，换设置（关 Warburg、丢感抗点、加电感、加链）很可能改善，
  本轮没替它调参，也不该替它调。
- 不能说"它隐藏失败"：残差图、区间、参数表都在，README 的透明化主张成立；
  差别是**没有显式判据与拒答**，不是藏数据。
- 不能说"我们因为它而更可信"：本轮没有任何新验收线、没有改判据，
  只是把一个外部基线摆在旁边，让 §19 的归因多一条独立佐证。

## 6. 必须先排掉的坑：runner 会重排频率

`run_bm_drt_simple._clean_eis_arrays()`（`:94-105`）按
`np.argsort(freq)[::-1]` **降序重排**后返回，而 `bm_real.load_spectrum`
给的是升序。第一次试跑直接用原始 `z` 减 `Z_fit`，得到 `AZ3` 的
`Rwp=76.99%`、`bands=52.6/19.6/123.2%`，而 `Z_fit` 的虚部范围
（−10.40..−1.86）与观测（−10.2..−1.75）几乎重合——这个矛盾就是错位信号。
换用 runner 自己返回的 `r["freq"] / r["Z"]` 对齐后即消失。

这类"跨库数组顺序"错误不会在任何 R̂ / acf 里露出来，只会表现为
"外部基线莫名其妙地烂"。脚本里用 `assert` 把
`result["Z_exp"] == r["Z"]` 钉住，避免以后再被"修"回去。

## 7. 边界

- 本轮只对照 **BM-DRT 这一档**，不评估它的 Simple DRT / Bayesian DRT /
  电路构建器 / persistence map；说"它是超集"仍指功能面。
- 单链、默认 seed=0、默认 warmup/samples，与 GUI 默认一致；**没有替它调参
  调到好看**。它的模型可能有更好的设置，本轮不找。
- ADAPT 的输出只写进 `out/adapt_baseline/`，**不进任何生产结果、不参与
  门禁、不改分级**。
- 残差 acf 只作对照指标，不是给它新造一条验收线；本轮结论不用于改判
  §13/§14 的任何验收结果。
