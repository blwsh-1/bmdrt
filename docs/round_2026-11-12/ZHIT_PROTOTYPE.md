# Z-HIT 原型评估：试过，不接

> 2026-11-12 · 代码 `bm_zhit.py`（原型，未接入任何门禁）· 结论：**否决**

## 1. 结论

**不接入。** 一阶 Z-HIT 在无噪声的完美谱上就有 0.95%–3.25% 的固有偏差，
与我们要检的不自洽（5% 幅值偏差 → 3.0%）**同量级**；22 条真实谱全部 fail，
而 fail 的驱动是**谱型**（端部感抗、相位跨 0），不是数据坏。

换句话说：它给不出"这条谱不自洽"的判断，只能给出"这条谱不是宽 DRT"。
后者我们本来就知道。

## 2. 实现的是什么（以及不是什么）

Z-HIT 的出发点是 Bode 增益-相位关系（Hilbert 变换的实轴形式）：

```
φ(ω) = (π/2) · d ln|Z| / d ln ω            (局部近似)
ln|Z(ω)| = c + (2/π) ∫ φ(ω') d ln ω'       (积分)
```

`bm_zhit.zhit()` 实现的就是上面这条一阶式：相位平滑（Savitzky-Golay，
窗宽报出来）→ 积分 → 与实测 `ln|Z|` 比 → 相对偏差。锚点 `c` 用中位数，
**整体幅值平移被吃掉**，所以它只检验"幅值随频率的形状"，不检验绝对标定。

Zahner 的 modified Z-HIT 在此之上加了窗函数、端部外推和二阶修正，参数不公开。
**本原型不是商业实现**，百分比不能和 Zahner 的数字逐行对比。

## 3. 合成标定（`python bm_zhit.py --synth`）

50 点，100 kHz → 10 mHz，与实测同网格。`rms` 是 50 点上的相对偏差均方根。

| 构造 | rms | 说明 |
|---|---:|---|
| `R_only` | 0.00% | 纯电阻，精确 |
| `zarc_0.5` | 0.95% | 宽带 DRT |
| `hn_2comp` | 1.12% | **两个 HN 串联 = 我们的模型族** |
| `zarc_0.7` | 1.67% | 中等展宽 |
| `zarc_0.9` | 2.63% | 近 Debye |
| `debye` | 3.25% | 最窄分布，**一阶近似误差上限** |
| `ind_tail` | 5.61% | 低频感抗尾（AZ31 型），无噪声 |
| `RL_inductive` | 7.69% | 串联电感主导 |

噪声底与待检信号的对比：

|---|---:|
| `zarc0.7` + 0.2% 噪声 | 1.75% |
| `zarc0.7` + 1.0% 噪声 | 2.12% |
| `zarc0.7` + 2.0% 噪声 | 2.74% |
| `zarc0.7` + **5% 平滑幅值偏差**（§19 那个构造） | **3.02%** |
| `zarc0.7` + 10% 平滑幅值偏差 | 4.60% |

**信噪比算一下**：5% 幅值偏差给 3.02%，而 1% 噪声的底是 2.12%、完美谱的
模型误差是 1.67%。净信号约 `3.02 − 2.12 ≈ 0.9` 个百分点，判据线不论怎么定，
都存在"把干净谱判坏"或"把 5% 偏差漏掉"两头堵。这不是调参能解决的。

两端都是感抗端。这跟数据自不自洽没有关系——`AZ3` 和 6 份 `Blank` 是同一份
谱（sha256 全同，见 `M6_VALIDATION_PLAN.md` §13），Z-HIT 给出一模一样的
3.01%；同一条谱的 `AZ3.txt` 与 `Blank_*.txt`（两种导出格式）也逐位一致。

## 5. 根因

一阶近似成立的前提是 `g = d ln|Z|/d ln ω` 在核的等效宽度内**慢变**。
我们的体系（AZ31 腐蚀 / 涂层的低频感抗尾、2E 的高频感抗）在端部让 `g`
变号，前提直接崩。这不是"我们的谱特别坏"，是 Z-HIT 的适用域不含这类谱。

试过更精确的核（离散 Hilbert 矩阵 + Tikhonov 反解 `g`），50 点下正则化
到 `reg=0.1` 仍是 50% 量级误差 —— 反卷积比正演病态得多，这也是 Lin-KK
选择"拟合复阻抗"而不是"反解相位"的原因。

## 6. 唯一还站得住的一点

**整体相位旋转**：1° → 6.58%，2° → 11.23%，且 `trend` 单调（−2.8 / −5.3 %/dec）。
如果哪天怀疑夹具/电缆校准使整条谱转了 1°–2°，Z-HIT 看得见。但谱型本底
就有 3%–16%，**分不开**是校准还是谱型。所以只能当红旗，不能当判据。

红旗也不需要 Z-HIT：Lin-KK 已经有重建阻抗 `Z_pred`，加一个
`phase_resid = angle(Z_pred / Z_obs)` 的统计量就有同样的相位敏感性，
不引入新的模型误差、不加新算法、半小时能做完。**建议走这条，不走 Z-HIT。**

**已落地（同日）**：`bm_kk._phase_resid()` 已接入 `kk_check()`，字段
`phase_resid` 报 `rms_deg` / 分段 `bands` / `trend_deg_per_decade` / `ac1` /
`systematic`。**只记账，不参与分级**（status 的代码路径完全不读它）。
实测：干净谱 `AZ3` 0.14°、`AZ31-4Li_100` 4.04°（低频段 6.86°）。
契约见 `test_contract.py` F10：干净谱 0.0011°；整体旋转 2° → 1.61° 且
`ac1=0.58`（系统性），但幅值中段残差 3.4% 未超阈，**status 仍是 ok** ——
这正是"幅值被 RC 链补偿、相位对不上"那个盲区被单独量出来的证据。

## 7. 顺带发现的数据陷阱

`archive/AZ31-4Li.txt` 是 **6 列**：`index, f, Zre, Zim, Zre, Zim`（后两列重复）。
`bm_real.load_spectrum()` 按无表头 `f, Zre, Zim` 解析 → 把 `index` 当频率，
读出 `n=49, f=1…49 Hz`，Z-HIT 直接给 2588%。

18 条 `.z`（Z60W）导出如果都是这个格式，**必须先转列**再用；`z_csv/` 目录
目前不存在，需要重建（见 §8）。这条与 Z-HIT 无关，但会污染任何"批量跑一遍
真实谱"的结论，记在这里防复发。
