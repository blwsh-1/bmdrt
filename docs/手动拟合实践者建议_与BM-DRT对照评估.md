## 0. 这份材料与前面几轮的定位差异

| 来源 | 关心的问题 | 典型动作 |
|------|-----------|---------|
| B站 UP主「幺的科研路」 | **软件操作与数据处**理流程 | RelaxIS / Nova / EIS Spectrum Analyser / DRT-DCT-RRT、电感修正、低频截尾、出图 |
| 本轮手动拟合实践者 | **拟合结果的物理可信度** | KK 门禁、参数相关性与置信区间、CPE-n 的物理含义、难谱与重复性验证 |
| 我们的 `bmdrt` | **自动定 K + 贝叶斯混合** | DRT 预判给候选区间 → NUTS → 逐点 PSIS-LOO 选 K → 诊断 |

三者不冲突，是同一条链路上的三个不同层次。UP主的材料讲"数据怎么进软件"，
实践者讲"什么情况下根本不该拟合 / 拟合出来的数能不能信"，
我们的代码主要解决第三层"用几个分量、哪个模型更好"。
**实践者的三条主主张恰好全部落在我们架构的前置条件与后置把关上**，所以对照价值很高。

### 原文疑点（不臆断，照录并标注）

- `R_LIICPE`：原文如此，疑似 `R‖CPE`（并联记号 `‖` 被录成 `II`）或 `R_L‖CPE` 的乱码。
  下文按"**高频感抗尾干扰高频弧 R‖CPE 的参数收敛**"理解；若原意不同需向提供者确认。
- `Ws`：本轮把"有限长扩散（Ws）"理解为**有限长度、短路/透射边界**的 Warburg。
  我们代码里 `Ws = W_short = R_W·tanh(z)/z` 正是这个口径，但 `bm_diff.py:32-35`
  特别提醒：`impedance.py` 的 `Ws` 是 tanh，**中文文献里 "Ws" 也常指半无限 Warburg**。
  对外讨论时须先对齐术语。
- "10 mHz 以上"：是实践者给的经验阈值，不是普适常数；真正的判据是
  `f_min` 与转折频率 `f_D = 1/(2πτ_D)` 的相对位置（见 §2.4）。

## 1. 建议原意结构化

| # | 主张 | 背后的理由 | 可操作判据 |
|---|------|-----------|-----------|
| M1 | **先做 KK（线性时不变）校验，再谈拟合** | 谱不满足因果/线性/稳定时，多给元件总能把曲线凑贴合、把残差压下去，但参数没有物理意义 | Lin-KK 残差、μ 判据；不过就停止拟合 |
| M2 | **看参数相关性，不要只看拟合误差** | 高频 `Rs` 与第一个弧的 `R`、`CPE` 的 `Q` 与 `n` 强相关时，误差表上 0.1% 的改善可能只换来参数漂到无意义量级 | 参数相关矩阵 + 各参数置信区间 + 残差图**并列看**，别单看 χ² |
| M3 | **CPE 的 n 不只是拟合数字** | `n` 明显偏离 0.9~1 且随温度/循环系统性变化，往往对应界面不均性或存在第二个时间常数 | 与其再加一个 RC，先上 DRT 看时间常数分布，重叠峰分开后再定 RC 个数 |
| M4 | **低频尾：Warburg 与有限长扩散（Ws）在只看 ≥10 mHz 的数据里几乎不可分** | 有限长扩散的特征弯曲只在 `ωτ_D ≲ 1` 出现；频段不够就只能定出组合量 | 没有更低频点就别用有限长模型去解释 |
| N1 | 难谱：**带感抗的实测谱** | 高频尾巴影响 `R‖CPE` 收敛 | — |
| N2 | 难谱：**两个时间常数贴近的谱**（中频弧叠高频弧） | 容易拟出假弧 | — |
| N3 | 难谱：**加噪数据看参数重复性** | 单次拟合好不代表参数稳 | — |
| M1′ | 无论手动还是自动，**拟合前先过一遍 KK** | 数据不自洽，电路拟得再漂亮也是在拟噪声 | 重复强调，说明这是第一优先级 |

## 2. 逐条对照 `bmdrt` 的代码事实

### 2.1 M1 / M1′「先做 KK，再谈拟合」→ **完全缺失，P0**

**代码事实**：在 `bmdrt/*.py` 中检索 `lin_kk|Lin-KK|Kramers|Kronig|因果|时不变|自洽`，
唯一命中是 `bm_check.py:131` 的注释「A5 DRT 积分重建 Z（与**正演自洽**）」——
那是检验 DRT 公式推导对不对，**不是对实测数据做 K-K 检验**。零实现。
`load_spectrum()`（`bm_real.py:100-188`）之后直接进 `prescreen_stage()`，
中间没有任何数据有效性门禁。

**为什么这一条对我们的架构尤其致命**：

1. 我们的 `select_k()` 用 PSIS-LOO 比较 `K ∈ {K_drt−1, K_drt, K_drt+1}`。
   LOO 是**在同一组似然假设内部**比较模型的相对预测能力，它**不能检验似然假设本身**。
   如果谱因漂移/非因果/非线性而不自洽，所有候选模型都在拟噪声，
   `elpd_loo` 只是选出"最会贴噪声的那个"，相对排序没有物理含义。
2. 多给 HN 分量 = 多给自由度 = 更容易把不自洽的结构也贴住。实践者说的
   "任何电路都能靠多给元件凑贴合"，翻译成我们的语言就是
   **数据不自洽时 K↑ 会持续抬高 elpd**。`select_k` 的简约优先
   （`deficit < max(2, dse)` 取更小 K）只能挡住一部分，挡不住系统性漂移。
3. 最坏情形是 `pool = ok or usable or list(res_list)` 这条降级路径：
   全部模型被硬剔除时仍输出"相对最好"结果。数据不自洽时，它正好把
   "不该拟合"包装成"最佳模型"。这正是实践者警告的场景。
4. 我们自己的代码注释已经写下同一句话：`bm_core.py:61-63`
   > 基底不匹配时 k 会错，而且**阻抗拟合仍然很好**（论文 §4.1.2：
   > "impedance fitting accuracy alone cannot guarantee correct DRT recovery"）。
   > 所以看 k 之前先看基底选得对不对，**不能只看 χ²**。

   `bm_bench.py:323` 也写着「注意：**rms 到噪声底 ≠ 参数对**」。

**现成可复用**：`D:\eis训练数据\AutoECM\validate_fit.py:58-77` 的 `lin_kk()`
（`impedance.py` 的 `fit_linKK` / `get_tc_distribution`，绕过 numpy 2.x 的两个 bug，
判据 `μ < 0.85`，返回实/虚部相对残差）。属 AutoECM 模块，`bmdrt` 从未调用。
接进来需补 `impedance>=1.7`（`requirements.txt` 已把它列为可选）。

**落地建议（P0）**：把 KK 放在 `load_spectrum()` 之后、`prescreen_stage()` 之前，
做成**门禁**而不是"又一个诊断指标"：

```
读入 → [Lin-KK 体检] → 通过? ─否→ 只出 DRT 预判 + 标注「数据不自洽，拒绝定 K」
                          │
                          是 → 电感/低频路由 → K 扫描 → LOO → 诊断
```

输出 `M, mu, res_re(f), res_im(f)` 并落进 `real_<名>.json`。
**注意两个坑**（两份外部材料在这里合流）：

- Lin-KK 的 RC 基底表示不了串联电感 `jωL` 与发散的 Warburg 尾，
  含这两者的谱会被误判为"不满足 KK"。所以要么**先扣 `jωL` / 截低频扩散尾再验**，
  要么按频段看残差（高频端残差归因于 L，低频端归因于扩散），而不是一律拒绝。
  这与 UP主"电感修正不是删点，要扣 `jωL` 把变形圆弧还原"、"低频 45° 尾要截断"
  是同一件事；也与我们之前给的 P1 建议"只在 `prescreen_stage` 给 DRT 预判扣电感"重叠。
- KK 检验的是线性、因果、稳定/时不变、有限性四件事，**不是**"模型对不对"。
  通过 KK 只说明"这条谱值得拟合"，不保证基底选对。

**判断**：这是本轮唯一一条"我们没有、且必须补"的建议。
我们之前《算法链路与数据预处理必要性评估.md》把问题定性为
"不是预处理做得不够，而是**错配**"；这份材料把边界再往上推了一层：
**比模型错配更靠前的是数据本身不自洽**。正确的优先级顺序是

> **KK → 电感/低频路由 → 基底与扩散项 → K → 参数可辨识性**

### 2.2 M2「看参数相关性、置信区间、残差图，别只看 χ²」→ **部分满足，P1**

**已经做得比较扎实的部分**：

| 实践者要求的三件套 | 我们的对应实现 |
|-------------------|---------------|
| 各参数置信区间 | `bm_real.py:815-823`：每个分量 `f_τ`、`w` 的 **90% 区间**（`np.percentile(...,5/95)`）；`bm_real.py:853` 的 `φζ` 区间；`bm_circuit.py:335-336` 电路图上标 5–95% 区间 |
| 参数相关性 | `bm_real.py:856` 的 `corr(lnR,lnτ)` + `ridge_ratio`；`bm_diff.py:328` 的 `np.corrcoef`；`bm_real.py:290-293` 用 `np.cov` 特征值找"定得最死的方向" |
| 残差图 | `plot_real()` 的 2×3 诊断图含 `residual Re/Im`，虚线标后验 σ（`bm_real.py:1110-1111`）；文字侧 `bm_real.py:893-905` 给 acf、蒙特卡洛零分布分位、平滑趋势 σ、按 `log f` 三分的残差分段表；`bm_real.py:610` 的 PPC 覆盖 |
| 收敛诊断 | `bm_real.py:806-810`：rank-normalized split R̂ / bulk & tail ESS / `Z(f)` 跨链 |

而且 `bm_real.py:280-293` 已经明确写下"**只看 corr 不够**"：
`corr=+0.999` 只说明有脊线，还得看脊线宽度与特征方向，
实测 `C_D = τ_D/R_W` 被定到 ±0.3%，所以"R_W 与 τ_D 可分"这种话不能只看相关系数就说。
这比实践者提的判据更进一步。

**仍然缺的部分**：

1. **没有全参数相关矩阵 / 热图**。代码只算了特定的两两相关
   （HN 的 `lnR↔lnτ`、扩散项的 `lnR_W↔lnτ_D`），没有对
   `R_inf, W, {lnτ_k, φ_k, ζ_k, v_k}, L, σ_re, σ_im` 做一次完整的
   `np.corrcoef`。实践者点名的 "`Rs` 与第一个弧的 `R`" 在我们口径里是
   `R_inf ↔ w_1`，没有系统报；也没有把 `|corr| > 0.95` 写成 warning 或进 `select_k` 的硬筛选。
2. **参数化不同，病没有消失，只是换了名字**。我们不是显式 `Q, n`，而是
   HN 的 `τ, φ, ζ` 与 stick-breaking 权重。`R‖CPE` 的 `Z = R/(1+(jω)^φ Q R)`
   对应 `τ^φ = Q·R`，所以 `Q` 与 `n` 的强相关在我们这里表现为
   **`w`、`τ`、`φ` 三者的简并**。`bm_core.py:48-50` 特意用 `w_k = W·π_k`
   去掉了一个不可辨识的冗余方向，但剩下的简并仍要报出来。
3. 后验样本已保存在 `real_<名>_samples.npz`，所以**全相关矩阵可以离线重算，
   不必改似然、不必重跑 NUTS**。

**落地建议（P1，成本很低）**：在 `report()` 里加一张全参数相关热图
（取对数参数、先按 `f0` 降序对齐解决标签交换），并把
「任何 `|corr| > 0.95` 的参数对」和「90% 区间跨超过 1 个数量级的参数」并列输出；
再写一个后处理脚本，对已有 117 条 `*_samples.npz` 批量补算，
直接回答实践者那句"0.1% 的误差改善换来参数漂到什么量级"。

### 2.3 M3「CPE 的 n 不只是数字；先 DRT 再定 RC 个数」→ **架构已对齐，但有一处重要反转**

**完全一致的那一半**：`drt.py:1-18` 开宗明义：
> `num_peaks` 特征判别力为零（互信息 6.2%），因为在 `log10(-Im)` 上拾峰
> 遇到压扁的弧（n 小）、重叠弧、CPE 尾巴就失效；
> **DRT 把"到底几个 RC"变成一个良态的反卷积问题**。

`bm_real.py:11-27` 的三层分工更把它写成硬约定：DRT 只产
「有几个峰 / 峰位 / 边界堆积与重叠程度」，给 **K 的候选范围**和 **NUTS 初值**，
不决定 K、不当额外观测、不进似然。`bm_real.py:925` 的 `judge()` 也写了
「先查是否缺项（Warburg / 电感 / 多孔扩散），**而不是加 K**」——
与实践者"与其再加一个 RC，不如先看分布"是同一判断。

**反转的那一半（必须记下来）**：实践者说"重叠的峰在 DRT 里分开"，
这是理想情形；**贴近到 3 倍以下时 DRT 自己也会并峰**。
`bm_real.py:29-35` 记了一个实证：

> `examples/example_caseF.csv`（真值 2 个 ZARC + 电感）
> 在 `λ=17` 下把**相距 3 倍的两个峰合并成一个**，`K_drt=1`；
> 若照 `K_drt` 拟合，`rms/σ=0.95`、PPC 覆盖 0.90 —— **所有常规指标都"合格"**，
> 只有残差 `acf=0.70` 暴露漏了一个过程。
> 「DRT 定 K + 常规拟合指标，会把**欠拟合**判成**通过**。」

原因在 `drt.py:29-30` 与 `drt.py:168-171`：λ 由"残差比准则"自动选，
强正则化必然压掉近邻峰，而 λ 不能手调（"手调就是在调结论"）。
`bm_bench.py` 的 B 组（间距 3×）、C 组（间距 1.5×）就是专门造出来测这件事的。

所以正确的落地不是"信 DRT 峰数"，而是
**DRT 只给区间 `[K_drt−1, K_drt+1]`，让逐点 LOO 去定**（`bm_real.py:25` 已经这么做）。
在这个具体问题上，我们的架构比"DRT 数峰 → 手搭 RC → 拟合"更稳健。

**还缺的一块（P1，分析层）**：实践者强调 `n` 要**随温度/循环连起来看系统性漂移**。
我们这边 `φ`（`ζ=1` 时 ZARC 等价 `R‖CPE`，`φ ≡ n`）有单点后验区间，
`bm_core.py:54-57` 也提醒 `φζ>1` 时 DRT 出现负值、`w` 不能再当峰面积，
`select_k` 会把 `φζ>1` 超阈值的模型淘汰。但 `batch_2e.py` 的 117 条谱是
**逐条独立拟合**，没有把 `φ` 按电流密度 / 循环数连成趋势线。
补一个后处理脚本即可，不用改算法。

### 2.4 M4「Warburg 与 Ws 在只看 ≥10 mHz 的数据里几乎不可分」→ **代码里已有数学证明与实测数字，无需改算法**

**数学依据（我们自己的代码里就写着）**：`bm_diff.py:39-42`

```
W_open  (coth): ωτ_D ≫ 1 → A_W (jω)^(-1/2)      ← 半无限 Warburg 尾
                ωτ_D ≪ 1 → R_W/3 + 1/(jωC_D),  C_D = τ_D/R_W
W_short (tanh): ωτ_D ≫ 1 → A_W (jω)^(-1/2)      ← 完全相同的半无限尾
                ωτ_D ≪ 1 → R_W
```

`bm_diff.py:503-511` 有自检 `[3] W_open/W_short 高频尾 / Warburg`，并注明
「必须在 `ωτ_D ≫ 1` 的渐近区测（`f = f_D` 时 `|z|=1`，`coth(1)/1=1.31`，差 4%）」。
也就是说：**有限长模型的"特征弯曲"只在 `f ≲ f_D = 1/(2πτ_D)` 才出现**；
测不到那个频段，`R_W` 与 `τ_D` 沿脊线完全简并，数据只能定出组合量
`A_W = R_W/√τ_D`（对 `Wo` 则是 `C_D = τ_D/R_W`）。

**代码里的实测**：`bm_real.py:228-230` 记 `corr(lnR_W, lnτ_D) = +0.999`，
「定得最死的是 `C_D = τ_D/R_W`（±0.3%），引用 `R_W` 时必须同时说明它与 `τ_D` 的相关性」；
`bm_real.py:280-293` 补了"只看 corr 不够，要看脊线宽度与特征方向"。

**我们这批数据的具体情况（本轮现场核实）**：
`EISmeasurements/csv_2e/` 下 118 个 CSV、6552 个频率点，
**`f_min = 1.002 Hz`，`f_max = 1.002×10^5 Hz`**（5 个数量级，每条 56 点）。
比实践者说的 10 mHz 还**高 100 倍**。
所以在这 117 条谱上，`W_inf` / `Ws` / `Wo` 的高频尾本来就相同，
而能区分它们的低频弯曲段完全在测量窗口之外——
**M4 对这批数据不是"提醒"，是硬约束**。

**与我们之前结论的关系**：《低频数据是否用DCT_结论.md》给出
"不引入 DCT，应把 `diffusion = none / Ws / Wo` 纳入同一套 LOO 模型比较"。
M4 给这个建议补了一个**前置条件**：没有更低频点时，
`Ws/Wo` 对照本身也没有分辨力，三者 LOO 分不出差别时应当**明确报告"不可分"**，
而不是照常选出一个"最优"。
落地（P1，在 `select_k` 里加，不改似然）：当 `diffusion ∈ {Ws, Wo}` 且
`p_diff_small` 高 / `corr(lnR_W,lnτ_D) > 0.95` / `ridge_ratio` 偏低时，
把该维度降级为"等价"，并在报告里写
「频率窗口 `f_min=1 Hz` 不足以区分有限长扩散，仅报告组合量 `A_W` 或 `C_D`」。

**术语校正（对外沟通时很有用）**：`bm_diff.py:32-35` 明确写
「`impedance.py` 的 `Ws` 是 tanh（有限长、透射），**不是**半无限；
中文文献里 "Ws" 也常指半无限」。
本轮材料的"Warburg 和有限长扩散（Ws）"与我们代码口径一致
（`W_inf` vs `W_short`），但换成 `impedance.py` 或中文文献语境要先确认。

### 2.5 三类难谱 → `bm_bench.py` 已逐一对上，但 N3 有实质缺口

| 实践者的难谱 | 我们的对应 | 代码事实 |
|-------------|-----------|---------|
| **N1 带感抗的实测谱**（高频尾影响 `R‖CPE` 收敛） | `bm_bench.py` **F 组**：`2×ZARC + L`，拟合时 `include_L=False`（故意缺项） | `detect_L()`（`bm_real.py:191-194`）取最高 3 点投票自动开 L；117 条谱中 **108 条自动启用 L**；`drt.py:27-28` 提醒"电感给出负 γ，非负约束把它压成 0，贡献被 `R_inf` 吸收 → **Rs 会被高估，DRT 的 `R_inf` 不能当 Rs 用**"；`convert_2e.py:22-23` 说明虚部符号翻错会让 L 判反。本轮现场抽查 `2EMC1-1_0005mA.csv` 最高频点 `Zim=+0.0388`（正 = 感抗尾），与 N1 完全对应。 |
| **N2 两个时间常数贴近**（中频弧叠高频弧 → 假弧） | `bm_bench.py` **B 组**（间距 3×）、**C 组**（间距 1.5×） | `bm_real.py:31-35` 的 caseF 并峰实证；`drt.py:29-30` λ 决定峰数；`bm_real.py:836-865` 的退化检查用"峰位出窗 + `φζ` + 脊线比"识别假弧 |
| **N3 加噪数据看参数重复性** | `bm_bench.py` **G 组**（相对噪声 0.5%）、**H 组**（窄窗口）；`bm_ident.py` 的 C1/C2/C3（无噪 / 有噪 / ζ 钉死，多起点最小二乘）；`bm_real.py:425-453` 的 `null_thresholds()` 蒙特卡洛零分布 | 见下方缺口分析 |
| **M1′ 无论手动还是自动，拟合前先 KK** | 无 | 见 §2.1 |

**N3 的实质缺口**：现有实现都是 **"单次噪声实现 + 多起点 / 多 K / 多零分布样本"**，
**不是"跨噪声实现的参数重复性"**：

- `bm_bench.py:79-87` 每个 case 用固定 `seed=0` 造一次噪声
  （`add(name, f, Ztrue, comps, sigma_vec, seed=0, ...)`）；
  `map_fit()` 的 `n_start=16` 是**多起点**，不是多个噪声实现。
- `bm_real.py:67` 的 `KW` 里 `seed=0` 也固定，NUTS 每次同种子。
- `null_thresholds()` 的 `n_rep=2000` 重采样的是**残差统计量零分布**，
  不是"换一锅噪声再拟合一遍"。

所以"同一真值、不同噪声实现下，参数散布多大 / 区间是否覆盖真值 /
0.1% 的误差改善对应参数漂多远"这件事**没有系统统计**。
实践者把它列为独立一类难谱，是对的。

**落地建议（P1，纯测试脚本，不动算法）**：在 `bm_bench.py` 外加一个 rep 循环，
对 A/B/C/E/F/G 组各跑 `seed = 0..19`，报每个参数的 `mean ± sd`、
90% 区间覆盖率与真值偏差；特别看 B/C 组（贴近时间常数）与 F 组（缺 L）在
噪声扰动下 `f0`、`φ` 会不会跳到另一个局部解。这正好量化 M2 那句
"0.1% 的改善可能只换来参数漂到无意义的量级"。

### 2.6 最根本的一条推论：KK 与 LOO 的分工

把 M1 翻译成我们架构的语言，是这份材料最有价值的产出：

> **PSIS-LOO 只能在"似然假设成立"的前提下比较模型。**
> 数据不自洽时，K 增大 = 自由度增大 = 更容易贴住噪声，
> `elpd` 会系统性偏向更大的 K；再丰富的**事后**诊断
> （acf / 趋势 / PPC / 峰位 / 脊线 / R̂ / ESS，我们全都有）
> 也只能提示"拟合得怪"，不能回答"这条谱该不该拟合"。

我们之前把 `select_k` 的问题归结为
「数据有效性/结构问题被推到模型层，最后被降级路径输出成模型结论」
（《算法链路与数据预处理必要性评估.md》）。
现在可以补完整链条：

```
数据不自洽（KK 不过）
   ↓ 没有门禁，直接进流程
高频 L / 低频扩散尾被模型层吸收（108/117 自动加 L；低频全靠 HN 硬扛）
   ↓
DRT 预判在强正则化下并峰 / 端部堆积 → K 候选区间偏移
   ↓
LOO 在不自洽数据上比 K → 偏向"更会贴噪声"的模型
   ↓
select_k 降级路径仍输出"相对最好" → 得到一组漂亮的、没有物理意义的参数
```

**KK 是事前门禁，其余全是事后诊断；把诊断做得再好也替代不了门禁。**
