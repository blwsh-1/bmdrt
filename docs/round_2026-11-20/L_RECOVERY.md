# L 可恢复性验证（2026-11-20）

**要回答的问题**：三族接入 `include_L` 之后，除了"能跑通"，能不能在**真值含 L** 的谱上
把 L 恢复出来、并且明显优于不带 L。没有这一步，`include_L` 只是多了一个参数。

**脚本**：`docs/round_2026-11-20/l_recovery.py`（一条命令可复现）
**产物**：`out/l_recovery.json`

## 1. 设计

- 真值：`Z = R_inf + jωL + Σ HN`，`R_inf=20 Ω`、`HN(W=120 Ω, τ=2e-3 s, φ=0.85, ζ=1)`、
  **`L=3 μH`**；`f ∈ [0.01, 1e5] Hz`，50 点；
- 噪声：`1%·|Z|` 的相对复高斯（seed=0，一次生成，不重抽）；
- 对照：同一条谱分别用 `include_L=True / False` 拟合三族（voigt K=1、nested L=1、adr）；
- 预算：`quick`，`likelihood=free`。

**预注册判据（跑之前写死，结果不改判据）**

| 编号 | 判据 |
|---|---|
| L1 | `need_L(f, Z)` 判 True（否则 auto 根本不会开 L） |
| L2 | 带 L 的 rms 相对降幅 ≥ 30% |
| L3 | L 后验中位落在真值 ±50% 内 |
| L4 | 不带 L 时**高频段**（100–1e5 Hz）rms 至少差 1pp |

## 2. 结果

| 族 | include_L | rms_rel | acf | L 中位 | R̂ | div |
|---|---|---|---|---|---|---|
| voigt | True | **0.649%** | 0.210 | 2.29 μH | 1.010 | 0 |
| nested | True | **0.729%** | 0.158 | 2.14 μH | 1.069 | 0 |
| adr | True | **0.732%** | 0.179 | 2.26 μH | 1.021 | 2 |
| voigt | False | 1.363% | 0.179 | — | 1.004 | 0 |
| nested | False | 1.376% | 0.170 | — | 2.603 | 9 |
| adr | False | 1.378% | 0.177 | — | 1.022 | 0 |

`need_L = True`。

## 3. 判据核对

| 判据 | voigt | nested | adr |
|---|---|---|---|
| L2 rms 降幅 ≥30% | 52.4% ✓ | 47.1% ✓ | 46.9% ✓ |
| L3 L 恢复 ±50% | 2.29 μH ✓ | 2.14 μH ✓ | 2.26 μH ✓ |
| L4 高频段差 ≥1pp | 1.18pp ✓ | 1.17pp ✓ | **0.99pp ✗** |

**9/10 通过**。未过的是 `adr` 的 L4：0.99pp，差 0.01pp 未到 1pp 线。

## 4. 怎么读

- **接入是真的**：三族都能在真值含 L 的谱上把 L 恢复到 **2.1–2.3 μH**（真值 3 μH，
  偏低约 25%，同向同量级），且带 L 比不带 L 的 rms 低约一半。L 不是摆设。
- **L3 的系统性偏低**（三族一致地落在 2.1–2.3 而不是 3.0）：这是 1% 噪声下
  `L` 与高频段 `R_inf`/CPE 尾的弱简并，不是接法错误。**不据此修正先验**——
  要判断这是偏差还是抽样，需要多 seed 重复（本轮只 1 个 seed，不下结论）。
- **`adr` 的 L4 未过按未过记**：0.99pp 与阈值 1pp 实质等价，但预注册线是 1pp，
  不改阈值、不重抽 seed 去凑。它的 L2（46.9%）与 L3（2.26 μH）都过，说明
  "该族能用 L"这件事成立，只是高频段的判别力比另两族弱一点点。
- **边界没变**：`nested` 不带 L 时 R̂=2.603、div=9（欠拟合导致后验病态），
  带 L 后 R̂=1.069 —— 这条谱也顺带说明"该加 L 而不加"会让采样本身变差。
