# 先验定标的隔离验证：主线没被污染，"改先验"这条线两半都被证伪

> 触发：`RINF_PRIOR_DIAGNOSIS.md`（11-21）证明 `R_inf` 先验中心用错了参照量，
> 但那次证据来自 `zmax_override = 5·|Z(f_max)|`，它会**同时**缩放 `W`/`Q`/`R1`
> 的先验（诊断 §6 自己写"那是运气，不是设计"）。所以诊断 §6 提出的最小修法
> **从未被真正测过**。本文补上这个实验，并顺带把 `R_ad`/`tau_ad` 的先验宽度一起测。
>
> 脚本：`docs/round_2026-11-22/prior_calibration_probe.py`（`audit` / `az31` / `real` / `b2`）
> 全部走生产代码路径，harness 侧只 monkey-patch `bm_top._prior_table`，`bm_*.py` **零改动**。

## 0. 一句话

**不要改这两条先验。** 主线（§13/§14）的 `Rs` 先验确实偏了 2.3–3.3σ，但把参照量改对之后
`rms`/`acf` 几乎不动（≤0.06pp / ≤0.014）；`R_ad`/`tau_ad` 的 σ 收窄后 R̂ 反而从 1.10 变 1.20。
真正被证实的问题只有一个：**`Rs` 在这些谱上不可辨识，报值随先验中心移动 2 倍**——那是报告问题，不是判定问题。

## 2. 一个诱人但错误的推断

把所有 AZ31 的 σ距按谱列出，与 §13/§14 的通过情况对照：

| 谱 | σ距 | 在哪个集 | 结果 |
|---|---|---|---|
| AZ31-4Li_50 | **+3.28** | §14 | 未过 |
| AZ31-4Li_150 | **+3.19** | §13 | 未过 |
| AZ31-8Li_150 | **+3.01** | §14 | 未过 |
| AZ31-4Li_10 | +2.33 | §14 | 未过 |
| AZ31-8Li_100 | +2.26 | §13 | 未过 |
| AZ31-8Li_50 | +1.85 | §14 | **过** |
| AZ31-8Li_10 | +1.79 | §14 | **过** |
| AZ31-12Li_50 | +0.68 | §14 | **过** |
| AZ31-12Li_10 | −0.29 | §14 | **过** |
| 其余 6 条 | −1.02 … +1.60 | §14 | 未过 |

**看起来极整齐**：σ距 ≥ 2.33 的 3 条全失败，4 条通过的全在 ≤1.85；
加上 §13 的 `4Li_150`（3.19）与 `8Li_100`（2.26），"先验卡住主线验收"这个假设很诱人。

**但这个推断是错的**，见 §3。它错在把"σ距大"与"该谱难"混为一谈——
两者都随动态范围上升，是共同原因，不是因果。

## 3. 主线验收集：改对参照量之后，什么都没变

预算 = §14 档（2000/1000/2 链/ta 0.98），口径 = F1（逐样本 Z 的逐点中位），seed 0。
只改 `Rs` 的先验中心（`0.2·zmax` → `0.5·|Z(f_max)|`），σ 仍 1.0。

| 谱 | σ距 | rms%（基线 → 改后） | acf（基线 → 改后） | `Rs`（基线 → 改后） |
|---|---|---|---|---|
| AZ31-4Li_50 | +3.28 | 7.78 → **7.79** | 0.687 → **0.701** | **1.741 → 0.891** |
| AZ31-4Li_150 | +3.19 | 6.43 → **6.42** | 0.403 → **0.404** | **4.925 → 2.290** |
| AZ31-8Li_150 | +3.01 | 5.91 → **5.94** | 0.778 → **0.779** | 14.63 → 14.64 |
| AZ31-4Li_10 | +2.33 | 10.35 → **10.29** | 0.744 → 0.744 | 44.46 → 44.47 |

`R̂` 四组全部 1.002–1.006、`div=0`——两种配置都收敛，比较是有效的。

**结论一：主线没有被这条先验污染。** rms 变化 ≤0.06pp，acf 变化 ≤0.014，
判定（rms≤5、acf≤0.50）一条都不会翻。§13 的 0/3 与 §14 的 4/14 **不需要因先验重跑**。

**结论二（真正的问题）：`Rs` 在这两条谱上不可辨识。** 4Li_50 的 `Rs` 从 1.741 变到 0.891
（2×），4Li_150 从 4.925 变到 2.290（2.15×），而 rms 一模一样。
说明高频端几乎不含 `Rs` 的信息（`Rs` 只占 `|Z(f_max)|`=25 Ω 的 4–8%，且与 `L` 的高频感抗混在一起），
后验位置由先验决定。**这直接影响 `Table 1` 报的 `Rs+R1`**——那是报告口径问题，不是拟合失败。

## 4. 合成极端谱：改善不单调，不能一概而论

`quick` 档（只看方向，不作判定；单链，R̂ 不可靠），同样只改 `Rs` 参照量：

| 谱 | σ距 | 基线 rms / acf / R̂ | 改后 rms / acf / R̂ |
|---|---|---|---|
| 钝化 | **+10.21** | 6.75 / 0.746 / 30.7 | **5.11 / 0.378 / 1.019** |
| 腐蚀 | +7.26 | 5.46 / 0.412 / 1.91 | 5.50 / 0.429 / 7.49 |
| 涂层 | +3.18 | 7.91 / 0.738 / 104.0 | 9.59 / 0.791 / 22.9 |

- **钝化（10.2σ）明显改善**：rms 6.75→5.11、acf 0.746→**0.378**（过线）、R̂ 30.7→1.02。
  这是唯一一条"先验确实是瓶颈"的证据。
- **腐蚀（7.3σ）无变化**：5.46→5.50。先验中心 `0.2·zmax` = 1.66e6 Ω，
  而拟合到 `Rs`=1011 Ω（与 `|Z(f_max)|`=1167 Ω 同量级，物理上对）——
  **后验落在先验下方 7.4σ 处，似然照样赢**。所以"σ距大"不等于"先验会卡住"。
- **涂层（3.2σ）反而变差**：7.91→9.59。

所以 11-21 诊断 §8 那个"腐蚀 298.5% → 6.04%"的改善**不是这条最小修法带来的**：
那次 `fixed` 用的是 `zmax_override`，`Q1`/`Q2`/`W`/`R1` 的先验跟着缩了，真正的杠杆在那边。
**诊断 §6 提议的"只改 `R_inf` 参照量"不足以复现 §4 的 50 倍。**

## 5. `R_ad`/`tau_ad` 的 σ：收窄反而更差，且这个指标不足以调先验

B2 `nested_L2_L`（§14 式 standard 预算，2 链），四种先验配置：

| 配置 | R̂_max | ESS_min | `R2` | `R_ad` | `tau_ad` | ρ(log`R2`, log`tau_ad`) |
|---|---|---|---|---|---|---|
| 基线 | 1.1005 | 12 | 198.34 | 10.4 | 5.4e-4 | −0.54 |
| **只收 ad σ→0.5** | **1.2005** | 7 | 197.92 | 27.6 | 1.39e-4 | **−0.89** |
| 只改 Rs 参照量 | **1.5370** | 4 | 197.64 | 7.55 | 1.79e-3 | −0.58 |
| 两者都改 | 1.2615 | 6 | 197.89 | 27.5 | 1.34e-4 | −0.93 |

- **收窄 σ 没有解决 R̂**（1.1005 → 1.2005），反而把相关从 −0.54 拉到 −0.89：
  先验一窄，`R_ad`/`tau_ad` 都被拽到各自中心（27.6 ≈ 0.1·zmax=35 一侧，1.39e-4 ≈ 1/w_ref=1.59e-4），
  脊变紧但链条照样不碰头。
- **"只改 Rs 参照量"这一行把问题暴露了**：`Rs` 的中心只动了 0.59σ（70.6→39.1 Ω），
  R̂ 就从 1.1005 跳到 **1.5370**（ESS 4）。这说明在这个预算下，**该配方的 R̂ 不是先验的稳定函数**，
  1.10/1.20/1.54/1.26 之间的差被"平方向上的随机落点"主导。

⇒ 用 R̂ 来给先验定标是**方法错了**：它信噪比太低（上一轮已算出要 ~14 个 seed 才能把偏置压到 0.3%）。
真要做，得先多 seed，或者直接按物理量纲定标，而不是拿 R̂ 当目标函数。

## 6. 结论

| 项 | 判定 |
|---|---|
| `Rs`/`R_inf` 参照量（`0.2·zmax` vs `0.5·|Z(f_max)|`） | **偏了，但不改**。主线 rms/acf 不受影响（§3）；合成类非单调（§4）；改它只会移动 `Rs` 报值 |
| `R_ad`/`tau_ad` 的 σ（2.0 → 0.5） | **不改**。R̂ 更差，且该指标不足以判断（§5） |
| §13 的 0/3、§14 的 4/14 | **不需要因先验重跑**（§3） |
| `Rs` 在低 `|Z(f_max)|` 谱上不可辨识 | **新问题，单列**：`Rs` 报值随先验 2 倍移动，`Table 1` 的 `Rs+R1` 必须注明"`Rs` 由先验定位" |
| 11-21 诊断 §8 的"50 倍改善" | **归因要改**：来自 `zmax` 同时缩放 `W/Q/R1`，不是 `R_inf` 参照量本身 |

**本轮不改任何生产代码**，`bm_core` / `bm_top` 一行未动，`entry_parity` 207/207 守着。

## 7. 真正该做的（按性价比）

1. **`Rs` 的不可辨识要报出来**（零成本）：在 `Table 1` / 结果层标注 `Rs` 的定位来源，
   别把"先验定位的 `Rs`"当测量值。判据里 `Rs` 本来就不是 target 的话，这一条只是文档。
2. **`R_inf` 参照量留给 voigt 单独测**：本文只覆盖 nested/adr（`_prior_table` 有表可 patch）；
   voigt 的 `R_inf` 在 `bm_core.make_model` 内部，要测必须改生产模块。若将来做，
   应当在 **voigt** 上做（11-21 的 110%→7.65% 全是 voigt K=1），不在 nested 上做。
3. **不要用 R̂ 做先验调参**（§5）。要判先验好坏，用"偏差均值 + 多 seed se"（`B2_BIAS_ATTRIBUTION.md` 的工具）。

## 9. 边界

- `az31` / `real` / `b2` 都是 **seed 0、单次**。§3 的结论（rms/acf 不变）在 4 条谱上一致，
  但每条只有一个 seed；acf 的 seed 波动在 11-22 的口径轮里测得 ≤0.02，远小于本节要看的差。
- `real` 用 quick 档 + 单链，`R̂` 列（30.7 / 104 / 1.02）**不可作为判定依据**，
  只看 rms/acf 的方向。
- 只 patch 了 `_prior_table`（nested/adr）。voigt 的 `R_inf` 未覆盖，结论不适用于 voigt。
- 没有做多 seed，也没有做 `Rs` 固定的对照拟合（`fit_top` 没有固定参数的入口）。
