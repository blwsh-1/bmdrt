# §14 曲线口径双报：实测与结论（2026-11-22）

> 先改执行器，再跑正式档，最后回答"F1 该不该作主判据"。
> **结论先说：判定一条没变（§14 4/14、§13 0/3），但报告值必须改。**

## 1. 为什么

`BMDRT_RESULT_AND_FIGURE_DESIGN.md` 的 **F1 契约**（2026-11-20 冻结）规定：

> 曲线 = **逐样本算 Z，再逐点取中位**。

而 §14 执行器 `m4_holdout2.py` 一直是 `Z(中位参数)`。`Z(θ)` 对 θ 非线性
⇒ `Z(median θ) ≠ median Z(θ)`，两者不是同一件事。

三个后果：

| # | 后果 |
|---|---|
| 1 | `out/m4_holdout2.json`（**2026-11-10**，`4/14` 的来源）是**旧口径** |
| 2 | 该产物**既没落 `z_fit`、也没落后验** ⇒ 无法只读重算，只能重跑 |
| 3 | 2026-11-20 之后 `circuit_runner` 已改 F1 ⇒ `compare` 的产物与 §14 不可直接比 |

## 2. 改了什么

只改"曲线怎么算"，**判据一个没动**（`RMS_MAX=10 / ACF_MAX=0.50 / ACF_DROP=0.20 / RHAT_MAX=1.05`）。

| 字段 | 口径 | 说明 |
|---|---|---|
| `rms_rel` / `acf` / `verdict` | 旧（`Z(中位参数)`） | **算法逐位不变** ⇒ 既有 `4/14` 仍可复现 |
| `metrics_f1` / `verdict_f1` | F1 | 并列报出、**不替代** |
| `z_fit` / `z_fit_f1` | 两条曲线 | 50 点 re/im 进 JSON ⇒ 以后口径再变可**只读重算** |
| `voigt_base.metrics_f1` | F1 | M-b 是"比 voigt 低 ≥0.20"的**跨族差**，两族必须同口径 |
| `state_f1` / `passed_all_f1` | — | 逐谱聚合 |
| npz（`--save-posterior`） | 两套 | 增 `rms_rel_f1` / `acf_f1` / `z_fit_*` |
| `meta.curve_policy` | — | 明写两套口径与"verdict 用 legacy" |

F1 实现**复用** `circuit_runner._pointwise_median_z`（`circuit_runner.py:453`）——F1 的唯一实现，抄一份必然漂移。§13 的 `m4_holdout.py` 同样改了（它的指标键是 `acf_max`，按其自身结构并列）。

`M6_VALIDATION_PLAN.md §14.6` 已记**变更 3**。

## 3. 实测（正式档 2000/1000/2/ta0.98）

### 3.1 判定：一条没变

| 集合 | 旧口径 | F1 口径 | 通过的是不是同一批 |
|---|---|---|---|
| **§14 全量 14 条** | **4/14** | **4/14** | **是**：`8Li_10`、`8Li_50`、`12Li_10`、`12Li_50` |
| **§13 留出 3 条** | **0/3** | **0/3** | 是（都空集） |

与封存记录对齐：§14 的 `M-a(rms) 8/14`、`M-b(acf) 4/14`、`M-c(R̂/div) 12/14` 也一并对上；
达到 §14 的仍是 `_10/_50` 中段状态，`_0/_5/_150` 全灭。

### 3.2 但报告值有三处必须记住

| 谱 | 旧口径 | F1 | 读法 |
|---|---|---|---|
| `AZ31-12Li_5` | rms **30.80%** / acf 0.896 | rms **5.86%** / acf 0.713 | 该谱 **R̂=22.07、div=1、ESS=1** ⇒ 后验根本没收敛，中位参数落在无意义处；F1 逐样本中位对多峰稳健。**两者都判未过**（acf>0.50、M-c 不过），但 rms 差 5 倍 |
| `AZ31-4Li_150` seed1 | acf 0.529 | acf **0.503** | 距 0.50 只差 **0.003**，且"低于 voigt 0.216≥0.20"已满足 ⇒ **处于翻转边缘**，不得宣称通过 |
| `AZ31-8Li_5` | acf 0.505 | acf 0.504 | 仍不过（差 0.004） |

其余 11 条 §14 谱：两套 acf 差 **≤0.02**、rms 差 **≤0.07 pp**。

### 3.3 顺带解开一个悬案

`TOPOLOGY_AUDIT.md` 记过"§14 记 rms 30.80% 而本轮复现 5.86%（R̂ 相同），**无法判定**因 §14 未落 `z_fit`"。

现在能判定了：**30.80% 是旧口径、5.86% 是 F1 口径**，不是两次跑出不同结果。

## 4. 结论：F1 该不该作主判据

- **判定层面：无所谓。** 4/14、0/3 两套完全相同，换口径不动任何结论。
- **报告层面：必须优先 F1。** 旧口径在未收敛后验上会给出 30.8% 这种无意义数字，
  而这类谱恰恰就是"采样不过"的谱 —— 用中位参数描述一个多峰后验，本身没有意义。
- **建议**：判定仍以 legacy 报（与既有 `4/14` 可比、不追溯改结论），
  **报 rms/acf 时优先 F1 并注明口径**。若要正式换主判据，需 §14.6 再记一条变更 4，
  并说明 `4/14` 的替换关系（当前结论是不需要换）。

## 6. 边界

- §14 是**单 seed（0）**、§13 是两 seed；跨 seed 的稳定性不在本轮范围。
- 冒烟（`100/100/1`）与正式档的差异量级不同，冒烟数字只用于验证管线。
- `AZ31-4Li_150` 的 0.503 说明**判据在临界点附近的稳定性不足**：换 seed / 换口径
  都可能翻。这不是"F1 更好"，是"这条谱本来就卡在线上"。
- 重跑用的是当前 `registry 0.8.0`；`candidate_id` 与 11-10 那次是否逐位相同未核（拓扑定义未变，预期相同）。
