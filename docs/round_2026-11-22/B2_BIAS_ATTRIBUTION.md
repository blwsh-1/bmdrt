# B2 的「`L` 系统性正偏」是假的 —— 一个共享噪声实现，不是模型偏差

> 触发：这句话**不在 `B2_REPORT.md` 里**，而是 2026-11-21 复盘时在下结论处写下的
> 「跨 3 配方 `L` 的 90%CI 全部不含真值（+1.4/+1.9/+2.0%）⇒ 方向一致的系统正偏；
> 1 seed 分不开『噪声实现』与『模型偏置』」。`B2_REPORT.md` §5 只保留了后半句的
> 谨慎措辞。本文补上那一步，**结论：偏置不存在，判定不用改。**
>
> 脚本：`docs/round_2026-11-22/b2_bias_attribution.py`（只读，除 `--mcmc` 外不跑 MCMC）

## 0. 一句话

`+2.0% / +1.9% / +1.4%` 不是三次独立观测，而是**同一次**噪声实现被三个配方各自投影一次；
它在各自的后验里都位于 **+2.0～2.5σ** 处，方向、量级都能由该噪声实现经 Fisher 信息
**无拟合参数地**算出来。偏置的解析均值为 **0（＜0.02%）**。

## 1. 三条结论

| # | 结论 | 依据 |
|---|---|---|
| 1 | 三个配方的噪声实现**逐位相同**，因此"3/3 全正"只有 1 个独立抽样 | 标准化残差最大差 ≤1.2e-14（浮点舍入级） |
| 2 | 那一个实现足以**定量**预报三个 `+Δ`：预报/实测 = 1.07 / 1.00 / 1.04 | Laplace（Fisher）一阶位移 |
| 3 | 解析重抽 4000 个实现的均值为 **−0.02 / −0.01 / −0.01 %**，正负各半 | `P(Δ>0)` = 49.8 / 49.6 / 49.0 % |

⇒ **不存在需要修的系统性错误。** `B2_REPORT.md` §5 那句"方向一致的系统偏移"应撤回为
"一次抽样 + 三配方共用同一次抽样"。

## 2. 为什么会"3/3 全正"—— 读代码就能看出来

`b2_baseline.generate()` 对每个配方都执行同两步：

```python
rng = np.random.default_rng(int(rec["seed"]))     # 所有配方都是 seed=0
nz = sigma[0]*rng.standard_normal(f.size) + 1j*sigma[1]*rng.standard_normal(f.size)
```

`f.size` 都是 61、seed 都是 0 ⇒ `standard_normal` 抽回**同一串**标准正态。
配方之间只有 `sigma = pct·|Z_true|` 的尺度不同，所以标准化残差
`nz / sigma_re` 在三族里完全一致：

```
voigt_K1_L   与 voigt 的标准化噪声最大差 0.00e+00
nested_L2_L  与 voigt 的标准化噪声最大差 1.24e-14
adr_L        与 voigt 的标准化噪声最大差 1.12e-14
```

这条同时暴露一个**设计缺陷**：三个配方不是三次独立重复，而是同一次噪声在三个系统里
的响应。任何"跨配方方向一致 ⇒ 系统性"的推断在这种设定下都不成立。

## 3. 定量归因：Laplace（Fisher）一阶位移

在线性-高斯近似下，噪声在真值处的**白化残差** `r` 与雅可比 `J = ∂Z/∂x` 决定后验均值的
一阶位移：

```
Δx ≈ (JᵀJ + Λ)⁻¹ Jᵀ r        Λ = 先验精度（log 坐标下 1/σ²；Uniform 内点取 0）
```

只用一次正演算 `J`，**不跑 MCMC**。结果：

| 配方 | `L` 预报 | `L` 实测（B2_REPORT） | 后验 1σ(ln L) | 预报/实测 |
|---|---|---|---|---|
| `voigt_K1_L` | +2.14% | +2.00% | 1.07% | **1.07** |
| `nested_L2_L` | +1.90% | +1.90% | 0.76% | **1.00** |
| `adr_L` | +1.46% | +1.40% | 0.65% | **1.04** |

同一口径下，`J`/`Λ` 给出的 90%CI 宽度也与实际后验一致（横截面校验，`voigt_K1_L`
seed 0，5 个真被采样的参数）：

| 参数 | MCMC 90%CI 宽 | 3.29×Laplace σ | 比值 |
|---|---|---|---|
| `R_inf` | 0.0079 | 0.0075 | 1.05 |
| `W` | 0.0164 | 0.0163 | 1.01 |
| `tau` | 0.0437 | 0.0451 | 0.97 |
| `phi` | 0.0237（绝对量） | 0.0219 | 1.08 |
| `L` | 0.0363 | 0.0353 | 1.03 |

⇒ 这套 Laplace 不是"讲故事"，它能复现实际后验的宽度，因此也有资格给偏差定预算。

## 4. 解析重抽 4000 次：均值为 0

`Δx` 对噪声是线性的，所以直接重抽标准正态即可得到 `Δln L` 的抽样分布（秒级）：

| 配方 | mean | sd | `P(Δ>0)` | seed 0 位于 |
|---|---|---|---|---|
| `voigt_K1_L` | −0.02% | 1.08% | 49.8% | +1.99σ（分位 98.1%） |
| `nested_L2_L` | −0.01% | 0.76% | 49.6% | +2.51σ（分位 99.4%） |
| `adr_L` | −0.01% | 0.66% | 49.0% | +2.24σ（分位 98.8%） |

均值为 0（MC 标准误 1.08%/√4000 = 0.017%），正负对称。**三个 +Δ 是这三个分布各自的
2.0～2.5σ 尾部点，且是同一个点**（见 §2）。

## 5. 真拟合复核：Laplace 与 MCMC 逐点重合

`voigt_K1_L`，`standard` 预算（3000/3000，ta 0.98），三个 seed：

| seed | Laplace 预报 | MCMC 实测 | 差 | R̂ | div |
|---|---|---|---|---|---|
| 0 | +2.14% | **+2.02%** | 0.12 pp | 1.004 | 0 |
| 1 | −0.09% | **−0.07%** | 0.02 pp | 1.001 | 0 |
| 2 | +0.09% | **+0.08%** | 0.01 pp | 1.004 | 0 |

三个 seed 横跨 +2.0% 到 −0.1%，Laplace 全部跟上。这说明：**偏差不是模型性质，
而是噪声实现的函数**。换 seed 就换符号。

三个 seed 的 MCMC 均值 = +0.68%，`sd/√3` = 0.62% ⇒ 1.1σ，与 0 相容。
**要把偏置压到 0.3% 以下需要约 14 个 seed**（`sd/√N ≤ 0.3%`），不是 3 个。

## 6. 顺带查出的两件事

### 6.1 `adr_L` 的退化方向被独立复现

`adr_L` 里 `Rct` / `R_ad` / `tau_ad` 的 Laplace 1σ **三者完全相同**，都等于
**1.155 = 2/√3**（= 先验 σ=2 在一维方向上的等分）。这正是"三者构成一条一维退化方向"
的解析特征，与 `TOPOLOGY_AUDIT.md` 用 `A` 矩阵奇异值得到的 **cond 2.70e9** 独立吻合。

代价是：三者的 1σ / 容差 = **11.55**，远超 1 — 也就是说 `adr_L` 的 4/7 **不是 seed 运气
问题，是结构不可辨**（与 B2_REPORT §4 的 deep 档结论一致：加预算仍 4/7）。

### 6.2 雅可比口径：`voigt` 的 ζ 被钉死，不能进雅可比

第一版把 ζ 也算进雅可比，结果 τ 的 1σ 被夸大约 4 倍（5.6% vs MCMC 的 1.33%）。
原因是 `bm_select.fit_voigt` 把 ζ 以位置参数 `"1.0"` 传给 `bm_real.fit_one`，
**ζ 不进采样**；把固定参数放进雅可比，会让它与 τ/φ 的强相关把协方差摊出去。

脚本里已按**实际采样键**建列（`sampled_coords()`），不是按真值字典建列。这条也顺带
说明 `voigt_K1_L` 的 6/6 里，`zeta` 那一条是"固定值 = 真值"的平凡通过，不是被估计出来的。

## 7. B2 该信几分：逐参数 seed 稳健性

用同一套 `(JᵀJ+Λ)⁻¹` 算出每个参数的 **seed 间 1σ**，除以 B2 的一步容差：

| 配方 | 最脆参数 | 1σ / 容差 | 其余 |
|---|---|---|---|
| `voigt_K1_L` | `tau` | 0.14 | 0.02–0.13 |
| `nested_L2_L` | `Q1` | 0.30 | 0.06–0.19 |
| `adr_L` | `Rct`=`R_ad`=`tau_ad` | **11.55** | `L` 0.07，其余 ≤0.15 |

读法：`0.30` 意味着一次 1σ 抽样只吃掉 30% 容差 —— 要翻转判定需要 ~3σ。**所以单 seed
的 6/6、8/8、7/7 在这三个配方上不会因换 seed 而翻**（`adr_L` 除外，它是结构不可辨，
本来就没过）。

⚠️ 但这条稳健性**只覆盖"噪声换一次"**，不覆盖：
- **单频窗**：换频率窗会改变 `tau`/`tau_ad` 的可见性（B2_REPORT §6 已列为未做项）；
- **先验尺度**：`zmax` 由本批观测算出，换谱即换先验中心；
- **模型误配**：这里是"真值在表达力内"（规格 C），真实谱没有这个保证。

所以「6/6 通过」的正确读法仍然是：**这条配方、这个频窗、这个先验尺度下，点估计能从
一个噪声实现里恢复到一步以内**，不是成功率。

## 8. 对 B2 判定的影响：无

`ci_covers` **不进判定**。`b2_pass = all(within_strict)`，而

```
within_strict = |err| ≤ 一步  且  90%CI 相对宽度 ≤ 1.0
```

`ci_covers` 只写进报告表的"覆盖"列（`b2_baseline.py:334`）。所以：

- `6/6`（voigt）、`8/8`（nested，`non_evaluable`）、`7/7`（adr_series，`non_evaluable`）、
  `4/7`（adr）**全部不变**；
- 报告里"CI 覆盖率 83% / 71% / 100%"这些数是**单 seed 的一次实现**，不是覆盖率估计
  （n=6 时 90% 名义覆盖的抽样 sd ≈0.73 条，5/6 完全正常），不应被引用为覆盖率。

## 9. 后续口径（写给下一次 B2）

1. **每个配方用自己的 seed**（如 `seed = 0, 1, 2, ...` 按配方序号，或
   `crc32(name) % 1000`），否则"跨配方一致"没有任何统计含义。
2. **别再用 "CI 不含真值" 当系统性判据**：90% 区间本来就有 10% 不含，n=6 时三配方
   同时不含的概率不低（尤其共用一次抽样）。要判偏置，看**偏差的均值与 se**。
3. **Laplace 可以当预算工具**：`(JᵀJ+Λ)⁻¹` 秒级给出"这个配方在 N seed 下能分辨
   多大的偏置"，用它决定要跑几个 seed，而不是跑完再看。
4. `adr` 族若要用，`Rct`/`R_ad`/`tau_ad` 必须合并成一个参数（或直接固定其一），
   1σ=1.155 的那条方向证实了它们不可分。

## 11. 边界

- 只对 `voigt_K1_L` 做了真拟合复核（3 seed）。其余两族只有 Laplace 预报 + 已有产物
  的实测值对照，**没有**为它们另跑 seed 1/2 的 MCMC。
- Laplace 是局部线性近似。对 `nested_L2_L`（R̂=1.100，`b4_fail`）和 `adr_L`（退化），
  其 1σ 只能当"方向上的量级"，不能当后验宽度的精确值。§7 的稳健性结论对这两族
  应理解为"即使按最乐观的线性化看也不会翻"，而不是严格证明。
