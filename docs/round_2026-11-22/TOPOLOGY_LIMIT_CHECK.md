# 拓扑极限检查：P-8 的可执行部分（2026-11-22）

> `adr` 复盘的结论不是"删掉它"，是"下一个族不能再这样立项"。
> 这份文档交付那件事的**检查工具**，以及一次覆盖全部 9 个族/接点的实测。

## 1. 检查什么，为什么只查实部

阻抗在两个端点都是实数：直流没有电容电流，高频电容短路（带顶层 L 时虚部发散）。
所以三个量就够描述端点行为：

```
Re Z(ω→0)     低频平台  = 直流总电阻
Re Z(ω→∞)     高频截距  = 溶液/引线电阻
Im Z(ω→∞)/ω   带 L 时    = 顶层电感
```

虚部在两端都趋于 0 或发散，比它没有信息量。

## 3. 关键读数：`adr` **两端都塌到 `Rs`**

```
adr = Rs + [ CPE ∥ Rct ∥ Z_ad ]
      ω→0 :  Z_ad → 0    ⇒ 整个并联节点被短路 ⇒ Re Z → Rs
      ω→∞ :  CPE → 0     ⇒ 整个并联节点被短路 ⇒ Re Z → Rs
```

两端同一平台意味着：**`adr` 的阻抗曲线是一个"鼓包"，两侧都掉回溶液电阻。**
它在结构上没有"低频电阻平台"这个概念——而真实电极的低频恰恰应该是
`Rs + Rct`（有限）或更高（扩散尾）。

对比 `nested/L=1`：`ω→0 → Rs+R1`（平台），`ω→∞ → Rs`。两端不同，这才是一个
能表达"低频电阻"的结构。

## 4. 但不能夸大：窗口内不一定真的短路

数学极限 `Re Z→Rs` 只在 ω→0 成立。**在有限窗口里是否真的短路 Rct，取决于 `τ_ad`**
（`R_ad=200, Rct=100`，`f=0.01 Hz`）：

| `τ_ad` / s | `\|Z_ad\|` / Ω | vs `Rct` |
|---|---|---|
| 1e-3 | 0.013 | 0.0001× ⇐ 已短路 |
| 0.01 | 0.126 | 0.001× ⇐ 已短路 |
| 0.1 | 1.26 | 0.01× ⇐ 已短路 |
| 1 | 12.5 | 0.13× |
| 10 | 106 | 1.06× 未短路 |

昨天在 `AZ31-12Li_5` 上拟合出的 `τ_ad=0.82 s`、`R_ad=3220 Ω`，其支路幅值：

| f / Hz | 1e-4 | 1e-3 | 1e-2 | 1e-1 | 1 |
|---|---|---|---|---|---|
| `\|Z_ad\|` / Ω | 1.7 | 16.6 | 166 | 1475 | 3161 |

**所以准确的表述是**：`Z_ad` 随频率**降低而单调减小**，在窗口底端（0.01 Hz）已与
`Rct` 同量级，再降就要短路。也就是说 `adr` 的低频**走向**是"往下"，而真实吸附的
走向是"趋饱和" —— 两者方向相反。这比"短路"更精确，也更难在单条谱上一眼看出来：
**它不是某个数据点错，是整个低频段的斜率方向错了。**

## 5. 方法学陷阱：`w_ref` 依赖窗口

首版把 `nested_L1_capacitive` 的 DC 期望写成 `Rs+R1 = 150`，实测 `7.0e8`，判 MISMATCH。
真因不是实现错，是**我写错了期望**——内层 CPE 阻断直流，`Re Z(ω→0)` 是 **∞**。

排查时还踩到第二个坑：`z_cpe` 的 `w_ref = sqrt(f.min()·f.max())` **随窗口变化**。
把 `f_lo` 从 `1e-8` 降到 `1e-14` 时，`w_ref` 也降了 `1e-3`，于是
`Z ∝ w_ref^n · ω^{-n}` 变成了 `∝ f_lo^{-0.5n}`——发散速率被人为压低一半。
**所以从两端读数判断收敛/发散时，必须先固定 `f_ref`，否则读到的指数是假的。**

最终判据改成：
- 有限极限：相对误差 ≤ 1e-6
- 期望 ∞：取 `f_lo/1e6` 再算一次，要求 `Re Z` 涨 ≥ 100 倍（幂律下应涨 ~1e5）
  —— 判**方向**，不判绝对值

## 6. 怎么用（P-8 的落地流程）

新族/新接点立项时：

```
1. 在 ADMISSION 的表里填三项：
   a. 与最近文献结构的逐项差异（连接点 / 元件类型 / 内部串并）
   b. Re Z(ω→0)、Re Z(ω→∞)、带 L 时 Im Z/ω      ← 本脚本的输出栏
   c. 该差异在目标频窗内是否可辨识（snr≥1 或 s_min≥1）
2. 把新配置加进 topology_limit_check.py 的 cases()，期望值必须写推导
3. 跑通且 9/9（或 N/N）一致，才允许登记进 registry
```

**如果 `adr` 当年走过第 1.b 步**，`Re Z(ω→0) = Rs` 会直接暴露"没有低频平台"，
不必等两周算 13 条谱。

## 7. 边界

| 项 | 说明 |
|---|---|
| 只查端点 | 中间频段的行为（形状、斜率）不覆盖；那是 `B2` 与 `acf` 的事 |
| 参数点单点 | 极限的**形式**与参数无关（只要非零、非退化），所以单点足够；但"窗口内实际值"强依赖参数，见 §4 |
| 不含扩散 | `Ws/Wo/Wshort` 的端点行为（`Wshort` 低频有限、`Wo` 低频发散）未纳入；本轮 9 个配置都 `diffusion=None` |
| `capacitive` 是研究接口 | 它的 ∞ 是设计意图（CPE 阻断直流），不是缺陷 |
| 不改任何拟合 | 纯正演，零 MCMC，零生产代码改动 |
