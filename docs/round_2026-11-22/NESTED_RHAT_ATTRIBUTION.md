# `nested_L2_L` 的 R̂=1.100 卡在哪：一个近乎纯先验的 `R_ad`–`tau_ad` 二维平片，把 `R2` 拖下水

> 触发：`B2_REPORT.md` §2/§4 —— `nested_L2_L` 在 `standard` 下 R̂=**1.100**（div=0）
> 记 `non_evaluable`，`deep` 掉到 1.007 ⇒ 判 `budget_limited`。
> 这只回答了"加预算能不能过"，没回答**为什么**。
>
> 脚本：`docs/round_2026-11-22/nested_rhat_attribution.py`（一次 standard + 一次 deep 拟合）

## 0. 一句话

`budget_limited` 的标签**是对的**——deep 不是"收敛到一个混合"，是真的收敛了
（`R2` 两链 198.6/198.8、链内 sd 1.8、偏差 −0.7%）。但失败的**机制**很具体：
`R_ad` 的先验中心是 `0.1·zmax = 35.3 Ω`，而真值是 `0.5 Ω`；先验把后验往高推两个数量级，
推到 `Z_ad ≈ R_ad` 的纯电阻区。那一片上 `R_ad`/`tau_ad` 的数据曲率只有先验的 6.0%/21.7%，
standard 的其中一条链在那里漂到 `tau_ad ≈ 0.6 s`、`R_ad ≈ 30–320`，
把 `R2` 压到 **182±52**（ρ(log `R2`, log `tau_ad`) = **−0.54**）—— 报告里那个 R̂=1.100 就是 `R2`。

## 1. 几何：两条方向几乎是纯先验，且构成二维平片

`H = JᵀJ + Λ`（`J` = 白化雅可比，与 `b2_bias_attribution.py` 同一口径）在真值处分解：

| 方向 | 特征值 λ | 该方向的先验曲率 `vᵀΛv` | **数据绝对值** | **数据/先验** | 组成（前 3） |
|---|---|---|---|---|---|
| `v[0]` | **0.2651** | 0.25 | **+0.0151** | **6.0%** | `tau_ad` +0.90、`R_ad` −0.44 |
| `v[1]` | **0.3042** | 0.25 | **+0.0542** | **21.7%** | `R_ad` +0.90、`tau_ad` +0.44 |
| `v[2]` | 755.2 | — | — | — | `Q1` −0.81、`Q2` −0.40、`R1` +0.30 |

条件数 **1.84e6**，且 `v[0]`/`v[1]` 与 `v[2]` 之间差 **2800 倍**。

**这两条方向的数据曲率只有先验的 6.0% 和 21.7%** ⇒ 在 `(R_ad, tau_ad)` 上，后验 ≈ 先验。

还有一点比"脊"更糟：`v[0]` 与 `v[1]` 是对 `(log R_ad, log tau_ad)` 平面上互相正交的两个 45°
方向（实测 ρ(log `R_ad`, log `tau_ad`) = **−0.024**）。所以这不是"一条脊"，
而是 **(log R_ad, log tau_ad) 上的二维近乎平坦的子空间** —— **两个参数各自都不被数据约束**，
而不是"只知道乘积"。
这不是"耦合强"，是**数据什么都不说**。与 `B2_REPORT` 的声明一致（`R_ad` 不测），
但声明不等于无害 —— 见 §3。

## 2. 实测：standard 的一条链漂到 `tau_ad` 的尾巴上

`standard`（2000+1000 / 2 链 / ta 0.98），`R̂_max = 1.1005`（复现报告的 1.100）：

| 参数 | 真值 | split-R̂ | ESS | 后验均值 |
|---|---|---|---|---|
| **`R2`** | 200 | **1.1005** | **12** | 190.43（−4.8%） |
| `tau_ad` | 0.01 | 1.0937 | 13 | 0.3027 |
| `L` | 1e-5 | 1.0120 | 130 | 1.0198e-5 |
| `R_ad` | 0.5 | 1.0026 | 250 | **35.18** |
| 其余 6 个 | — | 1.0002–1.0128 | 56–250 | — |

逐链拆开，机制就出来了：

| 量 | 链 0 | 链 1 |
|---|---|---|
| `tau_ad` 均值 | **0.605** | **5.26e-4** |
| `R_ad` 均值 | 30.01 | 40.34 |
| **`R2` 均值 / 链内 sd** | **182.4 / 51.9** | **198.4 / 1.67** |
| `log tau_ad` 链内范围 | [−11.5, **+2.71**] | [−14.7, −4.6] |

- `R_ad` 的后验均值 **35.18 ≈ 0.1·zmax = 35.29**（zmax=352.9）——**后验就是先验**，
  链条数字直接印证 §1 的 λ≈0.25。
- `log tau_ad` 在链 0 里跑到 **+2.71**（`tau_ad=15 s`），而先验中心是 `1/w_ref = 1.59e-4`、
  先验 σ=2 ⇒ 那是 **5.7 个先验 σ**。链 0 是"逃出去"了。
- ρ(log `R2`, log `tau_ad`) = **−0.54**（同坐标；用原始 `R2` 会得到 −0.61，两者不通用）：`tau_ad` 大 ⇒ `ωτ ≫ 1` ⇒ `Z_ad → R_ad`（纯电阻）
  ⇒ 与 `R1` 并联后把直流/低频水平抬高 ⇒ `R2` 必须往下让。

所以 R̂ 最大的那个参数不是几何最扁方向上的参数，而是**被那个平片拖走的补偿量**。
（投影到 `v[0]` 本身的 split-R̂ = **1.33**，比任何单参数都差——单参数 R̂ 会低估问题。）

## 3. deep 是真收敛，不是收敛到混合

`deep`（4000+2000 / 2 链 / ta 0.97），`R̂_max = 1.0075`（复现 1.007）：

| 量 | standard | **deep** |
|---|---|---|
| `R2` 链均值 | 182.4 / 198.4 | **198.61 / 198.79** |
| `R2` 链内 sd | 51.9 / 1.67 | **1.79 / 1.88** |
| `R2` 偏差（vs 200） | −4.8% | **−0.7%** |
| `tau_ad` 链均值 | 0.605 / 5.26e-4 | **5.80e-4 / 7.03e-4** |
| `log tau_ad` 区间重叠 | +4.38（部分） | **+6.15（完全）** |
| ρ(log `R2`, log `tau_ad`) | −0.54 | +0.36 |
| 投影到 `v[0]` 的 split-R̂ | 1.3306 | **1.0013** |

`deep` 的 `R2` 链内 sd 1.79 → 相对 **0.90%**，而 `b2_bias_attribution.py` 的 Laplace
Fisher 界给的是 **0.76%** ⇒ **deep 达到了 Fisher 界，standard 没达到**
（链 0 的 sd 51.9 = 26%）。这是"非收敛"而不是"后验本来就宽"的硬证据。

⚠️ 因此：**`nested_L2_L` 的 `8/8` 在 standard 下是"数字对、后验没抽对"**。
`R2` 的 −4.8% 落在 ±10% 容差内、判 `within`，但那是中位数侥幸；
deep 下同一个量是 −0.7%。引用这条配方的 B2 数字必须用 deep 档。

## 4. `budget_limited` 这个标签该怎么读

| 读法 | 对不对 |
|---|---|
| "加预算就能过" | **对**，且是真收敛（§3） |
| "所以这条族没问题，只是算得少" | **不对**。standard 下 `R2` 会给出 −4.8%、链内 sd 26% 的数，而它**通过了 B2** |
| "`R_ad` 声明不测，所以它无害" | **不对**。`R_ad` 所在的平片通过 ρ=−0.54 直接污染 `R2`；声明只让它不进判定，没让它不进模型 |

## 5. 把 `R_ad`/`tau_ad` 拉进退化区的是**先验的宽度**，中心只是选址

```python
# bm_top._prior_table
t["R_ad"]  = dist.LogNormal(jnp.log(0.1 * zmax), 2.0)     # zmax=352.9 → 中心 35.3 Ω
t["tau_ad"] = dist.LogNormal(jnp.log(1.0 / w_ref), 2.0)   # 中心 1.59e-4 s
```

两件事要分开：

| 事实 | 造成什么 |
|---|---|
| 数据在 `(R_ad, tau_ad)` 上的曲率只有先验的 6.0%/21.7%（§1） | 这两个参数**不可辨识**——改先验中心不会改变这一点 |
| 先验 σ=2（log 尺度 ≈ ±2 decade） | 不可辨识的后果被放大成"链条能漂 4–5 个数量级" |
| 先验中心 `35.3 Ω` vs 真值 `0.5 Ω`（低 1.85 dec） | 决定链条**往哪个方向**漂——往 `Z_ad ≈ R_ad` 的纯电阻区，那里会把 `R2` 一起拖进去 |

所以"只把先验中心改到 0.5 附近"是**不够的**：后验仍会在一条二维平片上铺开，
只是换了个位置。真正的杠杆是 **σ**（把游走范围限住），或者干脆不采样。

这与已记录的同类问题是一族，但成因不完全相同：
- `ecm_05687` 的 σ 先验比真噪声高 4.75 dec（`STD_RECHECK.md`）—— 中心错位主导；
- `R_inf` 先验诊断（`RINF_PRIOR_DIAGNOSIS.md`，本次未动）；
- 本条：中心错位 1.85 dec **叠加** σ=2 的宽度。

**共同点：先验中心与宽度都由数据尺度（`zmax`/`w_ref`）派生，对"该元件是否在窗口内可见"不做任何判断。**

## 6. 结论与建议

1. **不改任何判定**：`nested_L2_L` 仍是 `b4_fail` / `non_evaluable`（standard），
   deep 下 `budget_limited` 成立。`B2_REPORT.md` 的数字不用改。
2. **引用纪律**：这条配方的 B2 数字只能引 deep 档；standard 的 `R2=−4.8%` 是未混合链的产物。
3. **`R_ad`/`tau_ad` 的处置才是真问题**，而且要分清两件事：
   - **平坦不是先验中心造成的**。数据在那两条方向上的曲率只有先验的 6.0%/21.7%，
     这是真值处的**似然性质**，改先验中心只会挪动后验停在哪，不会让它变得可辨识。
   - **链条能漂 4–5 个数量级，是因为先验 σ=2**（log 尺度 ≈ ±2 decade）。
     真正的杠杆在这里。
   所以可选做法按力度排：①把 `R_ad` / `tau_ad` 的先验 σ 从 2 收到 0.5 量级
   （保持"不测"的语义，但把游走范围限住）；②`R_ad` 干脆不采样（`parallel` 退化成
   `series`，即 `adr_series` 那条 7/7 的接法）；③按 `§9.4.42` 整个并联支路不接。
   —— 三条都要先预注册，本文只提供证据，不拍。
4. **B2 的口径补一条**：`non_evaluable` 的配方，`within` 也要一起标，
   否则 `8/8` 会被当成"参数恢复了"读（本次就是）。

## 8. 边界

- 只做了 2 链 × 1000 / 2 链 × 2000 两档，`R̂` 是 split-R̂（半链切分）。
- `v[0]`/`v[1]` 是**真值处**的局部曲率。`tau_ad` 在 15 s 处显然已非线性，
  所以"数据无信息"是**在真值附近**成立，不能外推到整个尾部。
- 未做「把 `R_ad` 固定后重拟合」这一步（`fit_top` 没有固定参数的入口，
  要改生产模块），因此"钉住 `R_ad` 后 R̂ 会掉到 1.0x"是**推断**，未实测。
