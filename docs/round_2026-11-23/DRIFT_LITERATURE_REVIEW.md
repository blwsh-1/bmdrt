## 1. 每篇能用到什么

### 1.1 Ziino20 —— 漂移是真实、单向、集中在工作电极的

- 量级：报告区间 **0.11–5.5 Ω/min**；该实验初始抛光下 0.50，更新抛光 0.15，
  每次测量间取出并冲洗工作电极 **0.11**（最低）。
- **假电池对照斜率 = 0 Ω/min** ⇒ 漂移来自溶液/电极，**不是仪器误差**。
- 只报 `Rct`：作者明说「其余变量未被发现持续线性漂移」（p.2）；
  漂移机制猜测为铁氰化物还原膜 / 氯化物膜在工作电极表面形成。
- **第 0 分钟点异常**：`Rct(0)` 与 `Rct(10min)` 的差显著大于其它相邻时间点，
  线性拟合只用 10–50 min（p.3）。
- 反直觉点：降低 `[Fe(CN)6]3-/4-` 到 1 mM 反而漂移飙到 **5.5 Ω/min**、误差棒变大；
  作者自述「没有可用理论」。

**对我们的用处**：支持「漂移真实存在、单向、在样品/电极侧」；「首点异常」提醒
重复测量设计的第一条谱不能当基线。**不能外推**：体系是水溶液铁氰化物 + 玻碳，
我们的是 AZ31 腐蚀 / 2E / 3E；Ω/min 不能换算到我们的 acf。

### 1.2 Pillai26 —— 漂移的时间尺度分层，正好补上 E1 的设计盲点

- 定义：固定 SOC/温度/静置时间下重复测量的变异 = drift，是 SOH 估计的额外不确定性源。
- **时间尺度分层**（本文最有价值的一条，见 §5.1）：
  1. 跨多次完整谱measurement 时间尺度：系统变了、但单次谱内没变 ⇒
     **重复谱不同、每条谱各自仍满足 KK**；
  2. 单次谱measurement 时间尺度：系统在一张谱内变了 ⇒ **不满足 KK**；
  3. 单频点时间尺度：单频点内变了 ⇒ 无校正时该频点被污染。
- 静置时间：短静置 ⇒ Nyquist 变异更大，**尤其在低频**；高频欧姆电阻在不同静置下
  保持一致；阻抗随静置时间在低频增大，**最大变异在 ≤1 Hz**；2 h 弛豫可稳定（依体系）。
- 实验（3 天 × 每天 3 次，间隔 1 h）：**同一天的三次无递增/递减规律**；
  跨天单向升（Day01<Day02<Day03），实部跨天差 2 mΩ、drift 0.5 mΩ，
  扩散电阻跨天方差 11.11%。假电池四次重复完全重合。
- 缓解：对多次测量**取平均阻抗**可减轻 drift 影响；提出跨体系归一化指标 d-ohm。

**对我们的用处**：「漂移在低频、高频欧姆稳定」与我们 `ACF_BAND_PROFILE.md` 的
「acf 卡在低频、去高频达标 0/10」**方向一致**。但更关键的是它暴露 E1 的设计盲点：
`E1_PREREG.md` 的「同一状态连续测 3 条」按这篇的说法**可能落在「同日无规律」区**，
测不出单向漂移模式——这是**采集条件**问题，判据与 27/27 执行器都冻着，不该动。

### 1.3 Orazem23 —— 最硬的一篇：漂移校正救不了非稳态

- 主结论（摘要 + §5）：**drift correction cannot generate KK consistent data for
  nonstationary systems**；即使改善，也不能完全恢复未被漂移污染的原谱。
- 四厂商对比：不同厂商的漂移校正算法（都是线性基线扣除）对外因引起的非稳态
  **都没能让谱 KK 合规**（§4 末尾，「data will not be presented for brevity」）。
- 三分时间尺度（与 Pillai26 一致，见 §1.2），并明确：
  「drift correction reduces the error at a given frequency, but **cannot compensate
  for changes over the range of frequencies that make up a spectrum** if the
  impedance itself changes throughout」。
- 唯一有用的例外：阻抗本身稳定、只是**基线漂移**（galvanostatic 换频点的初始瞬变），
  且漂移接近线性时，线性扣除能改善；但作者强调「这 **almost never linear**」，
  非线性情形仍 KK 不合规，且这种改善「should not be treated as anything more than
  a cosmetic improvement」。
- 仿真细节：换转速导致非稳态的情形，即便完美校正得到各频点瞬时值，
  组成的谱**仍不满足 KK**（Fig.8 讨论，p.6）。

**对我们的用处**：这篇直接回答了我们 11-11 撤回 R24 时留下的空白——
当时只证了「有限阶 Lin-KK 残差不是下界」（M=12 的 8.49% → M=45 的 6.84%），
但没回答「非稳态数据能不能被判为 KK 不一致」。Orazem23 的答案是：
**非稳态数据的 KK 不合规是真实的**，不是测量模型的阶数伪迹；而且事后校正救不回来。
⇒ 我们不该走「对现有 14 条谱做漂移校正再重拟合」这条路，那是 cosmetic。

## 3. 对本项目的操作含义（按能不能做排序）

### 3.1 现在就能改的：E1 采集条件建议（不动判据、不动执行器）

`E1_PREREG.md` 与执行器 27/27 是冻结的，判据一个字不改。但**排期时的采集条件**
可以补三条，来自三篇文献：

1. **首点单列**：按 Ziino20，第一条谱可能是瞬变污染，单独标记、不作基线；
   E1 判据若以「第一条 vs 后续」比对，需要把这个已知效应写进采集备注。
2. **同日 + 跨天分开**：按 Pillai26，同日三次无规律、跨天单向。
   「同一状态连续测 3 条」只覆盖「跨多次谱」尺度的一种；要分漂移，
   建议同日 3 条 + 隔日 3 条都留（但样本量需求按 `E1_PREREG.md` 原判据，不自行改）。
3. **记静置时间与温度**：按 Pillai26，短静置放大低频变异、≤1 Hz 最敏感。
   采集时记录静置时长与温度，否则事后无法判断低频 acf 是否受此驱动。

> 这三件事都属**实验条件**，不属于判据；是否采纳由用户排期时定。

### 3.2 明确不能做的：事后漂移校正

按 Orazem23，对现有 14 条谱跑厂商式线性漂移校正再重拟合是 cosmetic，
且会把本已冻结的 4/14 变成不可比口径。⇒ **不接这条**。

### 3.3 文献不能替代的：E1 六条 csv

三篇都是「重复测量 → 见到漂移 → 取平均缓解」。我们手上没有重复谱，
`MB-SIM-01` 已证 acf 分不出残差来源（AUC 0.517）。文献能支持「漂移值得测」，
但**不能**把 4/14 从「未过」变成「可归因」。

## 5. 边界与局限

- 三篇的体系（铁氰化物水溶液、锂离子电池、超级电容）与我们的 AZ31 腐蚀 /
  2E / 3E 都不同；漂移机制（膜形成、SOC 变化、温度）未必适用于我们的样品。
- 量级不可直接换算：Ω/min、mΩ、d-ohm 都不能映射到我们的 `acf_max` 或 rms。
- 本文是**文献对照**，不是新实验；没有跑任何拟合，没有产生新的谱或新数字。
- E1 的三条采集建议**尚未被用户采纳**，也未写进 `E1_PREREG.md`（冻结文档不动）。
