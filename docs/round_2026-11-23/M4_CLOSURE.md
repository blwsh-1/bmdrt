## 1. 先纠正一个用词（用户 2026-11-23 指出）

此前把路 B 写成"不接生产"是**用词错误**。代码事实：

| 事实 | 位置 |
|---|---|
| `bmdrt.py` import `nested_fit` | `bmdrt.py:332`、`:401` |
| `auto` 族分派：voigt 预检 `excluded` ⇒ `_run_nested_branch()` | `bmdrt.py:493-509` |
| `build_candidates` / `fit_nested` 是生产调度的一部分 | `circuit_runner.py:241`、`:566` |
| 分派产物标 `provisional`，`admission.py` 的 `PASSED=False` 恒成立 | `round_2026-11-16/PROVISIONAL_ADMISSION.md` |

所以「nested 接没接生产」有两个不同含义，必须分开说：

- ✅ **已接入**：`auto --family-auto` 下 voigt 结构上表达不了时切入 nested，
  产物标 `provisional`、可跑可读、可作探索分析（11-16 裁决，用户"合起来能跑就行"）；
- ❌ **未过**：升级为**默认族 / 正式准入**——§9.4.21 A1–A4 未满足，
  §13 `0/3`、§14 `4/14`、§17 `0/10` 全部原样。

路 B 的"不接生产"**只指后者**：不升级为默认族。路 B 不要求拆掉入口——
拆掉 11-16 的既有分派是倒退，本裁决明确不做。

   4/14 从来没被证伪，也不改。路 B 只是不再让它承担族选择声明，
   重心转到**有真值、能出结论**的合成谱线（B2 `voigt_K1_L` 6/6、可辨识性框架）。
