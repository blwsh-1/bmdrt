# 吸附元件的可恢复性验证（2026-11-21）

> **要回答的问题**：`adsorption` 这个元件"要不要补"。
> 脚本 `ad_recovery.py`（本目录），产物 `out/ad_recovery.json`。
> 复算命令：`python docs/round_2026-11-21/ad_recovery.py --from-json`
> （只按落盘结果复算判据，不重跑采样）。

## 0. 先纠正问题前提：它不是"缺"

| 事实 | 证据 |
|---|---|
| `bm_ad.z_ad` 与 `bm_top.z_rl_parallel` 是**同一个函数** | 实测 `max|Δ| = 0.0`（30 点，R=30 Ω，τ=10 ms） |
| 有效接点（第二并联节点）已在候选集 | nested 的 `branch="parallel"` 是默认候选（`elements` 含 `rl_parallel`）；adr 的 `adsorption_branch` 同 |
| `adsorption` 这个 id 指的是**另一个接点** | voigt 顶层串联（`bm_core.model_z` 的 `z = z + A.z_ad(...)`） |

所以缺的从来不是元件，是**证据**：从没验证过"真值里真有吸附环时，能否把
`R_ad`/`tau_ad` 恢复出来"。本文件补这一项，并顺带在参数层面复核 §9.4.12。

## 1. 设计

- 两条真值谱，`1%·|Z|` 相对高斯噪声、`seed=0`、50 点（0.01–1e5 Hz）：
  - **谱 A**：`nested(layers=2, branch=parallel)` 真值，`R_ad=40 Ω, tau_ad=3 ms`（峰 ≈ 53 Hz）；
  - **谱 B**：`adr` 真值，同样 `R_ad=40 Ω, tau_ad=3 ms`。
- 候选：谱 A = nested(parallel) / nested(capacitive，**无感性支路**) / voigt K=2 /
  voigt K=2 + `adsorption="RL"`；谱 B = adr / voigt K=2 / voigt K=2 + `RL`。
- 预算 `quick` + `likelihood=free`（与 `l_recovery.py` 同口径，便于横向比较）。

## 3. 预注册判据

| 判据 | 结果 | 实得 |
|---|---|---|
| A1 谱A nested(parallel) rms ≤2% | **通过** | 0.711% |

## 4. 三条未过项各自的含义（这才是本轮的产出）

### A2：即使接点对了，`R_ad` 也恢复不了（偏 52%）

nested 把 rms 压到 0.711%（接近 1% 噪声底），但 `R_ad` 只给出 19.0 Ω。
说明**幅值与其他电阻竞争**：`R_ad` 与 `R1=120`、`R2=60` 在同一加法节点上，
低频极限只看 `R1+R2+R_ad` 的和，环的**直径**不是独立可认的量。
能看清的是"有没有这个环"（rms/acf 分得开），看不清的是"环有多大"。

adr 的 31.3 Ω（偏 22%）好一些，因为它的 `R_ad` 只与 `Rct=60` 竞争、少了 `R2`。

### A3：`rms` 不是"支路必要性"的判据（0.90pp < 2pp）

去掉感性支路（capacitive）rms 从 0.711% 升到 1.607%——方向对，但幅度只有
0.90pp。也就是说：在 1% 噪声、`R_ad=40 Ω` 的相对量级下，"少了这条支路"
的代价还不到 1 个百分点。**想用 rms 差值证明"这条支路该有"，需要更响的环
（更大的 `R_ad/|Z|`）或更低的噪声。**

### A4：最尖锐的一条——`rms` 对"接点错"零区分力

voigt + 顶层串联 `R∥L` 把 rms 从 2.561% 压到 **0.888%**（改善 65%），
比真值模型 nested（0.711%）只差 0.18pp；但它的 `R_ad = 7.1 Ω`（真值 40，偏 **82%**）、
`div=4`。

即：**一个接点被证否的结构，靠多两个自由参数，能把 rms 做到和真值结构几乎一样。**
这与 `MB-SIM-01` 的结论同型（`AUC=0.517`，M-b 对"仪器寄生 vs 样品侧结构"零区分力），
但这里是更基础的一条：**用 rms/elpd 改善当"该补这个元件"的证据，是无效的判据。**
§9.4.12 里 `44.0% → 40.7%` 的"改善很小"是在 `noise=0`（没有自由度可挥霍）时看到的；
一旦有噪声，同一结构立刻能把残差吃掉。∴ 判断接点对错只能靠**参数可辨识性 + 独立机制依据**，
不能靠拟合优度。

## 5. 对"要不要补 adsorption"的回答

1. **补到 voigt 不需要做**：§9.4.12 的极点证据（voigt(K=2)+ad 极点恒为实负
   `−20.0, −0.50, −0.625`；nested 为复共轭 `−0.479±0.438i`）说明相同有理函数
   必有相同极点集，参数盒里约 23% 落在复极点区、那里顶层串联严格不能表示。
   要"补上"就得给 voigt 加第二个并联节点，那**就是 nested**（§9.4.12.5）。
2. **元件本身不缺**：`rl_parallel` 已在 nested/adr 的候选集里跑（本文件 §2 的
   `nested/parallel 0.711%`、`adr 0.670%` 就是它在跑）。
3. **补了也不能宣称参数**：A2/A6 说明幅值恢复只在 ±20–50% 量级；A4 说明
   rms 变好不能当成"补对了"。

## 6. 边界

- `quick` 预算，`nested/parallel` 的 `R̂=1.899` 已贴近 2.0 警戒线 ⇒ 该行的
  `R_ad` 后验本身不够稳，"偏 52%"应读作"至少偏这么多"。
- 单 seed、单组真值参数、单条噪声实现 ⇒ 只作**结构性**结论（"rms 无区分力"
  这类方向性判断），不作偏差量的定量估计。
- 吸附元件 `adsorption` 在 registry 里仍 `wired=False`，理由已改为
  "顶层串联接点已证否"（不再是"接点未定"）；`rl_parallel` 与它的互指已写进登记。
