# standard 预算复核：哪些 R̂ 异常是"预算不够"，哪些是"天生不可辨识"

> 只读复核，不改生产代码、不改 21 条的任何既有结果。
> 执行器 `std_recheck.py`，产物 `out/std_recheck/{progress.jsonl, std_recheck.json}`。

## 0. 结论

21 条 quick/free 里 `rhat>1.05` 或 `div>0` 的共 **14 条**（不是早前记的 5 条）。
用 `standard`（2000+1000，target_accept 0.98，depth 10）重跑各自的 best 候选后：

| 判定 | 条数 | 含义 |
|---|---|---|
| `budget_limited` | **7** | R̂≤1.05 且 div=0 ⇒ 原来只是预算不足，**加预算后可用** |
| `budget_limited_minor_div` | **2** | R̂≤1.05，div 余 1–2（0.05–0.1%）⇒ 可用，需标注 |
| `structurally_unidentifiable` | **5** | R̂>1.05 或 div>5 ⇒ **加预算无用**，应标 `non_evaluable` |
| `failed` | 0 | — |

**5 条结构性异常的成因不统一，必须分开说**：

- `ecm_05687`：`free` 的 σ 先验（1.3255 Ω）比真值噪声（2.37e-5 Ω）大 **4.75 个数量级**
  ⇒ 似然被抹平、**91% 触顶**（详 §3.2）。与 L 无关（该谱 `include_L=True`）。
- 涂层 3 条 + `ecm_04375`：更像表达力 / 多峰，std rms 分别是 12.46 / 15.50 / 28.35 / 1.62%，
  **不是**似然被抹平的那种"rms≈0 而 R̂ 爆炸"。

## 1. 判据（跑前预注册，未改）

```
A. standard 下 rhat<=1.05 且 div==0        ⇒ budget_limited
B. rhat<=1.05 且 0<div<=5                  ⇒ budget_limited_minor_div
C. rhat>1.05 或 div>5                      ⇒ structurally_unidentifiable
D. 抛错                                     ⇒ failed
```

只重跑 `results.json` 记录的 **best 候选**，不重选模型；`zmax_override` 沿用原口径
（`prod` 用 `max|Z|`，`fixed` 用 `5·|Z(f_max)|`），所以 quick/standard 两列可直接比。

## 3. 三个必须记下的观察

### 3.1 涂层 #3 越算越差（26.0 → 92.5）

这不是噪声。`standard` 的 `target_accept=0.98` 让步子更小，暴露了**多峰后验**：
quick 的 26 已经不合格，standard 把它推到 92.5。说明该谱的后验不是"采样不够深"，
而是**在多个模式间跳**。同类证据：涂层 #1 从 53 降到 17 但仍远高于 1.05。

结论：涂层三条**没有任何一条的 rms/acf 可以引用**，包括 21 条表里的 22.04%。

### 3.2 `ecm_05687`：R̂ 986 的真因是 **σ 先验与数据差 4.75 个数量级**，不是"没接 L"

**先纠正一处误判**：这条谱的 `include_L = True`（`results.json` 记录），6 个候选
（voigt/K=1、K=2、nested/L=1、L=2、adr）全部在带 L 的前提下跑的，L 确实参与了拟合。
真值 `L_uH = 0.0249`（24.9 nH），在 1 MHz 的贡献约 0.16 Ω，而真值噪声
`sigma_re = 2.37e-5 Ω` ⇒ 信噪比约 7000，**L 本身完全可辨识**。所以问题不在 L。

真因在 σ：

| 量 | 值 |
|---|---|
| 真值 `sigma_re` / `sigma_im` | 2.37e-5 / 2.79e-5 Ω |
| `free` 的 σ 先验中心 `0.01·zmax` | **1.3255 Ω** |
| 比值 | **55,900 倍 = 4.75 个数量级** |

σ 比真实噪声大近 5 个数量级 ⇒ 似然被压成近似常数 ⇒ 后验 ≈ 先验 ⇒ 参数自由游走。
真值 json 的 `grade_fail` 直接写着 **`触顶=91%`**（91% 的后验贴在参数先验边界），
并已经给了 `R̂=2.512`。结果就是：rms = **0.00%**（曲线是被压出来的）而 R̂ = 986。

这与腐蚀的 D 问题是**同一族失配的两个极端**：

- **腐蚀**：σ 太大 ⇒ 最低阻抗点权重 → 0（高频被丢弃），靠 D 诊断；
- **`ecm_05687`**：σ 比真噪声大 5 dec ⇒ 整体似然被抹平 ⇒ 触顶。

**推论（重要）**：合成谱的 σ 是构造时给定的（2.4e-5），任何"按 `|Z|` 或 `zmax` 猜 σ"
的口径（`free` 与 `perpoint` 都是）都会差几个数量级。所以**合成谱只能验证"给定真 σ
时能否恢复参数"，不能验证"σ 估计本身"**。21 条里"合成 0.08%"因此不可解释。

**其余 4 条不一定是同一原因**：`ecm_04375` 的 std rms 是 1.62%（不是 0.001%），
涂层的 std rms 是 12–28%，它们更像表达力/多峰问题，不是似然被抹平。
未逐条取真值噪声，故本表不对它们下"σ 失配"的结论。

### 3.3 钝化反而是最干净的

钝化 3 条本就不在异常列表（R̂ 1.0017–1.0068，div 全 0）。也就是说
**69.15% 这个数字是在采样干净的前提下得到的**，它是真的结构问题，
不是"后验没收敛"的产物。这与 §3.1 的涂层形成对照：同样超表达力，
钝化的采样不炸、涂层炸——差别在真值拓扑（钝化 3 CPE、涂层 5 CPE 双层嵌套）。

## 5. 边界

1. 只重跑了 **best 候选**。若 standard 下最优模型会换（例如涂层该换族），本表看不到。
2. 只用了 seed=0。`B3b` 已知 seed 敏感性，单 seed 不足以判"收敛"，只能判"不收敛"。
3. `div=2` 的两条（腐蚀 #1、#2）按判据归"轻发散"，严格说仍未满足 §13/§14 的
   `div=0`；引用时应同时写 `div` 值。
4. standard 的 `target_accept=0.98` 与 quick 的 0.9 不同，两列不是"同一算法加样本量"，
   而是**两套预算**。这符合项目既有定义，但解读时要记住。
5. 本表不构成"模型选择结论"。它只回答"这些数字能不能用"。

## 6. 层结构：这次复核说明需要补一个"层 0"

之前把工作分成三层（噪声诊断 / 噪声建模 / 模型选择）。这次复核暴露了更前置的一件事：
**采样不干净的谱，讨论后面三层没有意义**。所以实际是四层，层 0 是一道门。

| 层 | 回答什么 | 准入判据 | 失败处置 |
|---|---|---|---|
| **0 采样有效性** | 这次 run 的后验可信吗 | `R̂<=1.05` 且 `div==0`（§13/§14 既有口径） | 标 `non_evaluable`，rms/acf 一律不引用 |
| 1 噪声诊断 | σ 尺度与 `|Z|` 范围是否失配 | 只读观测，**不设门** | 记录 `noise_scale_diag` |
| 2 噪声建模 | 真实 σ(f) 是什么形式 | 需要同状态重复谱 | 未启动 |
| 3 模型选择 | 用哪个族 / 是否 perpoint | 独立预注册 + 留出验收 | 未启动 |

四条防混层的硬约束：

1. **层 0 是门，不是指标**。它只输出"能不能用"，不输出"模型好不好"。
   把 R̂ 当模型优劣读，就是混层。
2. **层 1 不得解释层 0**。D 大不能用来解释 R̂ 差——本轮的 `r=0.05` 已经否掉这条路。
3. **层 1 不得直接驱动层 2/3**。D 到阈值只落字段，不触发 perpoint（A 的冻结承诺）。
4. **层 3 不得回灌层 0**。不能因为"换个模型 R̂ 就好了"就认为原谱可用——
   那是把"模型能吸收"当成"数据可信"，正是 `ecm_05687` 的陷阱（rms 0.00% 而 R̂ 176）。

这次复核就是层 0 的一次完整实例：14 条进门，9 条通过（7 干净 + 2 轻发散），
5 条挡在门外。**21 条里凡是在层 0 被挡的，都不该出现在摘要数字里。**
