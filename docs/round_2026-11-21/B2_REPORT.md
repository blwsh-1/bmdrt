# B2 参数恢复：可执行的基准判据

> 由 `b2_baseline.py` 生成（幂等，数据变直接重跑）。判据在脚本头部预注册。
> 规格来源 `BASELINE_SPEC.md` §3；层 0 口径来源 `LAYER0_SUMMARY.md`。

## 0. 一句话

**B2 = 造一条已知真值的谱，用同族 + 同 sigma 拟合，逐参数看能否回到真值；回不到就不许说模型改进。**

## 1. 规格 A 与 B2 是同一把尺子

规格 A 原文是 `Δ|Z|_k >= 10σ`，本脚本写成 `snr_k = |ΔZ|/σ >= 1`，其中 `ΔZ` 由**扰动一步** `δ_k` 产生（log 参数 ×1.10，有界参数 +0.10×支撑宽度）。
对电感 `ΔZ = 0.1·ωL`，故 `snr>=1 ⇔ ωL >= 10σ` —— 与原文等价，不是放宽。
统一成"一步"的形式之后，`n/phi/zeta` 这类无量纲参数也能算，且 B2 的容差直接就是同一个 `δ_k`。

**判据 v2**（`RULE`）：点估计落在一步内 **且** 90% 区间相对宽度 `(q95−q05)/|median| <= 1.0`。后一条是看到首轮结果后补的，补的方向是**更严**，且所有已存结果都从落盘的区间重算（`rescore_row`），不重拟合、不改 sigma、不改容差。

v1 只判点估计落在一步容差内。首轮 adr 出现 `R_ad` 偏 +11%（超 10%）而 90%CI=[55,906] —— 点估计本身无意义，被判成"恢复失败"会误导（真因是参数退化，不是采样或偏差）。v2 增加 `ci_rel_width <= 1.0` 的必要条件，并对所有已存结果重算，不重拟合、不改 sigma、不改容差。

读法：R̂ 随预算下降 ⇒ 原来那条是 `budget_limited`（B4 可救，B2 只是暂缓）；R̂ 不降 ⇒ 结构不可辨，B2 永久 `non_evaluable`。**注意**：这一档不能拿来给 B2 判据加分——判据在 `standard` 上定，换预算只是定位失败原因。

- `budget_limited`（deep 下 B4 转通过）：`nested_L2_L`, `adr_series`。

## 5. 结论只到哪

- 负对照被拦在拟合之前 ⇒ 规格检查本身有效（它不是"跑完再看"的事后解释）。
- `unresolved_by_design` 的参数（未声明 target 或 snr<1）**不计入** B2，也不计入失败。
- B4 未通过时，B2 的数字标 `non_evaluable`，**不得单独引用**（层 0 的口径）。
- 每个配方 1 个 seed、1 个频率窗、复高斯等方差噪声 ⇒ 只说明"这条配方在该条件下能否恢复"，不是成功率。
- **B3 未做**（`--b3` 默认关）：quick 的排名不足以支撑族识别结论。

## 6. 未做的部分与前置条件

| 项 | 为什么没做 | 前置 |
|---|---|---|
| B3 族识别 | quick 的"通过"已被证明不可信（钝化 #1） | 定 B3 用哪个预算、以及 elpd 在 perpoint 下的可比性 |
| 多 seed | 单次结果不能报成功率 | 每配方 ≥5 seed，成本 ×5 |
| 换频率窗 | tau 的可见性随窗口变 | 至少两档窗口 |
| voigt 的 prior z | `bm_core.make_model` 的 5 条先验没有表可读 | 抽一张 `voigt_prior_table`（会动生产文件，需单独授权） |
