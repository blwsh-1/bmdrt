## 3. 第三个问题：并联的直流极限物理上不可辩护（今天新算）

`Z_ad = R_ad·jωτ/(1+jωτ)` 在 ω→0 时 → **0**，不是 → `R_ad`。所以
`adr = Rs + [CPE ∥ Rct ∥ Z_ad]` 在直流时被 `Z_ad` **短路整个并联节点**：

| 结构 | ω→0 的 `Re Z`（同参数 `Rs=50 / R1=100 / R_ad=100`） | 含义 |
|---|---|---|
| `adr` | **50.0 Ω = `Rs`** | 吸附支路把 CPE **和** Rct 一起短路 |
| `nested/L=1 + parallel` | 150.0 Ω = `Rs+R1` | 只短路到 R1 |
| `nested/L=1 + series`（文献结构） | 250.0 Ω = `Rs+R1+R_L` | 内部串联不通直流 |

**"吸附"让电极在直流下变成短路**——这不是任何真实吸附过程的行为。文献用
`R_ads+L_ads` 串联正是因为低频要收敛到有限电阻（吸附饱和）。

> **分寸（2026-11-22 补）**：`Re Z→Rs` 是**数学极限**，只在 ω→0 成立。在有限窗口里
> 是否真的短路 `Rct`，取决于 `τ_ad`：`f=0.01 Hz` 时 `τ_ad≤0.1 s` 已短路、`τ_ad=10 s`
> 则只有 1.06×（见 `round_2026-11-22/TOPOLOGY_LIMIT_CHECK.md` §4）。昨天在
> `AZ31-12Li_5` 上拟合的 `τ_ad=0.82 s` 在窗口底端是 166 Ω（与 `Rct=115` 同量级，**未短路**）。
> 所以更准的说法是：**`Z_ad` 随频率降低单调减小、走向"往下"，而真实吸附走向"趋饱和"
> ——方向相反**。这比"短路"更难在单条谱上看出来：不是某个点错，是整个低频段的斜率方向错。

> 订正说明：`TOPOLOGY_AUDIT.md` §3.5 原稿写的 `Z_DC = Rs + (Rct∥R_ad) = 100 Ω`
> 是错的，已按 `dc_limit_check.py` 的数值订正。机制比原稿更极端（50 vs 150，3 倍），
> 方向一致。

## 4. 但有一件事要说公平

**立项动机本身是合理的**，不是"为了凑覆盖地图"（P-1 明令禁止）：

- 目标是对标外部模型 `Rs+[CPEdl∥Rct]∥(R_ads+L_ads)`（AZ31-12Li_5 上 Rwp ≈ 8.5%）
- 有个"能不能吃下那个模型"的框架，是有价值的
- 而且**外层并联是对的**——文献也是与 `CPEdl∥Rct` 并联

**错的只有一处**：吸附支路内部用了 `R_ad∥L_ad`，而文献是 `R_ads+L_ads`。
一处选择，把低频极限整个反了过来。

## 5. 现在应该怎么办

### 5.1 不需要"修 adr"，因为文献结构早就在代码里

```
nested(layers=1, branch="series") = Rs + [CPE ∥ (R1 + R_L + jωL)]
                                 → ω→0 = Rs + R1 + R_L   ✅ 与文献低频极限一致
```

也就是说 §5.3 要求的"串联吸附"**从来不需要新写**，`bm_top.z_nested` 里已有。
当年"是否补串联版"这个问题，正确答案是"已经有了，只是没被当成 adr 的替代品来用"。

### 5.2 该做的三件（都不动生产）

| 动作 | 内容 |
|---|---|
| **A** | `ADMISSION.md` §5.3 那条加日期补注：前置条件**已被反证**（§9.4.42.1 等价、今天 12/13 条串联更好）⇒ 裁决为"不接生产、保持 `exploratory`、不进默认候选集、只作负对照与外部模型对标器" |
| **B** | `adr` 的用途重新定位写进 registry notes（已做一半）；明确**不得用它下任何"族优劣"结论** |
| **C** | **新增一条立项硬门槛**：新族实现前必须书面回答三项——① 与最近文献结构的**逐项差异**；② **高频与低频极限对照**；③ 该差异在目标频窗内是否可辨识 |

C 是这轮最该留下的东西：**如果立项时被迫写"低频极限"，`Z_DC = Rs` 当场就会暴露**，
不必等到两周后算 12 条谱。

### 5.3 不该做的

- 不改 `adr` 结构（改了就是新族，要走完整准入）
- 不因为"12/13 输"就删它（三个非拟合用途仍成立：对标外部模型、表达"吸附致直流电导增加"这一类、现成欠定负对照）
- 不把"串联更好"升格为"串联正确"——§9.4.42.1 说两者在上界等价，今天的 12/13 是
  **同一批数据上的拟合优劣**，不是物理裁决

## 6. 一句话

**立项的问题不是"选错结构"，是"没有走自己定的门"。**
准入文档 11-12 就要求"先证明串联解释不了"，11-16 立项时没做，
而同一天的 §9.4.42.1 恰恰证明了串联能解释——**门是开着的，只是没人守**。
