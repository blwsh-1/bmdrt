**五条最要紧的**（下面 §2 有展开）：

0. **项目的两族就是教科书里的两套涂层模型**（书 p.160 图9.2.5）：对同一个"两个时间常数"的谱，书并列给出 (A) `Rs+(C_c∥(R_po+(C_dl∥R_f)))` 与 (B) `Rs+(C_c∥R_c)+(C_dl∥R_f)`，取舍依据是"**渗入是否均匀**"，不是谱形。(A)=nested、(B)=voigt。见 §2.K。
   **已把书里那句"同一谱对应两套电路"证成严格恒等**（§2.I）：在纯 RC、无感抗支路时，两族的阻抗函数**代数恒等**，参数映射唯一且闭式（`R1n=A²/den`、`τ2n=den/A`、`R2n=S−R1n`、`C1n=(τ1+τ2−τ2n)/S`），除 `τ1=τ2` 退化外四个参数全正；4000/4000 随机参数有全正解，残差 2.9e-9。
   **但要分三层说**，不能一律讲"两族等价"：① 纯 RC 无支路 → **恒等**（这条不可分）；② CPE 指数 ≠1 → 恒等失效，`n=0.95` 残差 4%、`n=0.9` 残差 7%（真实噪声 1.2% → 弱可分）；③ 带 L 支路 → `Im` 符号与高频极限**双重不相容**，**拓扑级不可能**。
   **「那打开 `include_L` 呢」——也不行，而且补错了频段**（§2.I ⑥）：`voigt+L` 在 `s→∞` 是**一阶极点**（`Z~sL`，发散），nested 是**一阶零点**（`Z~1/(sC1)`），阶数不同就不可能相等；更致命的是串联 `jωL` 的贡献**随频率单调升**，在 0.01 Hz 只有 `1e-8` 量级，而 AZ31 的低频感抗是 29–1123 Ω，**差 6.9–8.5 个数量级**。要补低频得开 `adsorption="RL"`（元件与 nested 的 parallel 支路相同），`bm_select.fit_voigt` 两个开关都没传。
   ⇒ **对 AZ31 这类谱，两族是「不相交」而不是「不可分」**；`indistinguishable` 的来源是有限频窗与采样降级，不是数学恒等。
1. **书 p.115–117「混合电位下 EIS 的退化」**：AZ31 全测于腐蚀电位附近 = 混合电位，此时某个状态变量（如吸附物种）若对阳极/阴极两个反应的影响相消，就会**在谱上完全消失**，实测时间常数个数少于过程数。这给 B2 的"正向命中 0 / 降级 8/20"一个**与采样无关**的解释。书里还给了破解法：**外加电流极化把电位推离 E_corr**（但要分级小幅，见第 4 条）。
2. **AZ31 的低频尾不可能是扩散**（书 p.106–107）：`W/O/T` 的虚部在低频全为负，实测 18/18 条在 0.01 Hz 处虚部为正。且 Warburg 公式要求"除 E 外没有别的状态变量"，有吸附就越界。→ `Ws` 这条线在这批数据上应当**收口**，不是继续调判据。
3. **感抗支路的原型是 `R_t ∥ (R₀ + L)`，项目把支路串在 R₂ 后面了**（**此条改过两次，§2.B 是最终版**）：书 p.51 式(4.2.9) 给出 `B>0`（感抗）的确切解 `Y_F = 1/R_t + 1/(R₀+jωL)`，`R₀=a/B>0`、`L=1/B>0`，电路是 **`R_t` 与 `(R₀+L)` 并联**，与 S1875/Epelboin 完全一致。项目写成 `R₂ + (R_L + jωL)`（串联），端点行为与物理解读都不同：并联是"两条电流通路"，串联是"膜层在界面之前"。另一条：**`R_ad ∥ L_ad` 在书里找不到原型**——书中的 L 无例外都与 R 串联。**（注：按 §2.K，项目这条"膜层在界面之前"的串联恰好就是涂层模型 (A) 的写法，所以问题不在"错"，而在"它描述的不是吸附"。）**
   补充：**AZ31 的谱型（高频容抗 + 低频感抗）属于书第 IVb 属，该属的电路本就含 `L>0`**，并给出 `L=R_t²B²/(|B|D−|A|T)` 与临界频率 `ω_c=[(|B|D−|A|T)/|B|]^{1/2}`；实测 18 条过零频率 0.139–1.389 Hz（中位 0.37）与书中算例 0.14–0.39 Hz **同量级**。所以"用 L"有据，见 §2.N。
4. **感抗弧的出现与消失有明确的电位条件**（书 p.180–181）：`θ < k₊₁c_A/[2(k₊₁c_A+k₋₁)]` 时出感抗弧；极化到 `θ≈0.5` 时 `B` 由正转负、**感抗弧消失**。与 7.3 的"推离 E_corr"方向相反 → 实验必须**分级小幅扫**，不能单点推。
5. **`CPE(0.5) ≡ W` 是恒等式**（书 p.138），所以"CPE(.5) 与 Warburg 分不开"不是缺陷；"Ws 死结"可降级为"窗口未覆盖 T 的 W→RC 转折"这一**可检验条件**。另有一条并联元件的通则可直接借：书 p.157"复合元件主要显示**阻抗小的那个元件**的特征"——这就是"参数定不住"的物理原型。

### 1.1 lazanas & Prodromidis 2023（教程，17 节）

覆盖面最广的一篇，按 17 节组织：正弦信号/复数/相量 → 传递函数 → 阻抗与电学元件 → EIS 原理 →
数据有效性 → 等效电路仿真 → 应用（腐蚀/能源/生物传感）。

与项目直接相关的六条：

1. **§15 感抗行为分两类**（P21）：
   - **高频感抗 = 仪器伪影**（导线自感/互感、参比电极高阻、仪器带宽）。表现为紧贴 Z″ 轴的直线；**低阻池（电池、超电容）更明显**。
   - **低频感抗环 = 吸附中间体弛豫**（"大多数电化学家的共识"）。文中明确点名 **镁在 0.5 M Na₂SO₄ 中的低频感抗环归因于 MgOH_ads**（ref 78 = Pebere 等）。→ 这是 AZ31 低频感抗的**机制性文献锚点**。
2. **§8 电路不唯一**（P8）：明文 —— *"there is not a unique model circuit for a given impedance spectrum … some circuits are mathematically identical"*，配 Figure 7 举例：`R1(C1R2)(C2R3)(C3R4)` 与 `R1(C1[R2(C2[R3(C3R4)])])` 给出**同一张谱**。并给 Boukamp CDC 记法（`(RC)` 并联、`[R(RC)]` 嵌套）。
3. **§15 感抗环出现的条件**（P21）：两步骤反应 `A ⇌ A(I)ads → A²⁺`，只有当测量过程中 k_a 与 k_d 的大小关系被电压**动态反转**时，感抗环才出现；若全程 k_a≫k_d 或 k_a≪k_d 则不出现。
4. **§16.5 KK 检验的实值门槛**（P23）：pseudo-χ² <1e−6 优、1e−5~1e−6 合理、1e−4~1e−5 勉强、更高为差；残差应随机分布于零附近；RC 段数默认等于数据点数，**噪声大时应减少段数以免把噪声拟合进模型**。
5. **§17 明示"任何数据集都能被复杂电路拟合"**，要求电路尽量简单且每个元件能对应到物理过程。
6. CPE：`Z = 1/[Y₀(jω)ⁿ]`，n=1 理想电容、n=0 电阻、n=0.5 半无限 Warburg；θ = (1−n)·90°。

### 1.2 S1875 柠檬酸盐镀镍（吸附中间体的完整推导）

这篇的价值不在结论，在**推导链**——它把"两步放电 + 吸附中间体"推到显式阻抗式，和项目 nested 族的物理来源直接对应。

- 机理：Ni²⁺ + H₂O → Ni(OH)⁺ + OH⁻ →(e) Ni(OH)ads →(e) Ni。速率控制步为第一次电子转移。
- 定义 A = −∂I₁/∂θ ≥ 0、B = ∂I₂/∂θ ≥ 0（θ 为 Ni(OH)ads 覆盖度）。
- 时间常数 **τ = q/(A+B)**；法拉第导纳
  `Y_F = 1/R_ct + (1/R_ct1 + 1/R_ct2)(1 − …)/(1+jωτ)`
  等价于 **`Y_F = 1/R_ct + 1/(R₀ + jωL)`，其中 L = R₀τ**。
- 于是总阻抗 `Z = Rs + 1/(jωC_d + Y_F)`，即 **`C_d ∥ R_ct ∥ (R₀ + jωL)`**。
- **A > B → 感抗环**（第 4 象限，闭合半圆，低频回到实轴）；**A < B → 两个容抗弧**（等效为 `R_a ∥ C_a`，R_a = −R_ct²/(R_ct+R₀)）。
- 实测（RDE、0.01 Hz–100 kHz、5 mV）：全部电位下均为"高频容抗弧 + 低频感抗环"；R_ct 随过电位增大而减小，C 基本不随电位变（~6–10 μF）；柠檬酸钠使 R_ct 从 19.2 Ω 升到 31.2 Ω、C 从 10.6 降到 5.6 μF。
- 注意：原文**只列表了 Rs/Rct/C，未给 R₀ 与 L 的数值**，所以拿不到 L 的量级参考。

已核读的关键页：

**p.46（R_p 与 R_t 的差别）**
- `1/R_t = (∂I_F/∂E)_ss`，**恒为正的有限值**。
- `R_p` = 稳态极化曲线在 E 处的斜率，**可为负、可为无穷大**。
- 原文："电化学阻抗谱图上 R_p 的特点如：是否为有限值、是正值还是负值？如为正值，比 R_t 大还是小？等等，**是区分阻抗谱图类型的重要依据之一**。"

**p.47–49（一个状态变量 → 完整三分支分类）**
- 一般式 `Y_F = 1/R_t + B/(a + jω)`；R_t、a 恒正，**只有 B 可正可负**。
- B<0 时 `Z_F = R_t + (R_a ∥ C_a)`：
  - `R_a = R_t²|B| / (a − R_t|B|)`，`C_a = 1/(R_t²|B|) > 0`
  - ① `a − R_t|B| > 0` → R_a>0 → **两个容抗弧**，`R_p = R_t + R_a > R_t`
  - ② `a − R_t|B| = 0` → R_a=∞ → `Z_F = R_t − j/(ωC_a)`，**R_p = ∞**（阀金属阳极氧化）
  - ③ `a − R_t|B| < 0` → **R_a < 0** → `R_p = −aR_t/(R_t|B|−a) < 0`，**实部进入负半轴**（Fe 及合金的活化—钝化过渡区）。原文强调"负的等效电阻是符合稳定性条件的"。

**p.50–58（第 4.2.3 节 需进一步讨论的几个问题）——四条落地判据**

- **① 感抗的来源清单（p.53）**：给出 4 类导致 `B>0` 的电极过程，其中两类最常用：
  - **中间产物型**：`R + A → P₁ + e`（i）＋ `P₁ → P + e`（RDS）（ii）。`b = K(1/R_t1 − 1/R_t2) > 0`（因 (ii) 是速控步，`R_t2>R_t1`），且 `m ≈ (∂I₂/∂X) > 0` → **B=mb>0 → 感抗**。
  - **还原性吸附缓蚀剂型**：`M + A + e ⇌ (MA⁻)_ads` ＋ `M → Mⁿ⁺+ne`。
  - **孔蚀活性点型（p.55）**：钝化膜厚度 l 是状态变量，`m=(∂I_F/∂l)<0`；Cl⁻ 富集的活性点处膜溶解快、导纳远大于其余部分 → **EIS 主要反映孔蚀活性点**；该处 `b<0` → **B=mb>0 → 感抗**。
- **② `C_a` 恒正、`L` 恒正，只有 `R` 可以为负（p.56–57）**：
  - `C_a = 1/(R_t²|B|) > 0`，原文："**无论是否满足稳定性条件，等效电容与纯电容一样，都不可能为负值**"。
  - `L = 1/B > 0`，而 `R₀ = −|a|/B < 0`（`a<0, B>0` 时）。
  - → **"负电容/负电感"在数学上就不出现**；能变号的只有电阻。这给 p.59 的告诫补上了公式依据。
- **③ 一条可直接实现的稳定性诊断（p.57 原话）**：**"当发现 `R_p>0`、且不存在感抗、而 `R_p<R_t` 时，就要检验阻抗测量是否满足稳定性条件。"** 这是书里唯一一条"从谱形反查测量合法性"的具体规则。
- **④ 等效电路与机理不一一对应（p.55–56 原话）**："在反应机理没有改变的情况下，由于状态变量的数值水准不同，相应的 EIS 可以相当于不同的等效电路"；并给出 **"故等效电路与反应机理不是一一对应的"**。同一机理、同一套速率常数，只因 `θ` 大小不同：
  - `θ < k₊₁C_A/[2(k₊₁C_A+k₋₁)]` → `m>0` → `B>0` → **感抗弧 + 等效电路含电感**
  - `θ` 大 → `m<0` → `B<0` → **低频容抗弧 + 等效电路只有电容、没有电感**


**p.41（稳定性条件）**
- 一般形式 `Y_F = 1/R_t + Σ_i B_i/(a_i + jω)`（多状态变量、互不耦合）。
- 稳定性要求雅可比矩阵本征值为**负实数**：即 `a_i > 0` 且为实数；（E,X₁,X₂）情形要求 `D>0、T>0、T²≥4D`。
- **关键**：稳定性只约束 a_i，**不约束 B_i 的符号** → 负阻合法。

**p.59（明确警告）**
- 若 a<0、B>0 且 R_tB>|a|，谱点会散布四个象限（图 4.2.9）。原文："…其根本原因则是电化学阻抗谱测量的**稳定性条件未被满足**。人们将这种特别的阻抗谱与体系不稳定相联系是合理的，但**引入负电容的等效元件则缺乏理论依据**。故在阻抗谱分析中…**不宜随意引入负电容或负电感的概念**。"

**p.115–117（第 7.3 节 混合电位下 EIS 的退化）——本批材料里最重要的一条**

AZ31 在腐蚀电位下正是**混合电位**（Mg 阳极溶解 + 析氢两个电极反应同时进行），这一节直接针对这种情形：

- 正常情况：EIS 时间常数个数 = 状态变量个数。
- **退化**：实测的时间常数个数**少于**状态变量个数。原因是某个（E 以外的）状态变量**同时影响两个电极反应**，而两个影响相互抵消。书中给了两个已解出的情形：
  - ① **缓蚀剂/吸附物种**：同时降低阳极与阴极反应速度，降幅绝对值相同、方向相反 → 式(7.3.1) `(∂I_F1/∂X) = −(∂I_F2/∂X)` 成立 → `B = 0` → `Y_F = 1/R_t = 1/R_t1 + 1/R_t2`，**整个谱只剩一个时间常数**。吸附过程确确实实在发生，但在谱上完全看不见。
  - ② 第 7 种情况：`m₁₁ = −m₂₁`（X₁ 对两反应的影响绝对值相同、方向相反）→ X₁"似乎消失了"，时间常数从 3 个降到 2 个。
- **破局办法（书中原话）**："只要式(7.3.3)的条件被打破，例如，**用外加电流极化的方法使电极电位明显偏离混合电位**，状态变量 X₁ 的影响就会在阻抗谱上反映出来。"
- 直接推论：**在混合电位下，"弧的个数"不等于"过程的个数"**。拿弧数/时间常数个数去选拓扑，是病态做法——这是书里给出的、不依赖采样的结构性理由。

**p.128–138（第 8.3 节 从阻抗数据求等效电路）**

- **8.3.1 电路描述码（CDC，Boukamp）** 四条规则：串联 → 符号并列（`RLC`）；并联 → 括号内并列（`(RLC)`）；复杂电路 → 先拆成两端的"盒"逐层分解；**奇数级括号 = 并联，偶数级括号 = 串联**。例：`R(Q(W(RC)))`。
- 求值算法：自最高级（最内层）向内推进，**奇数级算导纳、偶数级算阻抗**，逐级回代。
- **这份材料的实际用途**：CDC 是**拓扑的规范编码**。把 voigt 的 K 个 HN 与 nested 写成同一套 CDC，就能机械地判断两族是否同构——把"两族是否等价"从经验判断变成可计算。项目的 `label`（`K=1` / `parallel/L=2`）目前不是规范编码，两族无法直接比对。
- 8.3 后半是经典的**分段拟合/圆拟合**路线（高频段常可简化为 `R(RQ)` 或 `(RQ)`；`W/O/T` 主要影响低频；线拟合与圆拟合是解析基础）。原文自己也承认这条路的主观性："选不同的点，可以得到数值差别比较显著的估算结果"、"要选比较有把握属于一条直线的实验点"。这正是后来全局 NLLS / DRT 取代它的原因，也说明项目的全局拟合路线方向是对的。

**p.138（CPE 与 W 的关系、T/O 的插值）——直接回应项目的「Ws 死结」**

- 原文："等效元件 Q 的参数 **n=0.5 时，它就成为等效元件 W**"。二者函数形式同为 `1/(Y₀√(jω))`，**是同一个元件**。所以"CPE(0.5) 与 Warburg 分不开"不是拟合能力问题，是**定义使然**，不该再当缺口追。
- 更要紧的是 T/O 的插值性质：T（阻挡）与 O（渗透）在**低频**趋近 RC 复合元件（近垂直直线 / 半圆），在**高频**趋近 W（−π/4 斜线）。→ **T 本身就在 W 与 RC 之间插值**，其可辨识性取决于测量窗口是否覆盖了这个转折（`B√(jω) ~ 1`，对应拐点频率 `f_c`）。
- 于是"`Ws ≡ 窗外 R∥CPE(.5)`"可以改写成一条**可检验条件**：窗口覆盖转折 → `τ_D` 可定；窗口只盖住 W 段 → 与 W 不可分；只盖住 RC 段 → 与 RC 不可分。这与项目已有的 `f_cut` 开关口径一致，不必再记成"死结未解"。

**p.59–75（第 4.3 节 两个状态变量 X₁、X₂）——一套完整分类，且**确实推出了含 L 的等效电路****

一般式 `Y_F = 1/R_t + Y(ω)`，`Y(ω) = [A(D−ω²)+ω²BT]/[(D−ω²)²+ω²T²] + j·ω(BD−AT−ω²B)/[(D−ω²)²+ω²T²]`（式 4.3.2），
`R_p = D/(D+R_tA)·R_t`（式 4.3.3）。按 A、B 的符号分 4 大类，再按 `AT` 与 `BD`、`D` 与 `R_t|A|` 的大小分属：

| 类 | 条件 | 谱型要点 | 等效电路 | 关键式 |
|----|------|---------|---------|--------|
| I | A>0, B>0 | `R_p < R_t`；任一频率下导纳虚部为负 ⇒ 含感抗 | 图4.3.2：**两个 R–L 串联支路并联**（`L₁+L₂`、`R₁+R₂`） | `L₁≈1/B>0`、`R₁≈T/B>0` |
| I | A>0,B>0 且 `AT−BD<0` | 谱点分布在两个半平面（图4.3.3） | 图4.3.4：`R_L + L` **串联**再与 `(C∥R_c)` 并 | `C = B²/[A²+B(BD−AT)] > 0` |
| II | A<0 系 | `D−R_t|A|` 的符号再分三属；`>0` 时**低频容抗弧转高频感抗弧**，临界频率可算（书中例 0.39 Hz），`R_p > R_t`；`<0` 时 `R_p<R_t` 但不为负 | 图4.3.5：`R_t ∥ [R_L + L + (C∥R_c)]` | 见 p.64/p.66 对应式 |
| III/IV | B<0 各种 | 出现 `R_p < 0` 的谱型（图4.3.13：`R_p = −15`）、`R_p = 0` 的退化谱（图4.3.15） | 图4.3.17：`C ∥ (R_c + R_L + L)` 一类；IVa 属为两条 `R+C` 支路并联 | `R_L/(LC) = R_t²|A|`、`1/C = R_t²|B|` |

两条必须记住的结构性事实：

1. **同一个拓扑（图4.3.5）覆盖 II 类下的三个子属**，靠的是元件之间满足不同的不等式（`R_t²C ≷ L` 之类）。即**电路拓扑不足以决定物理类别**——反过来也成立，同一物理类别可写成不同拓扑。这是"拓扑↔谱不唯一"的**双向**版本，比 lazanas §8 的单向举例更强。
2. **L 在书中是合法等效元件**（I 类、II 类、IVa 属都出现），但它不是物理线圈，而是**两个耦合弛豫的等效**；而且每个电路都配了把元件值绑定到 `(A,B,D,T)` 的关系式——不是任意 `(R,L)` 组合都对应一个可实现的机理。

**逐图核过之后的定量实据（p.63–73）**

- **II 类（A<0,B>0）三个子属共用图 4.3.5 一张电路**，只差一条不等式 `D − R_t|A| ≷ 0`：

  | 子属 | 条件 | 参数 | 临界频率 | `R_p` |
  |------|------|------|---------|-------|
  | II a | `D−R_t|A|>0` | R_t=10, C_dl=1e−4, A=−0.1, B=1, D=4, T=20 | 0.39 Hz | `>0` 且 `>R_t` |
  | II b | `D−R_t|A|=0` | 同上但 D=1 | 0.28 Hz | **∞**（`R_c` 也 ∞） |
  | II c | `D−R_t|A|<0` | R_t=20, D=1, T=6 | 0.20 Hz | **−20**（`R_c` 也负） |

- **IVa 属（A<0,B<0 且 `|A|T−|B|D>0`）的电路是图 4.3.11 = `R_t + (C₁∥R₁) + (C₂∥R₂)`** —— 这就是项目 **voigt 族（K=2）** 的严格出处。且它要求 **`C₂≫C₁` 且 `R₂C₂≫R₁C₁`（两个 R∥C 回路的时间常数相差较大）** 才能按给出的式子估算元件值。
  - 同一张图 4.3.11 又按 `T−R_t|B|`、`D−R_t|A|` 的符号**再分 5 种型式**，`R_p` 依次为 **+26.7 / 负（R₂<0）/ −80 / ∞** 等。

- **IVb 属（`|B|D>|A|T`，高频容抗、低频感抗）——正是 AZ31 的谱型**，电路含 L 且各元素有闭式：
  `C = 1/(R_t²|B|)>0`、`R_c = R_t²|B|/(T−R_t|B|)`、**`L = R_t²B²/(|B|D−|A|T)>0`**、**`R_L = R_t²AB/(|B|D−|A|T)>0`**；
  临界角频率 **`ω_c=[(|B|D−|A|T)/|B|]^{1/2}`**；`T−R_t|B|=0` 时曲线在 `ω_c` 处**不连续**。

**p.75（第 4.4 节 其他情况）——最实用的一条总结**

- n 个互不耦合的状态变量 ⇒ `Y_F = 1/R_t + Σ B_i/(a_i+jω)` ⇒ **EIS 共有 n+1 个时间常数**。
- 时间常数相差 ≥5 倍时，谱上能分辨 **n+1 条**容抗或感抗频响曲线。
- **`B_i > 0` 对应的曲线是感抗弧，`B_i < 0` 是容抗弧。**
- 高频段第一条容抗弧一般是 `R_pC_dl` 复合元件。
- **方法论取舍（原话要点）**：纯法拉第阻抗用**数学模型**更优越；但**涉及非法拉第电流时数学模型往往无解**（涂层电容、涂层电阻都随非法拉第电流变，无函数关系）→ 此时**等效电路方法更合理**。这给项目"两族并存"提供了正当性：voigt 族偏数学模型、nested 族偏等效电路，本就该并存而不是二选一。

**p.84–96（第 6 章 由扩散过程引起的法拉第阻抗）——O 与 T 的严格形式，附一个更好的判据**

三个元件的精确式（`B = l/√D`，`z = √(2ω/D)·l`）：

| 元件 | 边界 | 阻抗 | tan φ | `ω→0` 极限 |
|------|------|------|-------|------------|
| **W** | 半无限 | `Z_0 (jω)^{−½}` | **1（恒 45°）** | `→∞`，`R_p=∞` |
| **O** | 有限层·**可渗透** | `Z_0 (jω)^{−½} **tanh**(B√(jω))`（6.3.4） | `(sinhz−sin z)/(sinhz+sin z)`（6.3.9） | **等效为 R 与 C 并联**，`R_p=R_t+R` 有限（6.3.13–15） |
| **T** | 有限层·**阻挡** | `Z_0 (jω)^{−½} **coth**(B√(jω))`（6.4.5） | `(sinhz+sin z)/(sinhz−sin z)`（6.4.8） | 纯电容，`Z_d→∞`，`R_p=∞` |

- O 的低频等效参数：`R = γR_t|I_F|l/(nFC_sD)`、`C = nFC_s l/(3γR_t|I_F|)`，`R_p = R_t(1 + γ|I_F|l/(nFC_sD))`。
- 高频端 O、T **都趋于 45°**（`z` 大时两者都回到 W）。**差别只在低频**。

**由此得到一个比"阈值"稳得多的判据（低频相位趋势）：**

| 低频 `tan φ` 走向 | 判为 |
|---|---|
| → 1（保持 45°） | W（半无限） |
| **→ 0** | O（可渗透有限层，`R_p` 有限） |
| **→∞**（趋于 90°） | T（阻挡有限层，`Z_d` 发散） |

这是**趋势判据**，不是阈值判据——正好绕开项目记忆里"Bode 相位不能当判据"的坑（那条针对的是用相位的**绝对值**去判 Ws 幅度，被 `R_inf` 平移打偏；这里看的是**低频端的走向**，平移不改趋势）。

**p.092 另有一条检测"隐藏状态变量"的办法**：Nyquist 上看不出第二个时间常数时，看**相位谱 `φ–log f`**——图6.2.5(b) 在 `f≈0.05 Hz` 出现一个**小峰**，即"除 E 外还有一个状态变量 X"。这与 §2.G 的"退化"互补：退化是变量被压掉，这个是变量露头。

**p.106–107（第 6.8 节 几个值得注意的问题）——直接判定 AZ31 的 Ws 问题**

① 扩散阻抗幅值总**正比于**法拉第阻抗 `Z_F⁰`，不能脱离 `Z_F⁰` 单独看。
② **Warburg 公式只适用于一种特殊情况**：平面电极 + 半无限扩散，**且要求对频响有影响的状态变量只有电极电位 E**。原文："倘使除 E 外还有其他对阻抗频响有影响的状态变量，Warburg 公式并不适用。"表面很粗糙时 Fick 定律也不能简单表示，谱也会偏离 Warburg。
③ **扩散阻抗直线偏角小于 π/4** 有两成因：除 E 外还有引起感抗弧的状态变量（`B>0`）；或平面电极表面粗糙到扩散部分相当于球面扩散（图6.8.2 给出 r₀=0.1/0.05/0.02/0.01 cm 的偏角都 <π/4，且 r₀ 越小越偏）。
④ **低频极限判据**：`f→0` 时 `Z_d→∞` 只发生在**阻挡层扩散(T)** 与**平面半无限扩散(W)**；其余（有限层 O 等）虚部→0、实部有限，可直接读出 `R_p`。

→ **对 AZ31 的推论**：`W、O、T` 三种扩散元件的虚部在低频**全是负的**。而实测 18/18 条在 0.01 Hz 处虚部为**正**且仍上升。所以 **AZ31 的低频尾在理论上不可能是任何扩散元件**，项目"18/18 判感抗、candidate 0/18"的结论被理论确证，不只是经验判据的结果。
→ 同时 ② 说明：**只要体系有吸附状态变量，拿 Warburg 公式去套本身就是越界**。AZ31 有 MgOH_ads（lazanas ref 78）→ Ws 判据在这个体系上的失效是**前提不成立**，不是判据调得不好。

**p.178（第 9.4 节 金属阳极溶解）**

通用两步机理：`M + A⁻(sol) ⇌ (IN)ads + e`（快，近平衡）→ `(IN)ads → P(sol) + e`（速控步）；
`I₊₁ = k₊₁,₀(1−θ)c_A·exp(α₁FE/RT)`。Cl⁻、Br⁻、SCN⁻ 等能吸附的阴离子都会形成吸附中间络合物——
即**卤素/阴离子吸附是低价金属阳极溶解的普遍形态**，与 4.2/4.3 的 B<0 分支对应。

**p.180–181（第 9.4.1 节）——低频感抗弧出现的力学条件，AZ31 直接可用**

对 `M + A⁻ ⇌ (IN)ads + e` → `(IN)ads → P + e` 两步机理，定义 `a = k₊₁c_A + k₋₁ + k₂ > 0`（满足稳定性）、
`m = k₂ − k₊₁c_A − k₋₁`（式9.4.15，**可正可负**）、`b > 0` 恒正 → **`B` 的正负完全由 `m` 决定**。于是：

- **`θ < k₊₁c_A / [2(k₊₁c_A + k₋₁)]` 时 `m>0` → `B>0` → 低频出现感抗弧**（式9.4.18）。
- `θ` 小 ⇔ 表面活性低 ⇔ **低极化电位**。原文："**在较低的极化条件下阳极溶解时，阻抗谱上低频部分容易出现感抗弧；而在高的极化条件下……低频部分容易出现容抗弧**"。
- 电位升高使 `k₊₁↑`、`k₋₁↓`，强阳极极化下近似 `θ≈0.5` 处 `B` 由正转负 → **感抗弧消失或转为容抗弧**。
- 阴离子浓度 `c_A` 增大使 `θ` 增大 → 更容易在低频出现**容抗**弧。
- 铁在硫酸介质中的实测证实了上述结论。

→ **对实验设计的直接约束**：书上 7.3 节说"极化偏离 E_corr 让隐藏状态变量显形"，9.4.1 节说"极化到 θ≈0.5 感抗弧反而消失"。**两股力方向相反**，所以"推离 E_corr"必须**分级、小幅**地扫，不能一次推狠——否则可能把要找的东西直接抹掉。这一条要写进实验方案，不能只写"极化"。

**p.182–183（第 9.4.2 节 钝化过程）**

- 三反应模型：`M → Mⁿ⁺+me`（无膜区）、`M + n/s·A^s⁻ → MA_{n/s} + ne`（成膜）、`MA_{n/s} → Mⁿ⁺ + n/s·A^s⁻`（膜化学溶解）；`θ` 为膜覆盖率。
- 简化到 `(E, θ)` 两个状态变量 → **两个时间常数**，`Y_F = 1/R_t + B/(a+jω)`，`a = K(k₂+k₃) > 0`。
- 关键：`m = −(k₁+k₂) < 0` 恒负（式9.4.32）→ **`B<0` → 容抗弧**。即**钝化膜形成过程本身不产生感抗**；AZ31 若呈感抗，来源是溶解侧的吸附中间体，不是膜生长。

**p.155–162（第 9.2 节 涂层与涂层破坏过程）——项目的两族就是书里的两套涂层模型**

这一节把项目的两族**原样**给出来了，而且是同一张谱的两个候选模型：

- **图9.2.3（浸泡初期）**：`Rs + (C_c ∥ R_c)`——涂层电容与涂层电阻并联。
  原文一句可辨识性判据："涂层电容与涂层电阻二者是**并联**关系，故由两者组成的复合元件的阻抗**主要显示阻抗小的那个元件的阻抗特征**。当电容值很小而电阻值很大时，涂层相当于一个**纯电容**。"
- **图9.2.5（两个时间常数，浸泡中期）**给出**两套并列电路**：
  - **(A) 嵌套型**：`Rs + (C_c ∥ (R_po + (C_dl ∥ R_f)))`
  - **(B) 阶梯型**：`Rs + (C_c ∥ R_c) + (C_dl ∥ R_f)`
  - 原文："**如果电解质溶液是均匀地渗入涂层体系且界面的腐蚀电池是均匀分布的**，这种情况下，就要用图9.2.5中的模型**(B)** 来描述两个时间常数的 EIS 了。"

→ **(A) 就是项目的 nested 族，(B) 就是项目的 voigt 族（K=2 的串联 R∥C）。** 书里让两者二选一的依据不是谱形，而是**渗入是否均匀、腐蚀电池是否均匀分布**——即**独立的形貌/机理信息**。这是 §2.C「结构性不可分」最硬的教科书依据，也说明**再加采样、再换选择器都不会让这件事变好**。

其他几条可直接用：

- **p.158**：浸泡初期"涂层体系相当于一个纯电容，故求解**涂层电阻会有较大误差**，而涂层**电容可准确估算**"。→ 并联复合元件里，一支阻抗远小于另一支时，**大的那支参数定不住**。这是项目 `R1/R2` 共线、`cv(A_W)≤0.15` 那条 guard 的物理原型，可写进文档。
- **p.158**：渗到涂层/基底界面并形成腐蚀微电池后，**"阻抗谱就会具有两个时间常数"**；此时涂层表面尚未出现宏观小孔。→ "两个时间常数"是**界面开始反应**的标志，不是失效。
- **p.158**：阻抗法"极其灵敏地显示出涂层/基底界面的结构变化……**不但比肉眼观察优越得多，且比其他测量方法更灵敏**"。这是 EIS 的正当性说明，也可作"为什么不能只看 SEM"的依据。

- **p.162（图9.2.9）**：浸泡中期孔隙内是**"切向扩散"**，`log|Z|` 平台区斜率 **−0.5~−0.2**（不是理想 Warburg 的 −0.5）。→ 又一条"标准 Warburg 判据在涂层体系不适用"的理由，且斜率范围可作判据。

## 2. 与项目当前缺口的对照

下面每一条都标了**文献依据**、**项目现状**、**能做什么**。凡涉及改族定义/改门禁的，一律标「待批」，不自行实施。

### A. 高频感抗 = 仪器项，不是可选的模型自由度 —— 影响 `include_L` 写死关掉的代价

- **文献**：lazanas §15（P21）：高频感抗来自导线自感/互感与参比电极，**低阻池更明显**；`EIS基础` 第 3 页把"初始高频端在实轴以下"直接归为伪影并列出三条成因。
- **项目现状**：`bm_select.fit_voigt` 的 `include_L` 默认 `False` 且无调用点传 `True`（已核），所以 voigt 族**结构性无法表示高频感抗段**。
- **实测（本轮新做，18 条 AZ31）**：**3 条**谱的高频端落在感抗侧 ——

  | 文件 | 感抗点数 | 转折频率 | 该处 Z_re |
  |------|---------|---------|-----------|
  | `AZ31-12Li_0` | 前 9 点 | 7197→5180 Hz | ≈45.0 Ω |
  | `AZ31-8Li_0` | 前 9 点 | 7197→5180 Hz | ≈12.6 Ω |
  | `AZ31-8Li_150` | 前 5 点 | 26827→19307 Hz | ≈14.0 Ω |

  即最宽的那条有 **9/50 = 18% 的点**在感抗侧。且这 3 条的 `Zre_min` 恰好是 18 条里最小的三个（44.7 / 12.5 / 14.0 Ω）——**与"低阻池感抗伪影更显著"的文献说法一致**。
- **能做什么（不改族定义）**：在进入族比较前**预裁**高频感抗点（或按 `bm_kk.estimate_L` 先估一个仪器 L 再固定扣除）。比打开 `include_L` 便宜，也不触碰"改族定义"的红线。**是否做，待批。**
- **但适用范围要说清楚（§2.I ⑥ 已量化）**：这条路只能处理**高频**感抗段。串联 `jωL` 的贡献随频率单调升——在 1e5 Hz 对 `L=1e-6` 只有 0.63 Ω，在 0.01 Hz 只有 6.3e-8 Ω。而 AZ31 的低频感抗在 0.01 Hz 是 29–1123 Ω，比 `ωL` 的 2σ 上界还大 7–9 个数量级。
  **所以 A 条不能推广成"用 L 处理感抗谱"**：它只覆盖 18 条里的 3 条、每条 5–9 个高频点；剩下 15 条的低频感抗与它无关，也不会因为开了 `include_L` 而变得可表示。

### B. 感抗支路的原型是 `R₀ + jωL` 与 `R_t` **并联**；项目把它串在 R₂ 后面了

> **本条改过两次，这是最终版（第三版）。** 第一版说"合法等效是 `(R_a∥C_a)`、不该用真电感"——**错**；第二版说"L 合法但缺 `(R_a∥C_a)` 支"——**也不全对**。错因：只读到 p.49（那是 B<0 的容抗分支），没读到 p.51。读到 p.51 后结论才闭合。

**书 p.51 式(4.2.9)–(4.2.11)，B>0（感抗）的确切解：**

```
Y_F = 1/R_t + 1/(R₀ + jωL),   R₀ = a/B > 0,   L = 1/B > 0
等效电路（图4.2.5）：R_t  ∥  (R₀ + L)          符号 (R_t(R₀L))
书中算例：R_t=5, a=0.5 s⁻¹, B=0.01 → R₀=50 Ω·cm², L=100 H·cm²
```

对照两端：

| 情形 | 判据 | 等效电路 | 出处 |
|------|------|---------|------|
| **感抗** | `B > 0` | `R_t ∥ (R₀ + L)`，即 **L 与 R 串联，整体与 R_t 并联** | 书 p.51 式(4.2.9) |
| **容抗** | `B < 0` | `R_t + (R_a ∥ C_a)`，`R_a` 可负（负值→实部进负区） | 书 p.47–49 |

- **这条与 S1875 / Epelboin 完全一致**：那篇的 `Y_F = 1/R_ct + 1/(R₀+jωL)` 就是书的式(4.2.9)，`L=R₀τ` 就是书的 `1/B = a/B·τ`（τ=1/a）。两个独立来源互证，这条可以放心用。
- p.52 式(4.2.12) 还给了物理读法：`Y_F = 1/R_t + [(∂I_F/∂X)(dX/dE)]/(1+jωτ)`。
  **感抗出现 ⇔ `(∂I_F/∂X)_ss` 与 `dX/dE` 同号**（即电位通过"电场直接作用"与"经状态变量"两条途径对电流密度的作用**方向一致**，B>0）。
  异号则 B<0，呈容抗。**（此处初版写成"反号"，已按 p.53 原文改正。）**

**项目现状与真实差异（这才是要改的）：**

`bm_top.z_nested` 是 `Rs + CPE₁ ∥ (R₁ + (CPE₂ ∥ (R₂ + Z_branch)))`，支路 `series` = `R_L + jωL`。
把书 p.51 的电路按同样的两层写出来应是 **`Rs + CPE₁ ∥ (R₁ + (CPE₂ ∥ (R₂ ‖ Z_branch)))`** ——
**支路与 R₂ 并联（两者导纳相加），而不是串联**。

差别不是记号问题，端点行为不同：

| | ω→0 | ω→∞ | 说明 |
|---|---|---|---|
| 书 `C_dl ∥ [R_t ∥ (R₀+L)]` | `R_t ∥ R₀`（有限） | 0 | 感抗分支与 R_t 是**并联的电流通路** |
| 项目 `CPE₂ ∥ (R₂ + (R_L+jωL))` | `R₂ + R_L`（有限） | 0 | 支路是 **R₂ 之后的串联段** |

物理解读也不同：吸附弛豫与电荷转移是**同一界面上的两条并联通路**（Y_F 相加）；而"串联段"对应的是**膜/孔层在界面之前**（涂层模型）。项目现在的嵌套拓扑其实是**涂层/多孔层**那一路，不是吸附那一路。

**另有一条：`R_ad ∥ L_ad`（parallel 支路）在书中找不到原型。** 书里出现的 L（p.51、图4.3.2/4.3.4/4.3.5/4.3.17）**无一例外都与 R 串联**，从不与 R 并联。`R∥L` 只在应用文献里出现（PPT 第 6 页 AlCrFeNi 高熵合金、第 42 页多支路链），属经验电路而非机理推导。

**能做什么（三条，均待批）**：
- **B1（最高优先）**：把 nested 族的 `R₂ + Z_branch` 改成 **`R₂ ‖ Z_branch`**，作为一个**新族/新候选**（不是替换原族，否则会破坏与 A2/B2 的逐位可比）。这条直接对应书 p.51 与 S1875 的机理形态，而且不改 `SWITCH_*`。
- **补记（2026-11-10 18:03，B 臂实测之后）**：上面「补 `R_a∥C_a` 支路」「开 `adsorption`」这类**单向补元件**的做法，已被实测否掉一半——**元件相同不等于能力相同**。`bm_core.model_z`（:194–197）把 `Z_ad` 加在**最外层串联**（`Rs + ΣHN + Z_ad`），而 nested 把它放在**第二个并联节点内**（`C2 ∥ (R2 + Z_ad)`）。同一个 `R·jωτ/(1+jωτ)`，两个位置是两个函数类：`noise=0` 下 voigt K=2 对 nested 谱的残差 **44.0%**，挂上顶层 `Z_ad` 只降到 **40.7%**；实验侧 Δ 从 283.6 变 284.3（不变），降级反而 8/20→10/20。极点层面更硬：voigt+ad 的极点恒为实负，nested 可出现复共轭对（`−0.479 ± 0.438i`，约 23% 的参数盒）。详见 `NESTED_TOPOLOGY_PROJECT.md` §9.4.12。
- **B2**：给 `series` 支路的 `(R_L, L_ad)` 加**参数类约束**——书要求 `R₀=a/B>0`、`L=1/B>0`，等价于 `R₀·L > 0` 且两者同号、且 `τ_ad = L/R₀ = 1/a` 应为**正的时间常数**。现在两个参数各自自由，等于允许 `τ<0` 这种非物理候选混进池子。

### C. 拓扑—谱不是一一映射，"不可分"是文献已知的结构性事实

### I. CDC 同构判定：**已做完**，两族的关系分三层，不是一句"不可分"

工具：`evidence/nested_topology/m4_cdc_isomorph.py`（纯 sympy + numpy，不碰生产）。
日志：`out/_cdc_isomorph.log`。

**① 结构（CDC 规范串，书 p.128 规则：奇数级括号=并联、偶数级=串联）**

| 结构 | CDC |
|---|---|
| voigt K=2 | `R(CR)(CR)` ← 两个并联块**并排串联** |
| voigt K=1 | `R(CR)` |
| nested L=2 无支路 | `R(C(R(C(R))))` ← **逐层嵌套** |
| nested L=2 series | `R(C(R(C(RRL))))` |
| nested L=2 parallel | `R(C(R(C(R(RL)))))` |

结构**确实不同**。但这只说明"串不同"，不能推出"函数不同"——所以要算第二层。

**② 函数（纯 RC、无支路）：** **严格恒等，不是近似**

设 `Zv = Rs + R1/(1+sτ1) + R2/(1+sτ2)`、`Zn = Rs + C1 ∥ (R1n + (C2n ∥ R2n))`。
相减通分令系数为 0，得 4 方程 4 未知，**唯一解**：

```
S = R1+R2,  A = R1·τ2 + R2·τ1,  den = A(τ1+τ2) − τ1τ2·S
R1n = A²/den,  τ2n = den/A,  R2n = S − R1n,  C1n = (τ1+τ2−τ2n)/S
```

`sympy.solve` 独立求出同一组解（4 个全部逐字一致），正性条件也验证了：
`den·S − A² ≡ R1·R2·(τ1−τ2)²` → **只要 `τ1≠τ2`，四个参数全正**。
4000 组随机参数（R 跨 1e0–1e5、τ 跨 1e-5–1e3）**4000/4000 有全正解**，
最大相对残差 **2.9e-9**（双精度地板）。

⇒ **除「两个时间常数相等」这一退化外，每一个 voigt K=2 谱都能被某个 nested L=2
以全正参数精确表示，反之亦然。** 这是 `§2.C` 那个"结构性恒等"的**证明**。

**③ 一旦带感抗支路，恒等不可能（拓扑级，与参数无关）**

两条独立论证，互为备份：

| 判据 | voigt（无 L） | nested series | nested parallel |
|---|---|---|---|
| `Im Z` 的正部 | 恒 ≤ 0（实测 −0.83） | `+8.2e8`（高频发散） | `+1.5e3`（0.097 Hz） |
| `ω→∞` 的 `\|Z\|` | → `Rs`（实测 10） | → `Rs`（10） | → `Rs`（10） |
| `voigt+L` 的 `ω→∞` | **发散**（1 MHz 处 6.28e3，是 `Rs` 的 628 倍） | — | — |

- 纯 RC voigt 的 `Im Z` 恒非正，而两种 L 支路都给出正 `Im` → 符号不相容；
- nested 无论哪条支路，高频都停在 `Rs`；而 `voigt+L` 高频按 `sL` 发散 →
  极限不相容。

⇒ **nested 永远追不上 `voigt+L` 的高频发散，`voigt`（无 L）也永远补不上 nested 的
感抗尾。** 这解释了两件事：`§2.A` 里 `include_L=False` 写死为何代价这么大；以及
§2.B 里"支路接法"为什么是族定义的一部分而不是实现细节。

**⑥ 「那打开 `include_L` 呢？」——**答案是不能，而且补错了频段**

工具：`evidence/nested_topology/m4_voigtL_vs_nested.py`；日志 `out/_voigtL_vs_nested.log`。

**(a) 代数：无穷远点的阶数不匹配**

| 配置 | 分子/分母次数 | `s→∞` 的 `Z` |
|---|---|---|
| voigt（无 L 无 ad） | 2 / 2 | `Rs` |
| voigt + L | 3 / 2 | **∞（发散）** |
| voigt + ad | 3 / 3 | `Rs + R_ad` |
| voigt + L + ad | 4 / 3 | **∞（发散）** |
| nested（支路退化） | 2 / 2 | `Rs` |
| nested series | 3 / 3 | `Rs` |
| nested parallel | 3 / 3 | `Rs` |

`sympy` 精确给出：`voigt+L` 在 ∞ 处是**一阶极点**（`Z ~ sL`），nested 是**一阶零点**
（`Z ~ 1/(sC1)`）。一个发散一个衰减到 `Rs`，**阶数不同，参数怎么调都不可能相等**。
`voigt+ad` 次数与 nested 相同（3/3）但极限是 `Rs+R_ad` 而非 `Rs`，要相等必须 `R_ad=0`，
那就退回 `voigt` 了。**所以：两族只在「voigt 两个开关都关 + nested 支路退化」时相交，
这一种情形 §②已证恒等，没有第二种。**

**(b) 频段：串联 L 在高频，并联 RL 在低频 —— 这是更致命的一条**

| 元件 | `Im Z` 峰值位置 | 0.01 Hz 的贡献 | 1e5 Hz 的贡献 |
|---|---|---|---|
| 串联 `jωL`（L=1e-6） | **无峰，随 ω 单调升** | `6.3e-8 Ω` | `0.63 Ω` |
| `R∥L`（R=3000, τ=1.6） | **0.102 Hz（1499.7 Ω）** | `298.6 Ω` | `3.0e-3 Ω` |

两者把感抗放在频率轴的**相反两端**。AZ31 的低频感抗（0.01 Hz 处 29–1123 Ω）
只能由 `R∥L` 解释，串联 L 在那个频点的贡献是 `1e-8` 量级。

**(c) AZ31 实测：与 `ωL` 差 7–9 个数量级**

`bm_core.make_model` 给 `L` 的先验是 `LogNormal(log(1e-6), 2.0)`，2σ 上界 `5.5e-5 H`。
在 `f=0.01 Hz`，`ωL` 上界 = `3.46e-6 Ω`。而 18 条实测的 `Im Z` 是 29.3–1120 Ω
（18/18 为正）：**量级差 6.9–8.5 个数量级，中位约 8.0**。

⇒ **开 `include_L` 对 AZ31 的低频感抗没有任何作用。** 它只覆盖 3 条谱的高频仪器段
（`12Li_0`/`8Li_0` 前 9 点、`8Li_150` 前 5 点，转折在 5180–26827 Hz，那里 `ωL` 才够大）。

**(d) 若要补低频感抗，该开的是 `adsorption="RL"`，不是 `include_L`**

`bm_core` 已有这条路径（`make_model(..., adsorption="RL")` → `bm_ad.z_ad`），

   |---|---|
   | 显著指向 nested | `nested`（照旧） |
   | 显著指向 voigt | `voigt`（照旧，这种情形本身可疑，留给上层报警） |
   | 不显著 + voigt 能表示 | `indistinguishable`（照旧） |
   | 不显著 + voigt 表示不了 | **`voigt_inadmissible`** |

   **判据分频段**，不是"有感抗就不可用"——否则将来打开 `include_L` 会误伤只有高频
   仪器感抗的谱：

   ```
   感抗点 fi = { f : Im Z > 0.05·max|Z| }        # 只看正虚部
   split    = sqrt(f_min · f_max)                 # AZ31 窗内是 31.6 Hz
   低频段若 fi 非空 且没开 adsorption → 不可用（note 现写作"需把 R∥L 放进第二并联节点"）
   高频段若 fi 非空 且没开 include_L  → 不可用（"需 include_L"）
   ```

   能力声明收敛到常量 `VOIGT_CAPS = {include_L: False, adsorption: None}`，
   `_selftest` 每次跑都**断言它与 `fit_voigt` 的实际签名一致**——判据描述一支并不
   存在的族时不会报错，只会让输出静静地错。

   **实测该判据的行为**（`voigt_can_represent`）：

   | 输入 | `include_L=False, ad=None` | `include_L=True` | `ad="RL"` |
   |---|---|---|---|
   | 合成 `voigt_true`（无感抗） | ✅ 可用 | ✅ | ✅ |
   | 合成 `nested_true`（低频 0.01–0.14 Hz） | ❌ 需 ad | ❌ **仍不可用** | ✅ |
   | 手工纯串联 L（高频 5e4–1e5 Hz） | ❌ 需 include_L | ✅ 可用 | ❌ |
   | AZ31 18 条 | ❌ 全部（低频段先命中） | ❌ | — |

   第二行是 §⑥ 结论的**直接体现**：开 `include_L` 对低频感抗谱**依然判不可用**。

   `_health()` 增加 `voigt_inadmissible` 计数；`_verdict()` 里它**既不算错切也不算
   命中**（比"并列"更弱）；若某天 voigt 真值谱出现这个终态，说明判据误伤，
   该去查 `IND_TOL_SPEC` 与 `VOIGT_CAPS`。

   **口径影响**：30/30 条真实谱（18 AZ31 + 12 archive）都会命中这个终态，等于把对 AZ31 的表述从
   "族级结论只能记 C 档"改成"**voigt 族对这批数据不适用**"。这是 §⑦-1 的落地。

   **单测**：`evidence/nested_topology/m4_inadmissible_check.py`（不采样，秒级）。
   之所以要专门写：**这个终态在四类合成用例上一次都不触发**（Δ 显著时仍报 `nested`，
   降级走旧分支），跑自检等于没测到它。覆盖五组共 24 个断言：

   | 组 | 内容 | 结果 |

   | 四 | `VOIGT_CAPS` 与 `fit_voigt` 签名一致 | ✓ |

### J. AZ31 的低频尾不可能是扩散——不是判据不灵，是前提不成立

- **文献**：书 p.106–107（第 6.8 节）。
  - ② **Warburg 公式要求"对频响有影响的状态变量只有电极电位 E"**；"倘使除 E 外还有其他……状态变量，Warburg 公式并不适用"。表面很粗糙时 Fick 定律也不能简单表示，谱同样偏离 Warburg。
  - ③ 偏角 <π/4 有两成因：额外状态变量引起感抗弧；或粗糙表面使扩散近似球面扩散。
  - ④ **低频极限**：`f→0` 时 `Z_d→∞` 只出现在阻挡层扩散(T) 与平面半无限扩散(W)；其余情形虚部→0、实部有限 → 直接读出 `R_p`。
- **项目现状 + 实测**：`W/O/T` 三种扩散元件的虚部在低频**全为负**；而 18/18 条 AZ31 在 0.01 Hz 处虚部**为正**（29–1123 Ω）且仍上升。
- **结论（可以写进文档，是理论推断不是经验判据）**：
  1. **AZ31 的低频尾在理论上排除了任何扩散元件**（W、O、T 全不符合符号），与项目"18/18 判感抗、`candidate` 0/18"一致——这是被理论确证，不只是判据算出来的。
  2. **对有吸附状态变量的体系（AZ31 有 MgOH_ads），套 Warburg 公式本身就越界**。所以 `WS_CRITERION_PLAN.md` 里那些"检测下限 / 天花板 / 只作事后诊断"的结论，根因是**前提不成立**，继续优化判据不会改变结果。
  3. 由此，`Ws` 这条线在这批数据上应当**收口**：不再追求"判出 Ws"，而改成"报出低频尾符号 + 判是否越界"。**待批（改的是文档结论措辞，不动代码）。**

### K. 两族就是教科书里的两套涂层模型；选哪个靠**机理**，不靠谱（对 M4 最直接）

- **文献**：书 p.160 图9.2.5。对**同一个"两个时间常数"的谱**，书并列给出两套电路：
  - **(A)** `Rs + (C_c ∥ (R_po + (C_dl ∥ R_f)))` = **嵌套型 = 项目的 nested 族**
  - **(B)** `Rs + (C_c ∥ R_c) + (C_dl ∥ R_f)` = **阶梯型 = 项目的 voigt 族（K=2）**
  - 取舍依据（原文）："如果电解质溶液是**均匀地渗入**涂层体系且界面的腐蚀电池是**均匀分布**的，就要用模型 **(B)**。"
- **含义（这是对 M4 最有用的一条）**：
  1. **两族不是"谁更对"，而是同一现象的两个理想化**：局部孔道渗入 → (A)；均匀渗入 → (B)。二者的谱可以重合，所以**任何基于谱的跨族判定都有天花板**。
  2. B2 的"零错切 + 正向命中 0"因此不是调参空间的问题。**把采样预算加倍、把 guard 补全，都不会改变这个上限。**
  3. **真正能区分两族的信息在 EIS 之外**：涂层/膜是否均匀、是否有局部孔、腐蚀电池是否均匀分布（SEM/截面/起泡率 F）。书里就是这么选的。
- **能做什么（三条，均待批）**：
  - **K1（口径）**：在 `NESTED_TOPOLOGY_PROJECT.md` 的结论里把"两族不可分"从"本窗本噪声下"升级为"**结构性**（教科书级）"，并注明依据 p.160。以后凡报 `indistinguishable`，同时给"需外部形貌证据"一句。
  - **K2（数据侧）**：真实谱若有配对形貌信息（是否局部点蚀/起泡），把它作为**外部协变量**记入元数据，供事后归因用；没有就明确标 `mechanism_unknown`。这不进 elpd，只进报告。
  - **K3（建模侧，可选）**：把 (B) 与 (A) 的**参数对应关系**推出来（(B) 的 `R_c` ↔ (A) 的 `R_po` 之类），检查在什么参数下二者谱重合——这是 §2.I（CDC 同构）的具体算例，比空谈"可能等价"更有说服力。

### L. 一条可直接实现的稳定性诊断 + 「C、L 恒正，只有 R 可变号」

- **文献**：书 p.56–57。
  - `C_a = 1/(R_t²|B|) > 0` 恒正；原文："**无论是否满足稳定性条件，等效电容与纯电容一样，都不可能为负值**"。
  - `L = 1/B > 0` 恒正；`R₀ = −|a|/B`，只有 `a<0`（稳定性不满足）时才为负。
  - **能变号的只有电阻**：`B<0` 且 `a>0` 时 `R_a<0` 是合法的（p.49）；`B>0` 时 `R₀<0` 则对应 `a<0`，属不稳定。
- **可直接用的诊断规则（p.57 原话）**：**"当发现 `R_p>0`、且不存在感抗、而 `R_p<R_t` 时，就要检验阻抗测量是否满足稳定性条件。"**
  → 这是一条**从谱形反查测量合法性**的规则，书里只此一条。
- **已实现为独立诊断，但实测结论是「在本项目数据上一条都用不上」**（`evidence/nested_topology/m4_spectrum_health.py`，`stability_shape()`）：

  | 数据 | n | `ok` | `unverified` | `not_applicable` |
  |------|---|------|-------------|------------------|
  | 18 条 AZ31 | 18 | 0 | 0 | **18** |
  | `archive/` 12 条 | 12 | 0 | 0 | **12** |
  | 合成谱（σ=1%,3%）× 4 类 | 8 | **2**（仅 `voigt_true`） | 0 | 6 |

  **全部 34 条真实谱都是 `not_applicable`**：规则的前提是「全谱无感抗」，而这批数据的
  正虚部相对深度在 18.7%–98.1%，前提一律不成立。所以这条规则**不能进 `bm_select.py`
  的 guard 表**——加进去就是一个恒不触发的死项。
  它只在**纯容抗谱**上有意义（合成 `voigt_true` 是唯一触发 `ok` 的样本）。
- **三条实现坑（都实测踩过，改了三版才对）**：
  1. **只能看正虚部**。用 `|Im|` 会把每个容抗弧都算成「有感抗」（第一版全谱 25–46%，
     四条合成谱全被读成有感抗，规则一次没触发）。
  2. **`R_p < R_t` 必须用端点比较，不能用逐步单调**。按 `np.diff` 判，1% 噪声就能在
     某一步造出超过容差的回落 → 纯 voigt 真值被误报 `unverified`（σ=1% 即触发）。
  3. **`R_p ≤ 0` 要带相对容差**。超低阻样品（`2EMC*`，`max|Z|≈0.05 Ω`）的噪声足以把
     低频实部推到 −0.012 Ω，硬判「实部越界」是假阳性。
- **对项目的一个确认**：`(R_L, L_ad)` 取正、`(R_ad, tau_ad)` 取正，与书一致，**不需要放开负值**。反过来说，若某个候选必须靠负 `L` 或负 `C` 才拟合得上，那不是"数值怪"，是**模型不适配**，应当剔除而不是用先验硬压。
- **另需注意**：项目记忆里的"负 γ"指**有符号 DRT 的负 δ 峰**（`bm_ad.gamma_ad`），与"负电容元件"不是一回事——书里的结论（C、L 不可为负）**不影响** signed-DRT 允许负幅值。

### M. W/O/T 的三分判别：用「低频相位走向」而不是阈值

- **文献**：书 p.93–96 的 `tan φ` 精确式（6.3.9 / 6.4.8）与高频极限：`z` 大时 **O 与 T 都回到 45°**，差别全在低频端。

  | 低频 `tan φ` 走向 | 判为 | 依据式 |
  |---|---|---|
  | → 1（保持 45°） | **W**（半无限） | — |
  | → 0 | **O**（可渗透有限层，`R_p` 有限） | 6.3.9 |
  | → ∞（趋于 90°） | **T**（阻挡有限层，`Z_d` 发散） | 6.4.8 |

- **为什么这条比现有判据好**：它是**趋势判据**，不是阈值判据。项目记忆里"Bode 相位不能当判据"那条，针对的是拿相位**绝对值**判 Ws 幅度——被 `R_inf` 平移打偏（纯 Ws 从 −45° 拉到 −10.8°），所以 20/20 全错。而**低频端的走向不受平移影响**：平移只改水平位置，不改"趋于 0 / 1 / ∞"。
- **顺带解释了 §2.H 的"窗口"问题的确切形式**：O 与 T 在**高频都等于 W**，所以只要窗口没盖到低频转折（`B√(jω)~1`），三者**在数学上就是同一条 45° 线**，不是"难分"而是"完全同一"。这比"窗口未覆盖转折"的说法更精确。
- **能做什么（待批）**：把 `Ws` 判据从"阈值 + 幅度"改成**三段趋势分类**（W / O / T / 都不是），用低频最后 6–8 个点拟合 `tan φ` 的单调走向；输出**四态**（含"都不属于"）+ 置信度，不做二值判定。
- **对照项目实测**：W/O/T 的虚部在低频**全为负**，而 18/18 条 AZ31 在 0.01 Hz 处虚部为**正**且仍在上升 → **符号就不在 W/O/T 的取值域内**，所以"都不属于"这一态可以直接由符号判定，不必依赖趋势拟合。趋势分类只在符号相符（虚部为负）时才需要，用来区分 W / O / T。与 §2.J 的结论一致。

### N. AZ31 的谱型归到书的**第 IVb 属**，且临界频率与书里算例同一量级

- **归类依据**：`4.3.4 第 IV 类（A<0, B<0）` 中，`|B|D>|A|T` 那一属是"**高频容抗、低频感抗**"（书 p.68/73）。AZ31 实测正是这个走向 → 属 **IVb**。
- **意味着什么**：IVb 的等效电路**含 L，且 `L>0`、`R_L>0`**（`L=R_t²B²/(|B|D−|A|T)`）——所以**为 AZ31 这类谱配一个真实的电感支路，是有教科书出处的，不是硬凑**。这修正了我第一轮"不该用真电感"的判断（见 §2.B 第三版）。
- **定量核对（本轮新做）**：书里 IVb 算例的临界频率 `f_c=0.14 Hz`；II 类三个子属是 0.20/0.28/0.39 Hz。实测 18 条 AZ31 的感抗↔容抗过零频率（`Zim` 由正变负处）：

  | 范围 | 中位 | 分布 |
  |------|------|------|
  | **0.139 – 1.389 Hz** | **≈0.37 Hz** | 17/18 落在 0.139–1.389；`12Li_5` 因高频噪声误判，不计 |

  → **与书的算例（0.14–0.39 Hz）同量级，量级与分布均相符**。这是"AZ31 属 IVb"的一条独立佐证，也说明这些谱的感抗转折**在测量窗内**（0.01–100 kHz 完全覆盖），不是看不见的窗外过程。
- **进一步的检验项（待批，成本低）**：IVb 的内部再分随 `T−R_t|B|` 的符号；`T−R_t|B|=0` 时**曲线在 `f_c` 处不连续**。可以在实测谱上查 `f_c` 邻域有无跳变——若有，说明落在临界情形，该带的参数估计不可信。
- **与 §2.K 的关系**：K 说的是"两族都是涂层模型、靠形貌选"；N 说的是"若坚持用机理路线，AZ31 该走 IVb 这条含 L 的支路"。两者不冲突：**K 是'谱分不开'，N 是'真要挑一族，挑这条'**。但按引用纪律，N 只能作**形态先验**，不能当族级判定依据。
