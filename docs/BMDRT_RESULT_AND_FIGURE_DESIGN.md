## 0. 定位

普通 EIS 软件的图回答"这条曲线拟合得怎么样"。BM-DRT 的图要回答的是：

1. 数据支持怎样的阻抗响应？
2. 不确定性有多大？
3. 哪些参数被独立约束，哪些只是组合量？
4. 当前数据能否区分不同模型？
5. 哪些结论可以写，哪些必须保留？

所以图不是结果面板的装饰，而是**结论的一部分**：图上出现的每个数都要能追到拟合结果，
图上不能出现的（联合可信域、唯一最优模型、伪相关矩阵）一律不画。

## 1. 三个出口，一份数据

| 出口 | 用途 | 形态 | 谁生成 |
|---|---|---|---|
| Analysis Dashboard | 日常分析：质量/拟合/残差/可信度/分类 | 单文件 HTML，分页、可缩放、可重排 | `bm_dash.py` |
| 出版图（Figure） | 投稿与汇报：固定版式、矢量、精确尺寸 | PNG/SVG/PDF/TIFF（mm 尺寸） | `bm_figure.py` |
| Data & Reproducibility | 复现与再分析 | CSV/NPZ/JSON + manifest | `bm_result.AnalysisResult.bundle()` |

**三者必须同源**：都只读 `AnalysisResult`，不允许各自再算一遍残差、区间或 DRT。
这条由测试 F1 守住（曲线 ≡ 逐样本分位、残差 ≡ 恒等式、CSV ≡ 图、sha256 对得上）。

> **名字别混用**：现在有 Dashboard、有出版图渲染、有结果包，但**没有图形编辑界面**
> （没有拖拽改色/改轴范围/自由拼版的可视化编辑器）。所以这里不叫 "Figure Studio"；
> 配色与版式通过 `figure_spec.json`（含 `style`）与面板的配色槽控制，
> 产物仍然是可复现的文本配置，不是一次性的鼠标操作。

## 2. 分层

```
real_*.json + *_samples.npz
        │
        ▼
AnalysisResult        一次算清：z_fit(=逐样本分位中位)、band、pred、resid、norm、DRT、判定
        │
        ├── payload() ──► bm_dash.py   （SVG + JS，浏览器内交互）
        ├── bundle()  ──► data/ metadata/ manifest.json
        └── payload() ──► bm_figure.py （matplotlib，mm 尺寸、矢量）
```

为什么不让面板直接读 `bm_real` 的内存对象：MCMC 一跑完这些对象就没了，
事后重看只能靠落盘产物；而落盘产物里**没有拟合曲线**，只有参数。
所以"从后验样本重算曲线"这件事必须有唯一实现——放在 `AnalysisResult` 里。

## 3. 面板：标题栏 + 两页（不再一页到底）

**标题栏**（粘顶，两行）：上行是样品名 + 点数/频段/K（副标题）+ 判定 chip 组 + 主题/导出/重置；
下行是分页签 + 当前页的一句话说明。

```
┌─ 标题栏 ───────────────────────────────────────────────────────────────┐
│ 2EMC1-1_0050mA          [采样达标（分级2）·结构判据 2/3] K=2+L Rwp… │
│ 56 点 · 1–1e+5 Hz · K=2 · +L                          Minimal 导出 重置 │
├────────────────────────────────────────────────────────────────────────┤
│ 总览 │ 判定与模型 ● 2 条警告                    先看图：拟合/DRT/残差       │
└────────────────────────────────────────────────────────────────────────┘
```

**第 1 页「总览」**（12 栅格，1560×900 一屏放得下）：

```
┌──────────── 指标条：Rwp / acf / max R̂ / div / PPC / 采样分级 ────────────┐
├──────────────────────────┬─────────────────────────────────────────────┤
│ 阻抗拟合 (6 栅格, 2 行)   │ DRT 分布 (6, 1 行)                          │
│   Nyquist 数据/中位/区间  ├─────────────────────────────────────────────┤
│                          │ 残差诊断 (6, 1 行)                          │
└──────────────────────────┴─────────────────────────────────────────────┘
```

**第 2 页「判定与模型」**：`判定与警告`（通栏）+ `模型与参数`（通栏三列）。

排版理由：

- **分页而不是长页面**。5 张卡叠在一页要 ~1500px，一屏看不完，于是第一屏永远只有
  Nyquist，判定和模型要滚两屏才看到——"看不到的判定"等于没有。分页后每页一屏，
  且**判定 chip 常驻标题栏**，任何一页都能看到"是否达标、几条判据过了"，
  失败信息不会因为分页被藏起来。
- **Nyquist 跨两行、占 6 栅格**。等比例坐标（1 Ω 横 = 1 Ω 纵）是硬约束；画布过宽
  就要靠扩数据域补比例，右侧会留一条空带（7 栅格时 x 轴被拉到 0.10，数据只到 0.09）。
  6 栅格（宽度 ≈ 高度 ×1.27）时扩域量与数据本身匹配，弧充满画布。
- **Bode 不进总览**。它和 Nyquist 争同一块面积，且总览阶段看的是"像不像"，
  细节留给抽屉。点"Bode"按钮展开幅值 + 相位双轴。
- **DRT 与残差同宽上下叠**，便于竖直对照（残差峰位与 DRT 峰位对不上的那类问题
  正是靠这个对齐看出来的）。
- **模型/参数不进图**。K 候选、参数区间、相关矩阵本质是表格；塞进子图会为了
  省空间把字号压到 7pt，最后谁都看不清。
- **判定不混进 KPI 条**。判定是"分级 + 判据 n/3"的两层陈述，混进指标条会被读成
  一个可以比较的分数。

可编辑项（第一版就支持，都是布局级，不是画布级自由拖拽）：

| 操作 | 实现 |
|---|---|
| 切页 | 分页签；`#page=md` 可深链 |
| 上移/下移面板 | 拖卡片标题（HTML5 drag，按 id 传，跨页不串位） |
| 改宽度 | "宽"按钮循环 4/6/8/10/12 栅格 |
| 隐藏/恢复 | "隐藏"，底部出现恢复条 |
| 缩放/平移/复位 | 滚轮、拖动、双击；`Shift`+滚轮只缩横轴 |
| 固定读数 | 点击图上一点，各图按**频率值**对齐（见下） |
| 保存版式 | 自动存 `localStorage`，"重置"回默认；可导出布局 JSON（含 `colors`） |
| 风格预设 | 5 套（Minimal / Nature-like / ACS-like / Angewandte-like / Presentation） |
| 逐系列配色 | 导出抽屉里 5 个取色器（实验点/拟合/DRT/Re/Im），写进 `LAYOUT.colors` 与 spec 的 `style` |
| 单面板 SVG | 卡片"SVG"按钮，导出当前视图（含缩放后的轴） |

**跨图联动共用频率值，不共用数组下标**。`curves.f` 是实测频点（50 点），`drt.f` 是
后验 τ 网格取倒数（几百点），两组网格长度和位置都不同。`PIN` 存 Hz，每个面板各自
`nearIdx` 就近映射；从 DRT 点过来时读数会注明"按最近实测点 x Hz"。共用下标会让
点 DRT 在 Nyquist 上落到另一个频点，网格更长时还会越界读出 `undefined`。

不做：任意坐标拖放、图层系统、在浏览器里改字体文件。第一版做成网格是因为
**对齐比自由更值钱**——六个图各自找位置，最后没有两张图的坐标轴是对齐的。

## 4. 视觉编码（固定，用户不必每次重设）

| 元素 | 编码 |
|---|---|
| 实验数据 | 空心圆点，细描边 |
| 后验中位 | 实线 |
| 区间 | 半透明（Nyquist 用逐点十字误差棒，见下） |
| 残差 Re / Im | 圆点 / 方块 |
| DRT | 紫色实线 + 半透明带 + 峰位竖虚线 |
| 判定状态 | 绿=通过、琥珀=降级/待查、红=不通过、灰=不可评价；**不用颜色表达"重要性"** |

配色跟随主题预设，也可以逐系列改（`style` / 面板取色器），但上面这些**形状与线型
不随主题变**——换风格不能把"实验数据"从空心点变成实心块，否则同一课题组的两张图
无法互读。只改拟合色时区间色自动跟随，否则会被读成两组数据。

## 5. 口径（三条硬规则）

1. **区间分两类，字段名不同、永不同图混用**
   - `band` = 参数后验传播的**响应区间**（逐样本算 Z(f) 再逐点取分位）；
   - `pred` = **后验预测区间**（响应 ⊕ 该样本自己的噪声 σ），默认不画。
   - `band` 的 Re/Im 是**各自**取分位，复平面上是矩形包络，**不是联合可信域**。
     所以 Nyquist 上画成逐点十字误差棒，不能连成一条"带"——连起来那圈面积没有
     概率含义，在拟合很差的谱上还会变成横贯全图的色带（已踩过）。
2. **标准化残差用本次拟合的 σ**（后验 σ 的中位数），不套 2% 观测噪声。
   缺 σ 时置空并标注，不用 2% 顶替。**实部与虚部分别判有效**：σ 只有一半可用时
   只置空那一半，CSV 里该列留空（不写 0——0 会被下游读成"残差为零"）；
   画图时两种量纲不能共轴，整幅退回绝对残差并在图内注明原因。
3. **判定分两层陈述，不合并成一个"通过"**
   - 采样档：分级 2 / 1（降级）/ 0（不合格）/ exploratory；
   - 结构判据：`acf≤0.50`、`max R̂≤1.05`、`div=0`，逐条给 pass/fail/na。
   - `采样达标（分级 2） · 结构判据 2/3` 才是完整的一句话。
   - `indistinguishable` 不等于"有唯一最优模型"；只跑过一个 K 时显示"未做跨 K 比较"，
     不显示 `ΔELPD 0.0`（那会被读成"比较过且无差异"）。
   - 缺后验样本 → 不画相关矩阵、不画区间，写"不可用"，不伪造。
4. **Rwp 只报数值，不上颜色**。`acf / R̂ / div` 有预注册阈值，Rwp 没有；
   给它红黄绿等于凭空造一条验收线，用户会把 12% 读成"失败"、3% 读成"通过"。
   面板上写"无预注册阈值"，定义（`100·sqrt(mean(|ΔZ|²/|Z|²))`，不除 √2）放页脚。
5. **Lin-KK 是四态，不是二值**：`ok→通过`、`warn→警告`、`fail→未通过`、
   `unavailable→不可评价`。把 warn 染成红色失败，恰好会把"可拟合、端部需归因"
   说成"数据报废"——这是本项目的口径红线（§15 归因只到"部分被解释"）。

## 6. 导出契约

```
results/<sample>/
├── dashboard.html                 # 交互面板（自包含，可离线打开）
├── figures/
│   ├── figure_<panels>.<fmt>      # png / svg / pdf / tiff（mm 精确、字体可编辑）
│   └── figure_spec.json           # 实际生效的 PlotSpec，换一条谱可原样复用
├── data/
│   ├── input_data.csv             # frequency_Hz, Zre_obs, Zim_obs
│   ├── fitted_impedance.csv       # 观测/中位/两个区间的上下界/残差/σ/标准化残差
│   ├── residuals.csv
│   ├── drt_distribution.csv       # frequency_Hz, tau_s, gamma_median/lo/hi
│   ├── parameter_summary.csv      # parameter, kind, q05/q50/q95, sd, log_scale
│   └── posterior_samples.npz      # 原始后验（参数名与链信息见 fit_config.json）
├── metadata/
│   ├── fit_config.json            # K/σ 模型/种子上限/区间口径/分位/抽样数
│   ├── model_comparison.json      # K 候选、ELPD、状态、来源（结构化 or 日志解析）
│   ├── analysis_report.json       # 判定、判据、KK、组分审查、退化、警告
│   └── source_result.json         # 源结果 JSON 副本，包能自己重新出图
└── manifest.json                  # 每个文件的 sha256 + 源文件 sha256 + 复现命令
```

`fitted_impedance.csv` 的列序固定（观测 → 中位 → 响应区间 → 预测区间 → 残差 → σ →
标准化残差）；两套区间靠列名前缀区分（`Zre_lower90` vs `Zre_pred_lower90`），
不靠注释里的一句话。

### manifest 两段式封包

```
bundle()          → status="partial"   （此刻 figures/ 空、dashboard.html 还没写）
                    pending 里写明还缺什么、用哪条命令补
bm_figure --all   → 写完图立刻 finalize_bundle()
bm_dash --bundle  → 写完 html 立刻 finalize_bundle()
                  → status="finalized"，files 覆盖磁盘上**全部**文件，
                    complete = (data/metadata/figures 都不空)，missing 列出空目录
```

为什么必须单独一步：`bundle()` 只能给当时已落盘的文件算哈希，而推荐流程是
"先 `--bundle` 再 `--all`"——出版图会永远进不了清单，"每个文件都有 SHA256"
就成了空话。`complete` 的含义是"该有的目录都不空"，不是"清单写完了"：
只出数据包没出图时必须为 `false`，否则读者以为包是齐的、找不到图还以为是下载坏了。

`posterior_samples.npz` 保留原数组名与维度；参数名、固定参数、链/预烧/采样数
写在 `fit_config.json`——不能只给一串无标签数组。

## 7. 验收（已实现，全部有测试）

| 条件 | 判据 | 测试 |
|---|---|---|
| 数值一致 | 交互图、出版图、CSV 的拟合值来自同一份数组；曲线 = 逐样本分位中位 | F1 |
| 可复现 | PlotSpec 落盘→读回→校验逐键相等；画布 mm 精确生效（不吃 `bbox_inches`） | F3 |

## 9. 明确不做

- 不在面板里做拟合、选 K、改门禁——它是**只读**的展示层。
- 不做"可信度总分"。K 的采样分级、结构判据、参数可辨识性是三类不同证据，
  相加会得到一个既不可解释、又能掩盖单点失败的数字。
- 不把 `acf`、`Rwp`、`ELPD` 换成一个排名。不同量纲、不同样本量下没有共同尺度。
- 不宣称风格预设"符合某刊投稿规范"。投稿前仍需按当期要求核对字体、字号、
  线宽、色彩模式与分辨率。

## 10. 已知限制

1. 单谱。所有面板都是"一条谱的一次分析"，跨样品对比（同状态不同样品、
   同一样品不同工作点）还没做——这恰好也是 R18（缺同状态重复谱）的症状。
2. DRT 是各分量 HN 解析 DRT 的逐样本叠加，φζ>1 时会出现负值，仅作可视化；
   要定量重建 γ 仍需 `drt.py` 的 Tikhonov 反演。
3. Nyquist 的区间是逐点边缘分位，点密集时误差棒会重叠；只表示"该频点各自的
   不确定度"，不表示曲线之间的相关性。
4. 主题只改排版语言，不改数据编码（见 §4）。
