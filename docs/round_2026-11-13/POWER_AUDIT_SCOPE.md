## 1. 一条关键前提（已核实，不是假设）

`results.json` 逐候选存了完整 `params`，因此**残差可精确重建**：
本轮先做 `repro` 自检——用存盘参数重算 `rwp_pct` 与 `acf`，与存盘值逐条比对（容差 1e-6）。

实际覆盖范围（**不是首版写的「32 条 × 2 候选」**）：脚本遍历**全部 168 条谱 × 每条谱所有有 `params` 的候选**
= **1503 个 (谱, 候选) 对**（168 × 9 = 1512 中 9 条未收敛/无参数），**0 条不一致**。
不一致即停止，不得用重建残差做零分布。⇒ 评审担心的「只有汇总指标、无法恢复零分布」不成立。

## 2. 统计单位（a4 的口径）

- **谱** ≠ 独立样本。`seed` 只控制噪声实现、不改变真值：同一 `(family, difficulty)` 的
  3 噪声 × 2 seed 只是同一物理场景的 6 次重复实现。
- 独立单位记为 `unit = (family, difficulty)` = **28 个**（全数据集）；主集 S 里只有 **8 个**，
  即 32 条记录 = 24 张唯一谱 = **8 个配置**（每配置 4 次实现：2 噪声 × 2 seed，其中 `n00` 的 s0/s1 同谱）。
- 三种口径并列报，**不许混用**：
  1. **按谱**（与本轮预注册一致，口径不改，只为可比）；
  2. **按唯一谱**（去重相同 sha256）；
  3. **按 unit**：每个配置的逐谱命中串、`全中/全不中` 计数；跨配置推断用
     **clustered bootstrap**（整体重采样 unit，B=2000，报 2.5/97.5 分位）。
- **unit 内必须先按 sha256 去重再进 bootstrap**。聚类只解决「不同配置算独立」，
  挡不住「同一张谱在一个配置里被算两次」——`n00` 的 s0/s1 是同一张谱。
  修前/修后点估计：① 71.9% → **62.5%**，② 68.8% → **58.3%**（旧值只作留档）。
- clustered bootstrap 要分两个估计目标，**同时报**：
  - **谱等权** `Σh/Σn`：把这批谱混在一起看的命中率；各 unit 谱数不等时会被大 unit 拉走。
  - **配置等权** `mean(h/n)`：换一个真值配置的期望命中率，**泛化问题只能看这个**。
  本例两值相同（每 unit 均 3 张唯一谱，balanced），但定义不同，换设计规模会分开。
- 按谱/按唯一谱给 **Wilson 95% CI**，但它把同配置的重复实现当独立 Bernoulli，
  **只是描述性区间**；回答「换一批真值配置会怎样」只能用 clustered bootstrap。
- **8 个 cluster 的 percentile 区间只能当探索性**：尾部分位在这么少的 cluster 下本身不稳，
  重采样 2000 次只提高 Monte Carlo 精度，不增加独立配置数。
- 两个研究目标要分开说：评价**对新配置的泛化** → 统计单位是配置；评价**固定配置下的噪声鲁棒性**
  → 重复噪声实现提供信息，但不能拿来估泛化能力的样本量。

## 3. 零分布（a1）定义

- 数据：真族候选在**本谱**上的残差 `d = Z_fit − Z_obs`（绝对口径，与
  `bm_real.py:1086` / `bm_bench.py:226` / `truth_recovery.py:274` 一致）。
- 替代数据：对 `d` 的实部、虚部分别独立随机变号，共 `B=2000` 次
  —— 逐点保 `|d_i|`（**保留异方差与重尾幅度结构**），只打乱与频率顺序相关的符号结构。
- 统计量：`acf = max(acf_max(d.real), acf_max(d.imag))`，滞后 1–5，同生产口径。
- 输出：逐噪声档 `q50/q95/q99/max`；逐谱置换 `p` 值 =
  `#{null ≥ obs}/B`。**`p` 只作诊断，不转成通过/不通过。**

## 4. 检出力（a2）刻度

- 偏置代理：`Δrwp = rwp_ind − rwp_true`（pp，配对同谱）。
- **归一化分母 = 纯噪声下 Rwp 的期望量级 `√2·pct·100`**：残差实/虚部独立、各
  `sd = pct·|Z|` ⇒ `E|d|²/|Z|² = 2·pct²` ⇒ `Rwp ≈ √2·pct·100`（pct=0.05 → **7.07pp**）。
  首版分母写 `pct·100 = 5pp`，**少乘 √2**，比值系统性偏大 41%（两套都保留在 `audit.json`：
  `drwp_norm` / `drwp_norm_5pp`）。
- 分箱：`[0,0.15) / [0.15,0.30) / [0.30,0.60) / [0.60,∞)`（**归一化量**，不是 pp）；
  每箱给检出率 + Wilson CI + n。**heavy 档另给逐条明细表**，因为 n=16 时任何分箱都是任意的。
- `MES80`（logistic）**已废弃**：n=16、两类之间有间隙，logistic 不可识别（拟合给出 0.26，
  与观测矛盾）。改报**经验检出边界**：未检出样本的最大比值 vs 检出样本的最小比值，
  并显式标注「本批样本 + 本估计器 + 本 ACF 定义下的观测分界，不外推」。
- 受控功率曲线（系统改变支路幅度 / 频率点数）需要重拟合，**不在本轮**，
  下一轮单独立项（规格见 `STAGE2_SPEC.md`）。

## 5. 设计层标签（几何口径，全部可算）

对真值含容性支路的谱，设 `Z_b(f) = Q_b/(iω)^n_b`（**项目约定：`Z = Q/(iω)^n`，
不是 `1/(Qω^n)`**；2026-11-13 首版脚本曾把这条搞反，导致 f0 全部算成 1e-13 Hz），
支路串联的电阻为 `R_L`（L1 取 `R1`，L2 取 `R2`）：

| 量 | 定义 |
|---|---|
| `f0_char` | `(Q_b/R_L)^(1/n_b)/2π`，CPE 与 `R_L` 的**幅值交叉频率**（几何代理，**不等于整个网络的弛豫频率**） |
| `window_ok` | `f_min ≤ f0_char ≤ f_max` |
| `effect_max` | `max_f \|Z_full − Z_short\|/\|Z_full\|`，`Z_short` = `Q_b→0`（**去掉支路**，非换成别的支路） |
| `effect_over_noise` | `effect_max / pct`，`pct` 为该谱噪声幅度（`none` 档按 5% 参考算） |
| `sens_snr` | `sqrt(mean_i(\|∂Z_i/∂lnQ_b\| / (pct·\|Z_i\|))²)`，**只报不判** |
| `degen_lin` | Jacobian（log 参数）中 `Q_b` 列对其余列的**线性解释度** `1−‖残差‖²/‖列‖²`，**只报不判**（切空间共线度 ≠ 不可辨识） |
| `degen_mismatch` | profile 式：`Q_b×1.5` 后，其余参数线性化迭代 4 步能否把阻抗补偿回去，返回**剩余相对失配 rms** |

标签判定（与 `power_audit.py::audit_labels` 逐行一致；顺序即优先级）：

1. `not window_ok` **且** `effect_max < 1×pct` → `non_identifiable_by_window`
2. `effect_max < 1×pct` → `weakly_identifiable`（特征在窗内但看不见）
3. `degen_mismatch < 0.5×pct` → `non_identifiable_by_degeneracy`（换掉这个参数、别的参数能补回去）
4. `degen_mismatch < 1×pct` → `weakly_identifiable`
5. 否则 → `identifiable_by_design`

> 首版 §5 第 3 条写的是 `degen_r2 > 0.999`，与代码不符（代码用的是 `degen_mismatch`）；
> 按 §8 变更 4，`degen_r2` 已降级为「只报」量。**文档以本节为准。**

**对照分解（exploratory）**：① 的对照模型是「换成 `R_ad∥L` 支路」，不是「去掉支路」，
两者不是同一个反事实 —— 前者同时去掉 CPE、加上 `R_ad`。因此必须并列报
`effect_max`（支路真实可见度）与 `Δrwp`（对照失配总量），
比值 `Δrwp/effect_max > 2` 的谱标注为 `control_adds_element`，
不得把这类谱的残差结构归因于"缺少容性支路"。

## 6. `D_ab` 预测距离（**诊断量，不是可区分性判据**）

- 定义：`D_ab = Σ_i |Z_a,i − Z_b,i|² / σ_i²`，`σ_i = 0.05·|Z_obs,i|`（固定 5% 参考使跨档可比），
  `Z_a/Z_b` 用两侧**各自的最优拟合参数**。
- **三条限制**（首版没写清，是审查指出的 P0-2）：
  1. **未校准**：`D` 不是 `P(可区分)`；其分布依赖频点数、实虚部协方差、参数不确定性、
     两模型各自的拟合偏差。`D=1` 没有统计含义。
  2. **只在本数据集内可比**：全部谱共用同一 60 点网格；换点数/换频段后量级变。
  3. **分组条件内生**：选对时 `D_best_vs_second` = 「真族 vs 最强对手」；选错时 top2 与真族
     关系不定 ⇒ **不能按 `D` 分箱算选对率当校准曲线**。
- 报什么：选对组的 `D_truth_vs_runnerup` 分位、误选组的 `D_true_vs_chosen` 分位、
  全部候选对里 `D<1` 的占比。**不设阈值、不给「可区分/不可区分」结论。**

## 8. 口径变更记录（跑前未预见，逐条如实登记）

| # | 变更 | 原因 | 影响 |
|---|---|---|---|
| 1 | `f0_char` 公式由 `(1/(Q·R))^(1/n)/2π` 改为 `(Q/R)^(1/n)/2π` | 首版把 CPE 约定写成 `Z=1/(Q(iω)^n)`；项目实际是 `Z=Q/(iω)^n`（`y_cpe=(iω)^n/Q`）。错版把 48 条 f0 全算成 1e-13 Hz，标签退化为单一类 | 修前后标签从「48/48 全 window」变成 4 类，说明**约定写错会直接毁掉审计**；修正后已重跑全部结果 |
| 2 | `MES80`（logistic）改为**经验检出边界**（未检出最大 vs 检出最小） | n=16 且 `Δrwp/噪声底` 在 0.17–0.36 之间有间隙，logistic 不可识别（拟合给出 0.26，与观测矛盾） | 只报观测边界 0.17 / 0.36，不报外推值；受控功率曲线留待下一轮重拟合 |
| 3 | `D_ab` 增报「BIC 第一名 vs 第二名」 | 真族被选中时 `chosen == truth`，`D_true_vs_chosen` 无定义（首版因此得到 n=0 的空结果） | 才能回答「选对了是不是真有证据」 |
| 4 | 退化标签由 Jacobian 共线度改为**有限幅度补偿失配** `degen_mismatch` | `degen_r2>0.999` 把 24 条判成退化，但其中 18 条 BIC 选对、17 条 ① 命中 → 切空间共线度不能推出不可辨识 | 标签改为 profile 式（`Q_b×1.5` 后其余参数能否把阻抗补偿回去），与实际结果一致性提高 |
