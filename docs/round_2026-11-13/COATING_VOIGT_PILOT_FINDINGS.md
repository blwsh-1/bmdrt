# 涂层族 60 条：生产 Voigt K=2 的失配结构（pilot 结论）

状态：**探索性**。判据跑前冻结（`COATING_VOIGT_PILOT_PREREG.md` §3），跑完未改；
本文件只登记读数与诊断，不改任何生产代码 / 阈值 / 先验 / 族默认值。

数据：`测试数据/涂层/.../Generated EIS data and Nyquist plots/`，1000 条合成谱（60 点，
26337→0.001 Hz），该族**只有一个拓扑** `R1-[P2,R3-[P4,R5-P6]]`，只有 3 个参数在变
（`Q_P2`/`R3`/`Q_P4`，对数均匀、两两无关）。
抽样：12 格 × 5 = 60 条，格内按 `md5(文件名)` 取前 5，**与拟合结果无关**。

## 2. 三族对照（只用收敛的样本）

| 口径 | 收敛 | `ratio` 中位 | `ratio` 范围 | `acf` 中位 | `acf>0.5` |
|---|---|---|---|---|---|
| **nested capacitive（真值拓扑）** | **60/60** | **0.94** | 0.72–**1.00** | **0.32** | 2/60 |
| voigt K=2，自由 σ（近生产） | 14/60 | 3.36 | 1.44–6.23 | 0.74 | 10/14 |
| voigt K=2，固定 2%·\|Z\| | 40/60 | **1.03** | 0.78–5.45 | **0.80** | 39/40 |

`ratio = rms_rel(拟合)/rms_rel(真值拓扑正演)`；`acf` = 滞后 1–5 自相关最大值（尺度不变）。

**配对子集（两种 σ 口径都收敛，n=9）**：voigt 自由 σ `ratio 2.22 / acf 0.75`；
voigt 固定 σ `ratio 1.06 / acf 0.79`；nested `ratio 0.95 / acf 0.28`。

### 2.1 这张表说明什么

1. **真值拓扑 60/60 贴到噪声底，且残差无结构**（`ratio ≤ 1.00`、`acf` 2/60 过线）。
   同一条谱上"数据能被完美解释"，所以后面 voigt 的偏差**全部是模型侧的**。
2. **固定 σ 让 voigt 的幅度回到噪底（1.03），但残差结构仍在（acf 0.80 vs 真值 0.28）。**
   ⇒ `ratio ≈ 1` 不足以判"表达得了"。这条与项目已有的 `acf` 主张一致：
   幅度与结构是两个正交判据，缺一就会把"幅度凑上了"读成"模型对了"。
3. 自由 σ（生产口径）连幅度都到不了（3.36），因为它按**绝对残差**加权：
   7.4 个 decade 里低频大幅值点主导，高频 `Q_P2` 支路被系统性轻视。

### 2.2 nested 的参数恢复（顺带）

| 参数 | \|θ̂/θ−1\| 中位 | p90 |
|---|---|---|
| `Rs` | **2.65** | 8.05 |
| `R1` | 0.02 | 0.22 |
| `R2` | 0.10 | 1.34 |
| `Q1`/`Q2`/`Q_b` | 0.10 / 0.18 / 0.20 | 0.74 / 4.10 / 0.38 |
| `n1`/`n2`/`n_b` | 0.02 / 0.04 / 0.05 | 0.10 / 0.32 / 0.10 |
| **组合量 `Rs+R1`** | **0.020** | 0.217 |

`Rs` 单独不可辨识（与低频平台互换），组合量 `Rs+R1` 恢复 2.0%。
与本项目既有纪律一致：**`Rs` 只报 `Rs+R1`**。

## 3. `R̂` 爆表的机制：标签置换 + 抵抗脊，不是数值失败

10 条（跨格轮转）用**真生产配置**复跑并记录逐链后验（`mode_diag.py`）：

| 指标 | 结果 |
|---|---|
| 原始 `R̂` 中位 | **18.49** |
| 逐样本内按 `ln τ` 排序后 `R̂` 中位 | **8.04** |
| 排序后 `R̂ ≤ 1.05` | **4/10**（纯标签问题） |
| 排序后仍 `> 1.05` | 6/10（不同链选了"哪个分量当常数"） |
| 至少 2 个模式 | 7/10 |
| 存在逃逸分量（`ln τ > 7`，即 τ > 1100 s，`1/f_min = 159 s`） | **8/10** |

`K=3` 对照（4 条逃逸样本，`k3_check.py`）：

| 样本 | K=2 `R̂` / `ratio` | K=3 `R̂`（排序后） | K=3 `ratio` | 逃逸分量数 |
|---|---|---|---|---|
| (0,0,0) | 18.4 / 5.38 | 107.6 → **1.00** | 1.72 | 3/3 链 |
| (0,0,1) | 19.4 / 10.37 | 47.5 → **1.00** | 6.94 | 3/3 |
| (0,1,0) | 13.1 / 4.79 | 19.2 → **1.04** | 6.58 | 3/3 |
| (0,1,1) | 19.5 / 13.47 | 16.6 → **1.03** | 5.00 | 3/3 |

**三条链都把恰好一个分量放在 `ln τ ≈ 7.4–8.2`，只是放在不同槽位。排序后 `R̂` 全部回到 1.0。**
⇒ 提高 K 不消除逃逸；`R̂` 爆表基本全是 **`K!` 置换对称**（外加 `R_inf` 与逃逸分量之间的抵抗脊）。

`Z(f)` 对置换不变 ⇒ `ratio`/`acf` 有效；**分量级参数（单个 `tau`/`W`/`pi`）不可用**。

### 3.1 所以 `unusable_sampling` 该读作什么

不是"采样器坏了"，而是"**该后验在本口径下存在多标签/多表示分支**"。
`bm_core.fit` 在两处会放大多分支：默认 `init_to_uniform` 让各链落到不同置换分支；
`max_tree_depth` 截断又让链间难以互相穿越。二者叠加使 `R̂` 变成"链是否落在同一分支"的指示器，
而不是"后验是否收敛"的指示器。

**这是生产侧的改进点**（本轮不动代码）：`R̂` 若要当门，须先按 `ln τ` 排序（label-invariant）再算。

## 4. 46 条"不可用"换初值后的去向

`PREREG` §2 的敏感性栏（**不进主比例**，只用于判"是不是初始化问题"）：46 条全部补算，

- **46/46 恢复收敛**；
- 恢复后 `ratio` **1.66–8.52**（中位 3.85），**46/46 都 >1.5**；
- 2 条换 3 个 seed 复跑：`7.54/7.46/5.25`、`4.26/4.30/4.26` —— 同一分支内稳定，
  波动只出现在换分支时（`R̂ 9.2` 那一次）。

⇒ **本族的失败是系统性的，不是偶发个案、也不是纯初始化问题**：
`unusable_sampling` 与 `structural_mismatch` 是同一件事的两个层面——
先被多重表示挡在门外，换初值后落到 `ratio > 1.5`。§0 的三分法在本族退化为：
`init_failure` 几乎不存在，`structural_mismatch` 是主因。

## 5. 口径偏差登记（`PREREG` M3-a）

`ta 0.98` vs `0.9`、`tree_depth 10` vs 13）。用真生产配置复跑 4 条：

| 样本 | pilot 口径 `R̂` | 生产口径 `R̂` |
|---|---|---|
| 1 | 16.24 | 16.52 |
| 2 | 14.51 | 15.00 |
| 3 | 10.97 | 16.74 |
| 4 | 15.77 | 16.99 |

**生产配置同样崩、且更差** ⇒ 结论不受影响。但正式表述须写
"**接近生产默认（warmup/链数/tree_depth 偏小）的口径**"，不是"生产默认原样"。

## 7. 结论（可直接引用的三句）

1. **真值拓扑（nested capacitive）在这 60 条上 60/60 贴到噪声底**（`ratio ≤1.00`）、
   残差无结构（`acf` 中位 0.32）、参数除 `Rs` 外恢复 2–20%（`Rs+R1` 2.0%）。
2. **生产 Voigt K=2 在这个族上系统性失配**：收敛者 `ratio` 中位 3.36（自由 σ）/ 1.03（固定 σ），
   但两种口径的 `acf` 都 0.74–0.80 ⇒ 幅度能凑、结构凑不上。
3. **`R̂` 爆表的 76.7% 不能当"采样失败率"引用**：逐链诊断显示是 `K!` 置换对称 +
   `R_inf`/逃逸分量抵抗脊，排序后 `R̂` 回到 1.0；换共享初值 46/46 "恢复"，
   恢复后 46/46 仍 `ratio>1.5`。
