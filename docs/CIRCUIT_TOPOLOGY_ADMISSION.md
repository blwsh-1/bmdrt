## 0. 准入原则（先立规矩，再谈补什么）

| # | 原则 | 具体含义 |
|---|---|---|
| P-1 | **不以「补齐覆盖地图」为目标** | 缺 ≠ 该补。覆盖地图是描述工具，不是待办列表 |
| P-2 | **「模型能拟合」≠「模型值得加入」** | 只报 Rwp 下降不算证据；必须同时看残差结构、参数后验约束、错误拓扑误选率、不损害已通过样品 |
| P-3 | **缺口分三类** | ① 当前研究目标直接需要、且已有数据证明 → 值得补；② 有明确物理场景、现有族确实不表达 → 保留研究扩展，不接生产；③ 数学可实现但当前数据不可辨识或不属目标 → 不补 |
| P-4 | **四个维度分别举证，不得互证** | 拓扑连接 / 元件类型 / 网络层级 / 可辨识性，各需不同证据；一份合成谱或一个拟合改善不能同时证明多项 |

| P-6 | **默认关 + `exploratory` + 不接 `bmdrt.py`** | 所有新增表达能力在准入通过前一律如此；`bm_select.BRANCHES` 不扩 |
| P-7 | **既有验收线不因新族回改** | 补模型不得用来放宽 `acf≤0.50` / `R̂≤1.05` / `div=0` 或重述 §13/§14 |

## 1. 覆盖地图四维重构

| 维度 | 要回答的问题 | 本轮涉及的例子 | 需要的证据类型 |
|---|---|---|---|
| **拓扑连接** | 元件之间如何连接？ | 串联、并联、嵌套、**C3 串联+嵌套混合** | 独立正演的理论上限 / 已知真值混合谱 / 留出预测优势 |
| **元件类型** | 每个支路是什么物理响应？ | R、CPE、L、Ws、Wo、Gerischer；**容性最内层** | 真值谱元件级对拍 + 参数后验约束 + 误选率 |
| **网络层级** | 网络包含几层？ | L=1、L=2、**L=3（C2）** | 第三个窗内时间常数的独立证据 + 层数可恢复性 |

**三者不可混为一谈**：C3 是拓扑连接缺口；容性最内层是元件类型缺口；L=3 是网络层级缺口。
`测试数据/` 的涂层谱只证明**元件类型**缺口，不能用来论证 L=3 或 C3 该立项。

### 1.1 等价类（P-5 的实证）

- **C1 ≡ C4 ≡ 我们的 `parallel/L=2`**：R–L 星三角映射后在 0.01–1e5 Hz 上
  `max rel = 2.7e-16`（§9.4.30.2）；同一套参数**不经映射**直接对拍却是 0.80。
  ⇒ Table 1 的 4 个电路只有 **3 个不同阻抗函数**，§17 的 C1/C4 两行必须合并读，
  否则会凭空多算一次独立电路试验（§9.4.30.3）。
- **`R∥CPE`（ZARC）≡ voigt K=1**：`测试数据/腐蚀` 的 `R1-[R2,P3]` 就是它，已覆盖。
- **C3 在纯 RC 退化下 ≡ voigt K=3**（§9.4.10.1）；一旦带 `R∥L` 感抗支路，
  `Im` 符号与高频极限双重不相容，恒等立刻失效（§9.4.10.2）。

## 4. 三张关键卡的展开

### 4.1 容性最内层：记号澄清与验证条件完成度

#### 4.1.1 必须先澄清的记号差异（否则会实现错拓扑）

评审意见写作 `Z_inner = R3 ∥ CPE3`。**按字面实现会得到错误结果**，原因：

| 写法 | 低频极限 | 归属 | 与真值谱是否一致 |
|---|---|---|---|
| `R ∥ CPE`（ZARC，评审意见字面版） | `Z → R`（有限） | **voigt K=1 等价类，已覆盖**（腐蚀 `R1-[R2,P3]`） | ✗ |
| `R + CPE`（`-` 记号，真值） | `\|Z\| → ∞`、`Im<0`（**阻断型**） | nested 骨架最内层 | ✓ |
| 本项目已实现 `branch="capacitive"` | 同上 | `Z_b = CPE(Q_b,n_b)`，**串联电阻由网络已有的 `R2`/`R1` 承担** | ✓ |

真值文件名：`-` 串联、`,` 并联、`[]` 分组。涂层 `R1-[P2,R3-[P4,R5-P6]]`
最内层是 `R5-P6`（`R + CPE` 串联），钝化 `[P1,P2-R3]-R4` 是 `P2-R3`（`CPE + R` 串联）。
⇒ **要补的是「串联电阻 + 容性支路」这一元件类型**，不是再引入一个并联 ZARC 节点；
后者不仅是错拓扑，还与 §1.1 的等价类重复。本卡精确记号统一采用 `R + CPE`。

#### 4.1.2 现有证据（`CAPACITIVE_BRANCH.md` 全文）

- 骨架归属数值断言：涂层 = nested **L=2**、钝化 = **L=1**、腐蚀 = ZARC。
- 真值对拍（`capacitive_branch_check.py` **独立手写** `Z_P=Q/(i·2πf)^n`，不调用项目正演）：
  涂层 20 条 `3.8e-16`、钝化 20 条 `7.1e-16`；旧两支路与改动前版本逐位对拍
  `max|ΔZ| = 0.000e+00`（numpy + jax 共 4 组）。
- 同谱同 `standard` 档配对：`parallel/L=2` acf **0.944** / R̂ 14.21 / rms_rel 10.81%
  → `capacitive/L=2` acf **0.279** / R̂ **1.005** / rms_rel **7.08%**（Rwp≈10%，贴噪声底 11–12%）。

#### 4.1.3 四条最低验证条件逐条判定

| # | 条件 | 状态 | 说明 |
|---|---|---|---|
| 1 | 不含该支路时存在**稳定结构性残差** | ❌ **多谱预注册判据未达** | 32 条主样本上 `acf>0.50` 占比 **71.9%**（线 75%）、中位 acf **0.796**；无噪档 16/16 全过，掉线的全是 5% 重尾噪声档 |
| 2 | 加入后**残差结构改善**，不只是 Rwp 降低 | ❌ **多谱预注册判据未达** | `Δacf≥0.20` 占比 **68.8%**（线 75%）、中位 Δacf **0.310**、中位 ΔRwp 仅 2.15pp；`C2_L3` 自由度对照中位 Δacf 0.139 |
| 3 | 新增参数有**可接受的后验约束** | ❌ **本轮不判定** | LS 无后验；本轮只给 `start_spread` / `jac_cond` / 参数恢复误差作**线索**（无噪档恢复 2.77e-10）。`Q_b`/`n_b` 后验宽度、贴边、与 `R2` 相关性仍缺；钝化 L=1 `standard` 给 R̂ 197.8 / acf 0.750 |

按 §9.4.21.2「先诊断，不先改模型」与 §11「不改先验」**未擅自改先验**，留作 M3 标定。

#### 4.1.4 第 ④ 步实测（同日第三轮，`out/truth_recovery/summary.md`）

预注册 `RECOVERY_PREREG.md` 先冻结口径，再由 `truth_recovery.py` 独立实现：
拟合侧用**导纳累加**正演（与生成器 `par()` 不同代码路径）、初值只由
`median|Z|` / 频率窗口 / 稳定 md5 决定（**不读 `truth_params`**）、`--selftest`
三方对拍生成侧 7 类 5.8e-16 与项目 `bm_top` 4 组合 4.2e-16。168 条 × 9 候选 ×
3 起点，99.4% 组合收敛；**无噪档容性真族参数恢复中位 `|ln(fit/truth)|`
= 2.77e-10** → 参数恢复层 anti-inverse-crime 已满足，不是只报 Rwp。

**归因（exploratory，不改判定）**：无噪档 16/16 全过 ①②、真族 Rwp 0.000%；
拉低结论的全部是 `heavy` 5% 重尾噪声档（`out_of_window` 0/4、`degenerate` 1/4）。
该档容性真族 Rwp 6.46%（≈5% 噪声底）、感性对照 8.15% —— 容性确实拟合更好，
但感性模型 acf 也被噪声压到 0.24–0.41，结构信号被淹没，`acf>0.50` 缺项探针失效。
⇒ ①② 的「未满足」是**噪声淹没 + 困难轴 LS 局部极小**的混杂，
**不能读作「容性支路无用」**；但预注册线不放宽、判定不改。

**顺带复现 §17 的负面证据**：`C2_L3` 在其真值谱上真族识别率仅 25.0%
（无噪档也只 4/8），在非其真值谱上 BIC 胜率 2.1%，`voigt_K3` 为 0.0%。
条件 ④ 唯一误选例正是 `C2_L3` 真值谱在重尾噪声下被少 3 参数的
`nested_L2_capacitive` 选中（Rwp 6.592% vs 6.677%）→ 第三层在噪声下不可辨识。

**数据集声明缺口（本轮不改产物）**：manifest 的 `structures` 声明含 `white`，
实际噪声档为 `none(0%) / correlated(2%) / heavy(5%)`，`white` 从未生成；
`README.md` 描述与生成代码不一致。本轮按 `noise.kind` 分层并如实记录，
改数据集会动 168 条 sha256，留待单独订正。

### 5.2 端部专用元件

`NESTED_TOPOLOGY_PROJECT.md` §3228–3260：3E 外部第一名电路

### 5.3 其余暂缓项

- **`Wshort`**：`bm_diff.z_wshort` 有正演实现，不等于可以接采样器；低频有限长度扩散
  与 `R∞` 强相关，`WS_CRITERION_PLAN.md` 的 Ws 判据死结未解，18 条真实谱低频是感抗
  （`inductive_tail`/`reject` 各 18/18、`candidate` 0/18）。先做已知真值合成谱的可辨识性扫描。
- **Gerischer**：需先有独立反应-扩散耦合证据、证明有限长度 Warburg / 现有 HN 不够、

- **`n=1`**：作边界/退化情形处理即可，前提是先验与数值实现支持边界值；当前

  两者不是同一数学模型，不能用已有 Ws/Wo 结果替代，也不能因文献存在就直接新增。
- **并联 `Z_ad`**：覆盖地图 #4 是「元件齐、接法不对」，但需先证明串联吸附不能解释数据。
