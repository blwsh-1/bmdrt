## 1. 做了什么

用户要求「从 ECM 里随机抽 3 组模拟数据，对现有代码做一次测试」。执行分三层：

1. **随机组**：全表均匀随机，`seed=20261105` → 行号 `[4382, 5687, 5940]`。这是用户要求的正题。
2. **对照组**：分层抽样（只取「所有分量峰位都在频率窗口内」）+ 纯 ZARC 可组合 + 按真值 K 分组，`seed=11` → `[797, 1139, 3139, 5254]`。目的是把「代码问题」与「数据/结构问题」分开。
3. **噪声实验**：给对照组里两条「点估计完美却被判 rejected」的样本注入 0.5%·|Z| 噪声重跑，验证失败机理。

运行命令：

```bash
python test_ecm.py --quick                                     # 随机组 3 条
python test_ecm.py --stratified --composable --by-k --n 4 --seed 11 --quick --tag control
python test_ecm.py --only 797,1139 --noise 0.005 --quick --tag probe
```

### 4382 `Rs_Ws`（真值：R_inf=106 Ω，半无限 Warburg）

- `R_inf` 拟合 108.6 Ω（+2.5%），K=2，采样分级 1，`acf=0.89`、趋势 1.46σ 在第 100 百分位 → 判「残差有系统性弯曲」
- 两个分量 `f0=1785 / 3.377 Hz`、`φ=0.5020 / 0.5009`、`w=9.77 / 58.3 Ω`
- **两个分量的 φζ 后验都压在 0.5 下界上**（`pz_lo = 0.5002`），这是数据在说「45° 斜率」
- 但 `n_warburg_like = 0` —— 判据漏了，见 §5.5

### 5687 `L-R-RCPE`（真值：R_inf=69.9 Ω，唯一分量 f0=3.48e10 Hz）

- **真值峰位比窗口上界高 4.5 decade**。在 1–1e6 Hz 内，这个 R‖CPE 早已退化成纯电阻 R=62.7 Ω
- 于是 `R_inf=69.9` 与「分量的低频平台 62.7」**完全不可分**，只剩总和 132.6 Ω 可观测
- 模型把 131.7 Ω 几乎全给了 `R_inf`，分量只剩 `w=0.834 Ω`
- 并用三条 ±1 的相关把这件事报了出来：

  ```
  ln R_inf ↔ ln w_1 = -1.00
  ln τ_1   ↔ ln w_1 = -1.00
  ln R_inf ↔ ln τ_1 = +1.00
  ```

→ **这是正确行为**：模型不但没有瞎猜，还明确说了「这三个数只能定出一个组合」。

### 5940 `L-R-RCPE-RCPE`（真值：R_inf=4.31 Ω，两个分量都在窗外）

- CPE1 `f0=5.3e8`（窗口上方 2.4 decade）、CPE2 `f0=0.0763`（窗口下方 2.1 decade）
- `R_inf` 拟合 4.768（+11%），CPE2 的 `φ` 从 0.855 拟合到 0.938
- 强相关：`ln w_1↔φ_2 = +0.99`、`ln τ_1↔ln w_1 = +0.98`、`ln τ_1↔φ_2 = +0.94`

### 随机组小结

三条全部「有分量峰位在窗口外」。这不是抽样运气差，是数据集本身的性质：**7462 条谱里只有 16.3% 全部分量在窗口内**（纯 ZARC 可组合的 6271 条里只有 547 条）。随机抽 3 条，抽到「全在窗口内」的概率只有约 16%。

## 4. 诊断：为什么点估计完美却被判 rejected

### 4.1 直接原因不是拟合差，是采样诊断

797 的 `grade_fail = ['R̂=1.028', 'tail=362', '触顶=53%']`。R̂ 和 tail ESS 只是没过「严格线」，但 **`触顶=53%` 连「可用」档（<5%）都过不了**，所以 `sample_grade=0` → 所有 K 判「不可用」→ `selection_status=rejected`。

### 4.2 根因：无噪声合成数据让 σ 塌陷

| 样本 | `σ_re/zmax` | σ_re 在自身先验中的位置 | 触顶 | R̂max | tail ESS | grade | 状态 |
|---|---|---|---|---|---|---|---|
| 797 | 5.69e-8 | **-12.1σ** | 53% | 1.028 | 362 | 0 | rejected |
| 1139 | 2.78e-8 | **-12.8σ** | 28% | 1.058 | 37 | 0 | rejected |
| 5254 | 3.76e-4 | -3.3σ | 0% | 1.006 | 293 | 1 | ok |
| 3139 | 2.14e-3 | -1.5σ | 0% | 1.010 | 233 | 1 | degraded |

**σ 塌得越狠，触顶越高，分级越低。** 机理：

- 似然是 `obs_re ~ Normal(Zt.real, s_re)`、`obs_im ~ Normal(Zt.imag, s_im)`
- `s_re ~ LogNormal(log(0.01·zmax), 1.0)` —— **没有下界**（`bm_core.py:285`）
- AutoECM 的 Z 是 ECM 正演出来的，**没有测量噪声**。只要模型族能精确表示实部（真值本来就是 `R_inf + Σ R‖CPE`，恰在模型族内），似然就会把 `s_re` 一路推向 0
- `σ→0` 是一个典型漏斗：NUTS 在漏斗里被迫不断加深树，53% 的迭代撞到 `max_tree_depth=13` 的天花板

反证：5254 和 3139 的 σ 没塌，因为模型族**表示不了**它们的真值（5254 少了分量、3139 少了两个），残差有地板，σ 就停在正常位置，触顶 = 0%。

> 讽刺的地方：**拟合越好，诊断越坏。** 797/1139 恰恰因为对得太准，才把 σ 逼到 1e-8。

### 4.3 决定性验证：加 0.5% 噪声

| 样本 | 条件 | `σ_re/zmax` | 先验位置 | 触顶 | R̂max | tail ESS | grade | 状态 |
|---|---|---|---|---|---|---|---|---|
| 1139 | 无噪 | 2.78e-8 | -12.8σ | 28% | 1.058 | 37 | 0 | rejected |
| 1139 | 0.5% 噪声 | 2.45e-3 | -1.4σ | **0%** | 1.012 | 150 | 1 | **ok** |
| 797 | 无噪 | 5.69e-8 | -12.1σ | 53% | 1.028 | 362 | 0 | rejected |
| 797 | 0.5% 噪声 | 3.93e-3 | -0.9σ | **0%** | 1.112 | 15 | 0 | rejected |

**触顶机制确认**：两条样本加噪后 σ 都从 -12σ 回到正常位置，触顶从 28%/53% 直接掉到 0%。

但 797 加噪后换了另一种失败：K 选到 4（多出 `w=0.052` 和 `w=0.306` 两个碎片分量），`R̂=1.112`、`tail=15` —— 采样质量本身崩了。**这说明 quick 档（800/400/2 链）在两种噪声条件下都不足以支撑 K 选择。**

### 4.4 本次测试能下和不能下的结论

| 结论 | 能不能下 |
|---|---|
| 点估计（R_inf / f0 / R / φ）在良态数据上准确 | **能**。797、1139 精确到 3 位有效数字 |
| 「无噪合成数据 → σ 塌陷 → 树深饱和 → 采样分级 0」 | **能**。4 条对照组 + 2 条加噪对照，关系单调，机理清楚 |
| 「`select_k` 的硬筛逻辑有问题」 | **不能**。quick 档的 `触顶` 是逐迭代属性、与采样条数无关，但 `R̂`/`tail ESS` 与条数强相关；加噪后 797 的 R̂=1.112 说明是采样预算问题，不是筛选逻辑问题 |
| 「随机 3 组差是代码问题」 | **不能，且证据指向相反**。三条都因真值峰位在窗外而不可辨识，模型用 ρ=±1.00 正确报出了简并 |

## 5. 五个具体发现

### 5.1 σ 无下界，是本次所有「rejected」的总开关

见 §4.2。这是唯一一个**会直接毁掉下游结论**的问题：真实数据不会触发，但任何近无噪数据（合成谱、仿真、极高信噪比测量）都会触发。

### 5.2 `R_inf` 先验与数据集结构性错配（但影响很小，不建议改）

| 统计项 | 数值 |
|---|---|
| `R_inf` 严格等于 0 的谱 | **4469 / 7462（59.9%）** |
| `R_inf` 落在先验 3σ 下界（0.0100·zmax）之外 | **5800 / 7462（77.7%）** |
| 按电路：`RCPE-*` / `RC-RC-*` / `RC-G-G` | `R_inf=0` 占比 **100%** |

`R_inf ~ LogNormal(log(0.2·zmax), 1)` 的支撑集是 `(0, ∞)`，**表示不了 0**；3σ 下界是 `0.0100·zmax`，而近 60% 的谱真值就是 0。

**但我原本以为这是主因，数据把它否掉了**：

| 样本 | 真值 R_inf | 先验位置 | 拟合 R_inf | 相对误差 |
|---|---|---|---|---|
| 797 | 0.0508 | **-2.60σ** | 0.05085 | **+0.1%** |
| 1139 | 728 | **-4.44σ** | 727.7 | **-0.04%** |
| 3139 | 0 | -∞ | 1.08 | 占 zmax 0.45% |
| 5687 | 69.9 | **+0.97σ（正中心）** | 131.7 | **+88%** |
| 5940 | 4.31 | -0.98σ | 4.77 | +11% |

**先验位置与 R_inf 误差无关**：-4.44σ 的 1139 精确恢复，+0.97σ 的 5687 偏 88%。5687 的偏差来自「分量峰位在窗外导致的不可辨识」，不是先验。**所以 `R_inf` 先验不要动。**

### 5.3 `hn_warburg_signature` 在 K≥2 时漏判（4382）

判据（`bm_diff.looks_like_warburg`）要求三条同时成立才给 `strong`：

```
pinned(φζ≈0.5)  and  (outside(峰位出窗) or atb(贴τ边界))  and  degen(R-τ简并)
```

4382 只满足第一条：`φζ=0.502/0.501`（`pz_lo=0.5002`，紧贴 0.5 下界），但两个峰位都在窗口内（`p_peak_out=0`）、不贴 τ 边界、`corr(lnR,lnτ)=+0.716`、`ridge=1.72` 都没到简并线 → 判 `no`。

**漏判原因**：判据的前提是「Warburg 表现为单个分量的 R–τ 退化脊线」。但 K≥2 时模型改用「多个 φ≈0.5 的分量拼出 45° 段」，不产生简并 —— 这条路径没被覆盖。而 4382 的真值恰好就是 `Rs_Ws`。

### 5.4 `--quick` 档与 `select_k` 的严格阈值在设计上不兼容

严格档要求 `tail ESS > 400`，而 quick 档总采样量只有 `2 链 × 400 = 800`，`tail ESS>400` 需要接近完美混合才可能达到；`触顶<1%` 更是几乎不可能。所以 **quick 档下 `k_selection_status` 恒不可信**。

脚本和报告里已经写明「quick（粗筛，指标不可当结论）」，但实际使用时很容易被 `rejected` 这个词误导成「模型选错了」。

### 5.5 测试脚本本身的三个坑（本轮已修）

1. **电阻编号不总等于 CPE 编号**：`L-R-RCPE-RCPE` 里 R1 是串联电阻，CPE1 配 R2。原先 f0 算成 2.9e10 Hz。修法：`off = 1 if circ.startswith("L-R-") else 0`。
2. **Gerischer 键名**：`re.findall(r"R_g(\d+)")` 返回 `['1','2']`，`k.replace("R_g","t_g")` 不生效 → `KeyError`。修法：改成 `r"R_g\d+"`。
3. **`--reuse` 行号漂移**：加了筛选后池子变了，同一 seed 抽出不同行。修法：不加任何筛选时保留全表。

## 6. 建议

### 6.1 优先做：给 σ 加噪声地板

```python
# bm_core.make_model 里，sigma is None 分支
s_re = numpyro.sample("s_re", dist.LogNormal(jnp.log(0.01 * zmax), 1.0))
s_im = numpyro.sample("s_im", dist.LogNormal(jnp.log(0.01 * zmax), 1.0))
```

改成带下界的参数化（例如 `s = floor + LogNormal(...)`，或 `s = floor·exp(x)`），`floor` 进 `config.json` 的 `fit` 段，默认 `1e-4·zmax`。

**为什么 1e-4 是安全的**：真实 2E 谱的 `σ_im/zmax` 落在 1e-3–1e-2 区间，比 1e-4 高一个量级以上；而合成谱塌到 1e-8，1e-4 的地板能拦住 4 个量级的塌陷。地板同时有物理意义——任何测量系统都有噪声底。

**预期效果**：合成谱的 σ 停在 -4σ 附近，漏斗消失，触顶掉到 0%，`sample_grade` 回到 1–2，K 选择才有意义。

### 6.2 次优先：`hn_warburg_signature` 增加多分量分支

当 ≥2 个分量的 `φζ` 同时落在 `0.5±0.04`、且各自峰位在窗口内时，至少给 `weak` 并在 `why` 里写明「多个 φζ≈0.5 分量拼出 45° 段，可能是扩散尾被拆成几段」。不要直接给 `strong`——单个 `R‖CPE(n=0.5)` 也会有 `φ=0.5` 且峰位在窗内，需要人看。

### 6.3 测试流程：`test_ecm.py` 默认加噪声

已实现 `--noise`（本轮新增），建议后续默认 `0.005`。无噪谱适合检验「点估计」，不适合检验「K 选择」和「采样诊断」——报告头已自动标注这一点。

### 6.4 不要改：`R_inf` 先验

见 §5.2，数据证明它不是误差来源。

### 6.5 下一步：full 档确认

用 full 档（3000 warmup / 1000 采样 / 3 链）+ 0.5% 噪声重跑 797 与 1139：

```bash
python test_ecm.py --only 797,1139 --noise 0.005 --tag full
```

只有这一步能回答「`select_k` 的筛选逻辑本身对不对」。本轮所有 `rejected` 都不能作为该结论的证据。
