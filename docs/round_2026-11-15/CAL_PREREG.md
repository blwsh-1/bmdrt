# CAL-01 预注册：开-短路 + 已知 RC 的最小化实物校准

> 性质：**预注册实验**（跑前冻结）。目的：拿**独立于样品**的测量，检验
> 「测量链自身的寄生响应」能否解释 §9.4.41 报出的高频残差。
> 不改 `bm_*.py`、不改 M-b 阈值、不跑批量拟合、不与 E1 合并。

## 0. 定位

M-B-SIM-01 的结论是：4 参数夹具模型与宽弛豫/Warburg **都落在生产模型的张成空间内**，
因此 M-b 无法区分、且这两族都解释不了真实残差。要继续往下走，必须引入**新的独立信息**。
本实验是三件套里最便宜的一件：**不需要样品、不需要状态、不需要重复扫描三次同状态**，
只需要同一根线、同一个夹具、五分钟。

**它不能回答**：残差是否来自样品侧。它只能回答「测量链能否产生这么大的、这个方向的偏差」。

## 1. 冻结的采集内容

同一线缆、同一夹具、同一档电流量程，按 `short → open → rc100` 顺序，各 **3 次**，每次之间不拆装：

| 对象 | 接法 | 期望（理论） |
|---|---|---|
| `short` | 夹具两电极直接短接（同一块短路片或同一段同材质导线） | \|Z\| → 0，只剩 `Rs + jωLs` |
| `open` | 两电极悬空、几何位置与测样品时一致 | \|Z\| 很大，近似 `1/(jωCp)` |
| `rc100` | **已知 100 Ω** 精密电阻（或已知 RC），四线接法优先 | \|Z\| ≈ 100 Ω、相位 ≈ 0 |

**两条硬要求**：

1. **优先保存「仪器补偿关闭」的原始数据**（raw / uncompensated）。若仪器只能给补偿后数据，
   必须在 `session.json` 里写明补偿档位，并把该事实标进结论（补偿后的数据不能再用来反解
   `Rs/Ls/Cp`，只能用来做「校准后残差」验收）。
2. 三次重复的**频率栅格必须一致**；不一致时按 E1 的 `exact → common_subset(≥90%) → blocked`
   处理，**只删点不插值**。

## 2. 前置自洽门（先查这个，再谈解释力）

这四道门是**阻断式**的：不过门就停，不换容差补救，如实上报。
`REFS_DIGEST` 里那份外部仓库就是反面教材——「短路」读到 0.102 Ω 比「100 Ω 参考」的 0.069 Ω 还大，
却照样发布了校准文件。

| 编号 | 判据 | 不通过意味着 |
|---|---|---|
| G-1 | `\|Z_short\| @ 1e4–1e5 Hz < 2 Ω`（< 真实样品 \|Z\|≈45 Ω 的 5%） | 短路接法本身有接触电阻，或线太长 |
| G-2 | `\|Z_open\| @ 1 Hz > 20 × \|Z_sample\| @ 1 Hz` | 夹具漏电/几何不对，open 不代表真实开路 |
| G-3 | `rc100` 在 1 Hz–1e4 Hz 内 `\|\|Z\|−100\|/100 < 5%` 且 `\|φ\| < 3°` | 参考件不准、或四线接法退化成两线 |
| G-4 | 同对象 3 次重复的两两 `\|ΔZ\|/\|Z\| < 2%` | 连接不稳定，后面所有反解都不可信 |

## 3. 反解与判定

用 §2 通过门的数据，按 **B 组同一变换**联合反解一套夹具参数：

```
Z_meas = Rs + jωLs + 1/(1/Z_true + 1/Rp + jωCp)
```

- `short`：`Z_true = 0` ⇒ 直接给 `Rs + jωLs`（两点定 L，全频段定 Rs）
- `open`：`Z_true = ∞` ⇒ `1/(1/Rp + jωCp)`
- `rc100`：`Z_true = 100`（或已知值）⇒ 交叉校验三者是否自洽

**判据（写死）**：把反解出的 φ̂ 作用到 14 条真实谱的拟合曲线上，得预测偏差
`Δ(f) = fixture(Z_fit) − Z_fit`，与实测残差 `res = Z_fit − Z_obs` 比（若夹具为真，应有 `res ≈ −Δ`）：

| 判定 | 预注册条件 | 允许的结论 |
|---|---|---|
| **K1 夹具可解释** | 高频带(100–1e5) `corr(res, −Δ) ≥ 0.70` 且幅度比 `median\|res\|/median\|−Δ\| ∈ [0.5, 2]`，并且在 ≥8/14 条谱上成立 | 测量链是这个频段残差的主要来源，后续必须走校准修正 |
| **K2 夹具不够** | `corr < 0.70` 或幅度比落在 [0.5,2] 之外，且在 ≥8/14 条谱上成立 | 夹具最多解释一部分，重心转到样品侧或模型表达力 |
| **K3 判不了** | 其余（含 G-1–G-4 未过、只拿到补偿后数据、栅格 blocked） | 不解释为任何一方，补测或改接法后重做 |

**另有一条独立旁证（不需要新数据）**：单一夹具给的是**一条固定的 Δ(f)**，它在不同样品上等效出的
`L_eq = −Im(Δ)/ω` 只能取一个有界的范围；而 §9.4.41 实测的 `L_eq` 在 **−72…+35 µH** 之间**变号**。
若 φ̂ 预测的 `L_eq` 跨度覆盖不了实测跨度的 50%，则即便 K1 不成立也能独立支持 K2。

## 4. 不做什么

- 不把校准结果写回生产拟合（不做 `Z_corrected` 生产化）；
- 不据此改 M-b 阈值、不改 §13/§14/§17；
- 不用校准数据反推样品参数；
- 不在本实验里加任何新电路元件；
- 不把「夹具可解释」写成「样品侧无结构」——两者可以同时存在。
