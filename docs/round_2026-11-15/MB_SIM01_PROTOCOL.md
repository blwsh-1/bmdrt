## 0. 目的与边界

回答三个问题：

1. 仪器/夹具寄生（H1）能否产生与 §9.4.41 所报同类的残差（高频成片、Im 主导、lag1）？
2. 样品侧未建模结构（H2）能否产生**同样**的残差？
3. 现有 M-b 指标（残差频率序列 ACF）能否在**已知生成机制**的数据上区分二者？

**结论只关于区分能力，不关于真实残差的物理来源。** 即使 B/C 可稳定区分，也不构成
「真实数据里的残差来自仪器」的证据；即使不可区分，也不能反推 H1/H2 哪个为真。

明确不做：新增生产元件、改 M-b 定义/阈值、用真实寄生参数辅助拟合、按中途结果调组定义、
把 `mb_hf_l_equiv` 解释成真实夹具电感。

## 1. 模拟输入口径（跑前核对，2026-11-15）

| 项 | 实测值 | 来源 |
|---|---|---|
| 频率栅格 | **50 点，0.01–1e5 Hz，7 点/decade（比值 1.389，49 段正好覆盖 7 decade）** | `out/_m6_samples/z_csv/AZ31-*.csv`；14 条共用同一栅格（`12Li_150` 经 M1 剔 1 点后 49） |
| 阻抗量级 | \|Z\| = 45–1530 Ω（低频 1e3 量级，1e5 Hz 处 34–45 Ω） | 同上 |

| 真实残差 | rms 2.68–30.8%，全谱 acf 0.341–0.896；**高频带(100–1e5, n=21) 0.669–0.916，14/14 越白噪声 p95=0.486** | `out/m4_mb_diag.json`（§9.4.41） |
| 通过与未过组 | 通过 4 条 acf 0.341–0.466（rms 2.68–4.52%）；未过 10 条 0.505–0.896 | 同上 |
| voigt 基线 acf | **0.730–0.941**（14/14） | `out/m4_holdout2_ess.json` |

**两处由口径直接推出的结论（决定了下面的设计）**：

- **M-b 的相对项在本批恒不约束**：`acf ≤ 0.50` 且 `voigt−acf ≥ 0.20`，而 voigt 基线 ≥0.730
  ⇒ `0.50+0.20 = 0.70 ≤ 0.730`，故 `acf ≤ 0.50` 成立时相对项必然成立。
  因此模拟里 **M-b 触发判据取绝对值 `acf > 0.50`**，这是相对项判别力的**上界**（相对项
  只会进一步削弱区分力，不会增强）。为验证该等价性，另在 B/C 各抽 5 条补跑 voigt 基线（§8）。
- **1e5 Hz 处 |Z| 只有 34–45 Ω**，所以「几十 µH 的串联电感 / 几 nF 的并联电容」在本窗口
  是**一阶效应**，不是微扰——B 组必须在这个量级上扫，而不是按电缆手册的典型值取。

## 2. 模拟数据设计（四组，配对生成）

对第 `i` 个实例，四组共用**同一**样品真值 `θ_i` 与**同一**噪声实现 `ε_i`（配对设计，
消除样品参数与噪声这两个混淆因素）：

```
A :  Z_meas = Z_s(θ)                                + ε
B :  Z_meas = Rs + jωLs + 1/(1/Z_s(θ) + 1/Rp + jωCp) + ε
C1:  Z_meas = Z_s(θ) + Re/(1+(jωτe)^α)^γ             + ε
C2:  Z_meas = Z_s(θ) + Rw·tanh(z)/z,  z = sqrt(jωτw) + ε
D :  Z_meas = F(Z_s(θ) + Z_extra(ψ), φ)              + ε
```

- `Z_s` = 生产基准电路 `T.z_nested(f, θ, branch="parallel", layers=2)`。
- `θ_i` 取自 **14 条真实谱的拟合中位参数池**（`out/m4_holdout2_ess.json` 的 `rows[k].rows[0].params`），
  均匀抽一条 + 逐参数量级抖动 `exp(N(0,0.15))`（R/Q/τ），`n` 加 `N(0,0.03)` 截到 [0.30,1.00]。
  这样 |Z| 的量级分布与真实批一致，寄生参数的**相对**影响也随之真实。
- `φ = (Rs, Ls, Cp, Rp)` 按 §3 冻结范围独立抽取；`ψ` 按 C1 或 C2 抽取（各半）。
- D 组的 `Z_extra` 与 `φ` 独立抽取（不复用 B/C 实例的参数），检验混合效应的可归因性。
- 噪声：`ε = σ(a+ib)`，`a,b~N(0,1)`，`σ_j = pct·|Z_clean,j|`，`Z_clean` 为加噪前的测量阻抗。
  故 A 组残差 rms 恰为 `pct`（≈2% 或 4%），与 §1 的似然尺度同口径。
- **不施加 M1 剔点**（干净数据无不可靠端点）；另记 `cut_top` 若施加会剔几个点，仅作旁注。
  理由是剔点会让不同实例落在不同频点上，破坏 acf 与分频段统计的可比性。

## 3. 参数范围（冻结；单位与抽样方式同表）

**H1 仪器/夹具（B、D 组）**

| 参数 | 范围 | 抽样 | 依据 |
|---|---|---|---|
| `Rs` | 0.05 – 5 Ω | log-uniform | 接触/线阻，相对 \|Z\| 为 0.003%–11% |
| `Ls` | 0.1 – 100 µH | log-uniform | 1e5 Hz 处 ωL = 0.06–63 Ω，覆盖 `mb_hf_l_equiv` 的 35 µH 量级 |
| `Cp` | 10 pF – 10 nF | log-uniform | 1e5 Hz 处 1/ωC = 159 kΩ–159 Ω，可低至与样品同量级 |
| `Rp` | 1e3 – 1e7 Ω | log-uniform | 并联漏电；**可能在本窗口完全无作用——这正是要测的** |

**H2 样品侧（C、D 组）**

| 参数 | 范围 | 抽样 | 说明 |
|---|---|---|---|
| C1 `Re` | 1 – 40 Ω | log-uniform | 额外宽弛豫的幅值（相对 \|Z\| 0.05%–90%） |
| C1 `fe` | 1e-2 – 1e4 Hz | log-uniform | 峰频，τe = 1/(2πfe)；**v2 上调上界**（见 §9） |
| C1 `α` | 0.30 – 0.80 | uniform | 宽度 |
| C1 `γ` | 0.20 – 0.60 | uniform | 偏斜；αγ ∈ [0.06,0.48] 给慢幂律尾 |
| C2 `Rw` | 5 – 60 Ω | log-uniform | 有限长 Warburg 的低频平台，即直流极限附加电阻 |
| C2 `fw` | 1e-2 – 1e4 Hz | log-uniform | 特征频率，τw = 1/(2πfw)；高频 → `Rw/sqrt(jωτw)` |

**范围声明**：以上是按 `§1` 的窗口与量级做的**敏感性扫描范围**，**不是**任何具体硬件的
实测寄生参数范围；不得把命中的参数值解释成夹具的真实 R/L/C。

## 7. 判定规则（预注册）

先算 `AUC(B vs C)`：以 `acf` 为分数，B 为正类，C 为负类；bootstrap（2000 次，按实例）给 95% CI。
分层：`pct=2` 与 `pct=4` 各算一次。

**类型 A：具备区分能力**（须同时满足）

1. A 组误报率 `P(acf>0.50) ≤ 0.10`；
2. 总体 `AUC ≥ 0.90` 且 95% CI 下界 `≥ 0.75`；
3. **两个噪声档各自 `AUC ≥ 0.80`**；
4. 差异不依赖单一参数：在 B 组内，`acf` 与任一寄生参数的对数相关 \|ρ\| 均 `< 0.9`
   （即不是「只有一个极端参数组合才有效」）；
5. D 组不被系统性归为单一来源：最近质心归因（特征 `[acf, acf_hf, rms_hf, rms_mid]`，
   用 A+B+C 池化标准化，质心取自 B/C）得到的「归为 B」比例 ∈ [0.20, 0.80]。

**类型 B：只能检出，不能归因**：B、C 两组触发率均 `≥ 0.80` 且 `AUC < 0.75`。

**类型 C：模型不足**：B 或 C 的**高频残差特征**无法达到真实数据量级，即
`median(acf_hf) < 0.60`（真实 14/14 为 0.669–0.916）；此时不能据本实验排除 H1/H2。

**类型 D：当前窗口内不可辨识**：B 与 C 的**阻抗响应**本身近似相同（两组逐点
`median|ΔZ|/|Z| < 5%`）且指标不可分 ⇒ 记为
`Non-identifiable under the current frequency window and measurement conditions`。

多类型同时出现时按 **C > D > B > A** 的保守顺序报告（先报「不可解释」的硬失败）。

## 8.1 附加分析 S6：跨体系「单一共享夹具」的可检验性（无 MCMC）

不占用主实验的 80 条谱，只用同一套 `z_parasitic` 变换做**判据校准**：

- **H1 情形**：两体系共用同一组 φ（样品不同）。用两体系数据**联合**反解一个 φ，
  残差应只剩噪声 ⇒ 检验有功效。
- **H2 情形**：两体系各带不同样品侧结构、无夹具。联合反解一个 φ 后残差应显著大于噪声
  ⇒ 检验有特异性。

阈值（写死在本节，跑前）：联合残差 rms ≤ **5%** 判「可解释」；功效 = P(H1 ≤5%)，
特异性 = P(H2 >5%)；两者均 ≥0.8 才判 `usable`。12 组夹具 ×（H1/H2 各一次），噪声 2%/4% 交替。

**已声明的两个弱点**（写在此处而不是事后才说）：

1. 该检验能分辨的前提是**样品侧结构明显高于噪声**；若结构幅度只有噪声的 1–2 倍，
   任何 4 参数夹具模型都有足够自由度把它吸收。故必报「结构 >2×噪声」子集上的条件化特异性。
2. 反解用的是**真值** `Z_s`（最好情形）。真实分析里只能用拟合模型，误差只会更大，
   故本节的功效是**上界**。
