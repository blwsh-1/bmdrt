## 2. K 比较与机制比较的阈值规则拆开

`pairwise_dse.csv` 新增 `comparison_type` 与 `threshold_rule`：

| 类型 | 阈值 | 用途 |
|---|---|---|
| `K_selection` | `max(2, 2·dse)` | 家族内 K=2 vs K=1、合成用例 |
| `mechanism` | `1·dse` | Ws−Wo、Ws−none（规格 §3.2 的 `|Δ| < dse`） |

不再让同一列 `thr` 在两种比较里代表两种含义。本案例两对机制比较仍都 `|Δ| < dse` → `ambiguous`。

## 3. 高 Pareto-k 敏感性复核（本轮最重要的新发现）

新增 `pareto_k_sensitivity.py`：对每个配对，标出任一模型 `pareto_k>0.7` 的频点，
去掉后重算 Δ/dse 与判定。**这是「删除高 k 点」的敏感性复核，不是 moment matching / 精确 LOO。**

| 配对 | 高 k 点 | 逐点贡献 | 全点 Δ / dse | 去点 Δ' / dse' | 判定变化 |
|---|---|---|---|---|---|
| K2−K1 / none | 1（91.03 Hz, k=1.071） | −3.863 | 187.021 / 15.020 | 190.884 / 12.864 | `K2_better` → `K2_better` ✅ |
| K2−K1 / Ws | 1 | −4.820 | 76.232 / 14.318 | 81.052 / 12.773 | ✅ |
| K2−K1 / Wo | 2 | +5.646 | 70.502 / 12.853 | 64.856 / 8.670 | ✅ |
| **Ws−Wo / K=2** | 1（91.03 Hz） | −0.418 | 0.297 / 0.616 `ambiguous` | **0.715 / 0.439 `preference`** | **⚠️ 结论翻转** |
| Ws−none / K=2 | 1 | −0.569 | 0.688 / 1.612 | 1.257 / 1.498 | `ambiguous` ✅ |

**结论按审查员建议拆开**：

- **K 选择稳健**：高 k 点不但没撑起 K=2 的优势，去掉后优势反而更大；三族去点后仍显著。
- **机制不可区分是探索性证据**：Ws−Wo 这一对去掉高 k 点后从 `ambiguous` 变成偏 Ws，
  说明该结论对单个高 k 频点敏感。`mechanism=ambiguous` 保留为工作判断，
  但在 `replay_identifiability.csv` 增加 `mechanism_pareto_k_caveat`，
  明确「尚待精确 LOO / moment matching 复核，不能当严格统计结论」。

Pareto-k 复核脚本修过一个对齐 bug：`pointwise_loo.csv` 的 index 是 10 个模型频率的并集
（合成用例点数不同），直接相减会把 NaN 行算进 N 而放大 dse；已改为 `dropna()` 后只保留
两模型共有的频点，重算结果与 `pairwise_dse.csv` 逐位一致。

## 4. 第四层状态命名统一

`asymptotic_only` **已从第四层状态中删除**（审查员指出 `three_exact_*` 检查的是精确幅值稳定性，
不是渐近近似是否有效）。现在只用：

| 状态 | 判定 |
|---|---|
| `reference_frequency_stable` | 两个参考频率下精确 HN 幅值三条件都满足 |
| `reference_frequency_dependent` | 两个参考频率结论不一致（**本案例**） |
| `unidentifiable` | 指定参考频率下精确贡献本身也不稳定 |
| `not_applicable` | 无对应慢分量 |

`A_*=w(ω_*τ)^{-φ}` 只作高频渐近诊断，有效性单独记录 `asymptotic_valid`（`ωτ>10`）——
本案例低频端 `ωτ` 0.52–1.23，全为 False。`reference_frequency_contribution.csv` 的
`verdict` 现为 `dependent / stable / dependent`，整体仍 `reference_frequency_dependent`。
