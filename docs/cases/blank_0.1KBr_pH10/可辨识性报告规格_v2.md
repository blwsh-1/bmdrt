## 0. 设计原则

1. **四层分离**：模型选择（K）、机制可辨识性、扩散参数可辨识性、分量参数可辨识性各算各的，
   一次运行不能替代跨模型证据。
2. **缺少证据写 `not_tested`，证据相互冲突才写 `ambiguous`。**
   不把未测试误判成机制不确定，也不为了让状态机看起来完整而过度解释数据。
3. **严格结论与诊断展示分开**：KK `warn` 或采样等级不足时，可以出探索性结果，
   但不能输出严格的 `converged`。

## 1. 本案例的最终判定（四层）

| 层级 | 判定 | 证据与含义 |
|---|---|---|
| K 选择 | `converged`（K=2） | 三族配对 Δ 187.021/76.232/70.502，均 > thr 30.040/28.635/25.706；去高 Pareto-k 点后仍显著，优势不依赖扩散项 |
| 机制可辨识性 | `ambiguous`（**探索性**） | 完整频段三族对 K=2 预测差异均未超配对 dse（`Ws−Wo` 0.297 < 0.616、`Ws−none` 0.688 < 1.612）；删除高 Pareto-k 点后 Ws−Wo 判定翻转，结论对单个频点敏感，待 91.03 Hz 的 moment matching / 精确 LOO 复核 |
| 扩散参数可辨识性 | `shape_resolvable_params_degenerate` | K=2/Wo 的形状可分（带内形状差 99%），但 `ρ(ln R_W, ln τ_D)=0.907`，`C_D` ±84.9%、垂直脊线 ±613% |
| 参考频率阻抗贡献 | `reference_frequency_dependent` | 精确 HN 幅值 `A_exact(ω_*)` 的后验稳定性依赖参考频率；低频端 `ωτ`≈0.52–1.23，不满足渐近近似 `ωτ≫1` |

**三条措辞区别（必须保留）：**

- `shape_resolvable` **不等于** `parameters_identifiable`；
- `reference_frequency_dependent` **不等于**整个慢分量都不可辨识——可辨识的是指定参考频率上的阻抗贡献，且该稳定性依赖频率尺度；
- `mechanism_identifiability=ambiguous` **不应该反过来影响** `k_selection`。

## 2. 为什么 v1 需要修订

v1 把本案例判成「K 选择不确定」。P2 的六模型比较改变了这个判断：

| 扩散设置 | K=1 elpd | K=2 elpd | K=2 优势 |
|---|---|---|---|
| `none` | −119.520 | 67.502 | 187.021（配对 dse 15.020） |
| `Ws` | −8.043 | 68.189 | 76.232（14.318） |
| `Wo` | −2.610 | 67.892 | 70.502（12.853） |

K=2 的优势在三个家族里都成立，而 K=2 内部预测不可分。所以本案例的不确定性在**物理分解**，不在 K。
把 K=2 标成 `K_SELECTION_AMBIGUOUS` 会让下游误以为「连用几个分量都没定」。

## 3. 四层定义

### 3.1 `k_selection_status`（K 复杂度选择）

| 取值 | 含义 |
|---|---|
| `converged` | LOO 在可接受候选中给出稳定选择 |
| `degraded` | 选定了，但有可解释的简并 |
| `rejected` | 所有候选采样不合格 |
| `rejected_by_kk` | KK 门禁拒绝 |
| `not_compared` | 只有一个候选（强制单 K / 无 K 扫描） |
| `K_SELECTION_AMBIGUOUS` | **仅当 K 本身不稳**：候选间 Δ 与 dse 同量级、候选集合不完整、或不同扩散家族给出不同 K |

**峰位出窗不再把 K 判成 ambiguous**，只记录 `component_out_of_window=true`，不确定性交给第二层。

### 3.2 `mechanism_identifiability`（三态，含转换条件）

```
not_tested
├── controls 不完整                     → not_tested
├── controls 完整，预测差异显著          → evidence_for_model_preference
└── controls 完整，预测差异不显著        → ambiguous
```

| 取值 | 含义 |
|---|---|
| `not_tested` | 未做（或未做全）跨扩散对照。**默认值**，不能默认写成 ambiguous |
| `evidence_for_model_preference` | 对照完整，且至少一个模型的预测优势 > dse（有偏好证据，但仍非物理证明） |
| `ambiguous` | 对照完整，但预测差异 < 配对 dse：**在当前测试模型集合内**，预测证据不足以区分物理解释 |
| `preference_conflict` | 对照完整但出现**方向相反**的显著偏好；不能汇总成单一 `evidence_for_model_preference` |
| `comparison_incomplete` | 任一机制配对的 Δ 或 dse 缺失/非有限或 dse≤0；**不得**据此推断 `evidence_for_model_preference` |

机制判定由纯函数 `decide_mechanism(mech_diffs, controls_missing, controls_complete)` 执行，
严格按「空比较 → 完整性 → controls → 显著性与方向」顺序，不得跳过任何一步。

`ambiguous` 表达的是「当前模型集合内证据不足」，**不是**「这些机制在物理上完全等价」。

### 3.3 `diffusion_identifiability`

| 取值 | 判定 |
|---|---|
| `no_diffusion` | 未启用扩散项 |
| `indistinguishable` | `level=indistinguishable`（带内形状差 < 2% 或 `f_D` 在窗口外） |
| `shape_resolvable_params_degenerate` | 形状可分，且（`|ρ(ln R_W, ln τ_D)| > 0.9` **或** `C_D` 相对区间宽度 `(q95−q05)/q50 > 50%`）；两个判据分别记录，逻辑「或」决定状态 |
| `resolvable` | 形状可分且扩散参数有界 |
| `unknown` | 代码拿不到 `τ_D`（Ws 单独跑时） |

### 3.4 `component_identifiability`

| 取值 | 判定 |
|---|---|
| `identified` | 各分量独立参数区间窄、无强相关 |
| `reference_frequency_contribution`（指标） | 指定参考频率上的**精确 HN 幅值** `A_exact(ω_*)=\|w/[1+(jω_*τ)^φ]^ζ\|`（ζ=1 时为 `w/√(1+2x^φ cos(πφ/2)+x^{2φ})`，`x=ω_*τ`），单位恒为 Ω；不依赖高频渐近近似。`A_*=w(ω_*τ)^{-φ}` 只保留作渐近诊断，并报告 `ωτ` 是否 >10 |
| `reference_frequency_stable` | 三条件 `CV(A_exact)<CV(w)`、`<CV(τ)`、`|ρ(ln w,ln τ)|>0.9` 在**两个参考频率**（ω₁=2π·f_min、ω₂=2π√(f_min·f_max)）下都成立 |
| `reference_frequency_dependent` | 两个参考频率结论不一致；含义为「慢分量在所选参考频率上的阻抗贡献，其后验稳定性依赖频率尺度」 |
| `unidentifiable` | 指定参考频率下的精确贡献本身也不稳定 |
| `not_applicable` | 没有对应慢分量 |

**`asymptotic_only` 已从第四层状态中删除**；`A_*=w(ω_*τ)^{-φ}` 只作高频渐近诊断，
其有效性由独立的 `asymptotic_valid`（`ωτ>10`）记录，不与精确幅值稳定性混用。
| `unidentifiable` | 连 `B` 都不稳 |
| `not_applicable` | K=1 且无慢分量 |

## 4. 判定顺序

```
① KK 门禁：fail → rejected_by_kk；warn → 只出探索性结果，不写 converged
② 每个候选的采样诊断：grade < 2 / div>0 / 触顶≥1% / ESS<400 / R̂>1.01 → 该候选不合格
   全不合格 → rejected
③ **从一开始就只有一个候选**（强制单 K / 无 K 扫描）→ not_compared（仍继续算 3.3/3.4）
   若原本是多候选、部分因采样不合格被剔除 → 属于「候选集合不完整」，**不走 not_compared**，继续到 ⑤
④ K 选择（thr = max(2, 2·dse)）：
     候选不完整                  → K_SELECTION_AMBIGUOUS
     配对 dse 缺失/非有限        → K_SELECTION_AMBIGUOUS（禁止严格 converged）
     Δ ≤ thr                     → K_SELECTION_AMBIGUOUS（差异不显著，取小 K 只是工程默认，不是统计结论）
     Δ > thr, best.P_out ≤ 0.5   → K=best, converged
     Δ > thr, best.P_out > 0.5   → K=best, converged + component_out_of_window=true
     多 K 时 Δ 取 best 与「最强较低 K 竞争者」K_lower* 的配对差，不是与 min(K) 比；
     配对证据由 `pairwise_comparisons[(best, lower_star)]` 映射提供，直接读取该配对的
     Δ / dse / thr / n_observations / comparison_type，**不用单一标量、不用汇总 ELPD 相减**；
     缺该配对 → `K_SELECTION_AMBIGUOUS`。来源统一为 `pairwise_dse.csv`（逐频点 elpd 差值）
⑤ K 本身不稳（Δ 与 dse 同量级 / 候选不完整 / 不同扩散家族选不同 K）
                                → K_SELECTION_AMBIGUOUS
⑥ 机制三态：按 3.2 的转换条件，独立于 ④⑤
⑦ 扩散/分量维度：独立计算
```

## 5. 阈值与字段

### 5.1 四参数定值

| 参数 | 定值 | 说明 |
|---|---|---|
| `elpd_k` | **2.0 × dse** | 保守工程阈值，不是普适统计定理；最终还要看配对差分布 |
| `grade_min` | **2** | 只有严格采样通过才允许改变模型选择状态 |
| `kk_status` | **只允许 `ok`** | `warn` 不进入严格模型选择结论 |
| `k_reference` | **LOO 最优模型** | 所有能算 LOO 的分支统一取 `max(elpd)`；返回完整标识 `{family, K, elpd}`，无 LOO 时 `None`；仅作预测/绘图参照 |

### 5.2 `controls` 必须互斥、可追溯

不能只记布尔值。每个 control 一条记录：

```json
{
  "family": "Ws",             // none / Ws / Wo
  "K": 2,
  "data_sha256": "6e73bafb...",
  "status": "not_compared",   // 该次运行自身的状态；强制单 K 时就是 not_compared
  "run_id": "G_K2_Ws",
  "elpd_loo": 68.189
}
```

`status` 只描述**该次运行**，不代表跨模型比较结论。`effective` 采用 **fail-closed**：
 `kk.status / sample_grade / divergences / tree_cap / rhat_max / ess_bulk / ess_tail`
 任一缺失或非有限即 `effective=False`，并记入 `missing_diagnostics`；缺字段不得默认成 0 或跳过。
 `controls_complete = 无 missing 且全部 effective 且 kk_all_ok`。门控输入来自随包的
 `control_diagnostics.csv`（由 `export_control_diagnostics.py` 从 run.log 导出），回放脚本不依赖仓库路径。

- `controls_done` 与 `controls_missing` **互斥**，同一 `(family,K,data_sha256)` 不能同时出现在两边；
- `controls_missing` 只写「计划做但没做」的项；不适用（如频段内 Ws/Wo 不可分）写进 `controls_note`，不塞进 missing。

### 5.3 `k_reference` 的用途边界

可用于残差图、预测图、模型比较的参照；**不能**自动成为物理机制的首选解释，也不能出现在
「机制结论」类字段里。报告措辞统一为「参考模型」而非「选定机制」。

### 5.4 严格门控与诊断报告分离

| 情形 | 允许输出 | 禁止输出 |
|---|---|---|
| KK `warn` | 探索性拟合、诊断图、`k_reference` | `converged`、机制结论 |
| 采样 grade < 2 | 探索性结果、ESS/R̂ 诊断 | `converged` |
| KK `fail` | 只出 KK 报告 | 任何 K/机制结论 |
