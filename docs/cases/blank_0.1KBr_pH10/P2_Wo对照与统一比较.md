## 0. 对独立分析的核对（两处）

1. **`B_2 = w_2 τ_2^{−φ_2}` 逐位复现**。用本案例包 NPZ 的 3000 个后验样本重算：

   | 模型 | `B_2` 中位数 | 90% 区间 | CV(`B_2`) | CV(`w_2`) | CV(`τ_2`) |
   |---|---|---|---|---|---|
   | K=2 / none | 6.929 | 6.484–7.387 | **4.03%** | 5.32% | 17.05% |
   | K=2 / Ws | 6.765 | 6.135–7.483 | **6.18%** | 19.18% | 39.99% |

   与独立分析给出的 6.93 / [6.48, 7.39] / 4.0%、6.76 / [6.14, 7.48] / 6.2% 完全一致。**并扩展到 Wo**：K=2/Wo 的 `B_2 = 7.291 [6.671, 8.027]`、CV **5.77%**，而 `w_2` CV 8.69%、`τ_2` CV 23.84%（§4）——三种扩散设置下，稳定的都是渐近幅值组合，不是独立的 `w_2`、`τ_2`。

2. **Pareto-k 可以重算，但代码没落盘**。`bm_real.py:555` 的 `loo_pointwise()` 内部算了 `pareto_k` 并用于硬筛选（`Pareto-k>0.7 超 10%`），却只把 `mean(pk>0.7)` 用作判定、没写进 JSON/NPZ。本轮用 `bm_real.loglik_matrix(s, f, Z, include_L=False, n_max=800)` 从 NPZ 样本重算逐点似然，再 `az.loo(pointwise=True)` 取逐点 k，最后 `az.compare` 把 6 个模型放在同一张表上。**自检**：重算的 `elpd_loo_recalc` 与 JSON 的 `elpd_loo_orig` 六组逐位一致（见 `grid_comparison.csv`），说明似然口径与代码完全相同。

   逐点似然定义（全部 6 组一致）：同一频率的实部与虚部是**一个联合观测**，`ll[a,j] = log N(Z'_j | Z'_model, s_re) + log N(Z''_j | Z''_model, s_im)`，等间隔取 800 个后验样本。因此下面的 elpd 比较不是「只凭 RMS 接近」。

**逐项回答你列的三个问题：**

1. **不同扩散模型内部，K=1 与 K=2 谁更好？** 三种设置下都是 K=2 明显更好：`none` 差 187.021（12.45×配对 dse）、`Ws` 差 76.232（5.32×）、`Wo` 差 70.502（5.49×）。扩散项在 K=1 家族能替掉大部分低频残差（`rms_re` 0.650→0.120/0.110），但补不齐 K=2 的改善。
2. **不同扩散模型之间，预测能力是否真的有区别？** 在 K=2 家族**没有**：`Ws−Wo = 0.297`（dse 0.610）、`Ws−none = 0.688`（dse 1.596），**差值都小于各自的 dse**；`rms_re` 0.0831/0.0839/0.0840、acf 0.537/0.537/0.581 几乎相同。stacking weight 集中在 K=2/Ws 只是数值结果，不能读成「Ws 是更好的物理模型」。K=1 家族则差别很大（−119.5 vs −8.0 vs −2.6），说明扩散项与 K 之间存在强替代。
3. **预测能力接近时，物理参数是否存在明显替代？** 是，且幅度很大（§4）。

**Pareto-k 检查结论**：6 组都最多 1 个频点 `k>0.7`（占比 2%），远低于代码硬筛选的 10% 阈值，整体 PSIS-LOO 可用。但需如实标注：K=2/none 在 **91 Hz 处 k=1.071 > 1**，K=2/Ws 0.723、K=2/Wo 0.882 也集中在 91 Hz；K=1/Wo 在 0.1 Hz 处 k=0.900。逐点值在 `pareto_k.csv`。单点不稳不影响整体排序，但不支持把 0.3 量级的 elpd 差当作显著。

**同时必须保留的边界**（呼应你的修正）：K=2 三族的趋势仍在零分布 **99.6–99.7 百分位**、acf 0.537–0.581，残差**仍不符合白噪声假设**。K=2 是「目前测试模型中明显更好的模型」，不是「已通过完整模型适切性检验」。

## 3. Wo 对照结果（本轮重点）

### 3.1 K=2 / Wo

- `elpd=67.892`、`rms 0.0839/0.1462 Ω`、acf 0.537、趋势 0.71/1.14σ、PPC 0.960/0.920 —— 与 K=2/none、K=2/Ws 几乎相同。
- `P(峰位出窗)=0.290`（介于 none 的 0.892 与 Ws 的 0.049 之间），慢分量 `f0=0.115 Hz`、`w_2=8.67 Ω`、`φ_2=0.513`。
- 扩散参数：`R_W = 0.0645 Ω [0.0064, 0.783]`（跨 2 个量级）、`τ_D = 0.386 s`、`f_D = 0.413 Hz`、等效 `A_W = 0.107`、`C_D = 5.98 F`；`corr(ln R_W, ln τ_D) = +0.907`，`C_D = τ_D/R_W` 本身 ±84.9%，垂直于该组合仍有 **±613%** 的脊线；`P(Rwo < 1e-3·zmax) = 0.464`。**扩散参数本身高度简并**。

### 3.2 Ws / Wo 可分辨性：同一个 Wo 模型，K 不同结论翻转

| 模型 | `f_D` | 与窗口关系 | 带内最大形状差异 | 代码判定 |
|---|---|---|---|---|
| K=1 / Wo | 0.0182 Hz | 窗口下界 0.1 Hz **之下 0.7 dec**，拐点没进窗口 | 13.5%（集中在窗口边缘） | **不可分**（保守） |
| K=2 / Wo | 0.413 Hz | **落在窗口内** | 99.0% > 2% | **可分**，elpd 比较有意义 |

这是一个需要单独记下的现象：**Ws/Wo 的有限频段可分辨性判断与 K 耦合**——K=1 时扩散项独自承担低频尾，`τ_D` 被推到窗口外；K=2 时慢 HN 分量分担了低频尾，`τ_D` 回到窗口内。因此不能把「可分辨」当成数据里存在有限长扩散的证据；代码日志本身也写了「可分辨 ≠ 数据里真有有限长扩散」。K=1/Wo 那组还明确打印了「不要用 elpd 差宣称存在有限长扩散」。

K=1/Wo 的扩散参数：`R_W = 14.07 Ω [12.89, 15.53]`、`τ_D = 8.747 s`、`corr(ln R_W, ln τ_D)=+0.755`、等效 `A_W = 4.756`、`P(Rwo<1e-3·zmax)=0.000`。

## 4. 模型替代的定量证据

| 量 | K=2 / none | K=2 / Ws | K=2 / Wo |
|---|---|---|---|
| `A_W`（或等效 `R_W/√τ_D`） | — | 1.020 | 0.107 |
| `A_W`（K=1 对应组） | — | **4.584** | **4.756**（等效） |
| `w_2` Ω | 9.772 | 6.125 | 8.666 |
| `τ_2` s | 1.951 | 0.829 | 1.389 |
| `f0_2` Hz | 0.0816 | 0.1919 | 0.1146 |
| `P(峰出窗)` | 0.892 | 0.049 | 0.290 |
| `B_2` 中位数 / CV | 6.929 / **4.03%** | 6.765 / **6.18%** | 7.291 / **5.77%** |
| CV(`w_2`) / CV(`τ_2`) | 5.32% / 17.05% | 19.18% / 39.99% | 8.69% / 23.84% |

- 扩散幅值在 K=1 与 K=2 之间差 **4.5 倍（Ws）/ 44 倍（等效 A_W，Wo）**，`τ_D` 差一个量级；`w_2`、`τ_2`、峰位、出窗概率都被重新分配。
- 但 `B_2` 在三种设置下都稳定在 6.8–7.3、CV ≤6.2%，明显优于独立的 `w_2` / `τ_2`。**稳定的是窗口内的渐近阻抗贡献，不是独立的时间常数或电阻**——这正是你判断的推广。
- `P(峰出窗)` 从 0.892 降到 0.049/0.290 只是**分配方式改变**，拟合指标没有实质改善；不能据此说 Ws/Wo 比 none 更接近真实物理过程。

### 总阻抗预测层面的对照（不是只看 RMS）

`predictive_comparison.csv` 给出 50 个频点上 6 个模型的总阻抗预测（后验中位数）与两两相对差：

| 对照 | `|ΔZ|/|Z|` 平均 | 最大 | 0.1 Hz 处 |
|---|---|---|---|
| K=1 vs K=2（none） | 2.11% | 5.05% | 5.05% |
| K=1 vs K=2（Ws） | 0.58% | 3.11% | 3.11% |
| K=1 vs K=2（Wo） | 0.55% | 3.18% | 3.18% |
| **K=2 家族内部（none/Ws/Wo）** | **0.105%** | **0.510%** | 0.510% |

即：尽管物理参数差几十倍，**K=2 三个模型的总阻抗预测几乎逐位相同（最大相对差 0.51%）**。这是「预测能力接近 ≠ 参数可辨识 ≠ 物理机制确定」最直接的定量依据。

按你的意见，`C_k(f)=|Z_k(f)|/|Z_model(f)|` **只报告、不作硬筛选**（不同分量复数相加会相消）。`component_contribution_grid.csv` 给出 6 组 × 每个分量 × 50 频点的：复阻抗贡献 `Z_k` 的实部 / 虚部 / 模及各自 90% 后验区间、`C_k` 中位数、以及模型总 `Z` 的实部 / 虚部中位数。`predictive_comparison.csv` 给出不同模型下总阻抗预测的差异。二者合起来可同时看到「分量贡献随频率变化的后验区间」与「总预测是否稳定」，避免把「参数分量不稳定」误读成「模型预测不稳定」。

## 6. 结论边界与下一步

**当前最稳妥的结论**（与你的独立分析一致，且经 6 格网格强化）：

> 在 0.1–10⁴ Hz 窗口内，K=2 的慢分量对阻抗响应具有显著解释贡献；它的特征峰位部分落在窗口外，与半无限及有限长扩散项存在明显替代关系。现有数据支持**慢频阻抗贡献**的存在，却不足以唯一确定其物理来源。

补充两条本轮新证据：`none/Ws/Wo` 在 K=2 下预测能力统计上不可分（`elpd_diff < dse`、总阻抗预测最大差 0.51%）；Ws/Wo 的可分辨性判断还随 K 翻转。因此**没有证据把慢贡献唯一归属为 HN 慢弛豫或扩散**。
