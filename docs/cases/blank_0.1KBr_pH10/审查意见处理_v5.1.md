## 1. P0：K 选择配对证据整体校验（已修）

审查员复现的问题成立：`thr=NaN` 时 `delta <= thr` 返回 False，程序错误输出 `converged`；
缺 `thr` 抛 `KeyError`；`comparison_type="mechanism"` 仍能通过。

新增纯函数 **`validate_pair_record(rec, key)`**，任一不满足即 `K_SELECTION_AMBIGUOUS`：

| 检查 | 要求 |
|---|---|
| 必需字段 | `delta / dse / thr / comparison_type / n_observations / K_a / K_b` 全部存在（缺字段不抛异常） |
| 数值 | `delta / dse / thr` 均为有限值（含 `thr=NaN` 拦截） |
| 尺度 | `dse > 0`、`thr >= 0` |
| 类型 | `comparison_type == "K_selection"` |
| 样本数 | `n_observations` 为有效正整数 |
| 方向 | `K_a == best`、`K_b == lower_star`（与 `model_a/model_b` 一致） |

`decide()` 改为先整体校验，再比较 `delta` 与 `thr`；不再直接读 `rec["thr"]`。

## 2. P1：反向配对符号（已修）

新增 **`normalize_pair(pairwise_comparisons, key)`**：只有反向记录 `(1,2)` 时，
同步反转 `delta` 符号、`direction`（A>B↔B>A）以及 `K_a/K_b`、`model_a/model_b`；
`dse / thr / n_observations` 对方向对称，保持不变。
审查员的例子 `(1,2), Δ=-10` → 规范化为 `(2,1), Δ=+10`，不再用 −10 判定。

---

## 3. P1：机制二元组方向歧义（已修）

`decide_mechanism()` 保留二元组兼容，但**按 Δ 符号自动推导方向**（`A>B` / `B>A`），
不再让 `"unknown"` 参与显著偏好判断：

- `[(2,1),(3,1)]` → 推导 A>B, A>B → `evidence_for_model_preference`（有明确方向）；
- `[(2,1),(-3,1)]` → `preference_conflict`；
- 显式 `direction="unknown"` 也按 Δ 推导；
- 若显著比较仍出现 `unknown`（例如 Δ=0 且无方向）→ `comparison_incomplete`。

## 5. 用例 2 正向：状态机层通过，真实谱层仍未成立

### 5.1 状态机层（已完成，4 项测试 PASS）

构造**两个候选都满足采样要求、KK=ok、Δ < 2×dse** 的合法输入：

| 测试 | 期望 | 实际 |
|---|---|---|
| 两候选合格 + Δ<2dse | `K_SELECTION_AMBIGUOUS` | ✅ |
| 未走「候选集合不完整」分支 | True | ✅ |
| `k_reference` 仍指向 LOO 最优 | K=2 | ✅ |
| 反向对照：Δ 显著 | `converged` | ✅ |

这验证了 `K_SELECTION_AMBIGUOUS` 的**正向触发**确实来自「Δ 不显著」，
而不是像用例 2a 那样来自「K=2 采样失败 / 候选不完整」。

### 5.2 真实谱层（仍未成立，附新证据）

`case2_positive_real.py`：用 `bm_core.fit(..., sigma=(s,s))` **固定噪声**
（仅在测试设置里消除 σ→0 漏斗，未改算法代码 / 先验 / 阈值），
对 4 组近简并双峰谱（第二峰 100/300/500/700 Hz，幅度 5/8/10/4 Ω）跑 K=1、K=2 各 3 链 NUTS：

| f0₂ / w₂ | K=1 | K=2 | Δ / dse / thr | KK | 状态机 |
|---|---|---|---|---|---|
| 100 Hz / 5 Ω | grade 2 (R̂1.002, ESS1026) | grade 0 (R̂1.047, ESS88, div57) | 0.670 / 0.445 / 2.0 | ok | ambiguous |
| 300 Hz / 8 Ω | grade 2 | grade 0 (R̂1.666, ESS4.9, div37) | −0.077 / 0.230 / 2.0 | ok | ambiguous |
| 500 Hz / 10 Ω | grade 2 | grade 0 (R̂1.094, ESS22.5, div53) | −0.275 / 0.218 / 2.0 | ok | ambiguous |
| 700 Hz / 4 Ω | grade 2 | grade 0 (R̂1.675, ESS4.8, div42) | −0.311 / 0.221 / 2.0 | ok | ambiguous |

**结论**：Δ 全部不显著、KK 全 ok、状态机全部正确返回 `K_SELECTION_AMBIGUOUS`，
但 K=2 始终采样退化，**正向用例仍未成立**。新证据是：固定噪声后依然退化，
说明问题不只是 σ 塌陷，而是近简并时第二个 HN 分量缺乏独立约束导致的后验几何病态
（标签交换 / 幅度–时间常数简并）。这与之前 6 组构造的结论一致且更强。

**边界声明**：固定 σ 改变了似然的噪声处理方式，elpd 绝对值与默认路径不可比；
该设置只用于验证状态机行为，不用于真实案例的 K 结论。按审查员要求单独报告。
未降低 grade 门槛，未把候选不完整分支冒充 Δ 不显著分支。

## 6. 四层结论（不变）

| 层级 | 判定 | 证据强度 |
|---|---|---|
| K 选择 | `converged`（K=2） | 较强，去高 Pareto-k 点后仍成立 |
| 机制可辨识性 | `ambiguous` | 探索性，高 k 敏感，待 91.03 Hz 精确 LOO |
| 扩散参数 | `shape_resolvable_params_degenerate` | 形状可分但参数简并 |
| 参考频率阻抗贡献 | `reference_frequency_dependent` | 两参考频率精确 HN 幅值不一致 |

保留审查员的关键表述：**K=2 是稳健的预测复杂度选择，不等于第二个分量的物理来源已确定**。
