## 0. 定位与工作假设

这次暴露的不是拟合能力不足，而是 **`select_k()` 的 `P(峰位出窗)>0.5` 硬筛选规则与「测量窗口之外的慢过程」发生冲突**：LOO 显著更优的 K=2 被剔除，退回 K=1 后留下系统性残差。

- 原始运行：**full 档**（3000/1000/3 链，div 0、R̂≈1.00、ESS 837–1526、分级 2），**Lin-KK 门禁通过**（μ=0.80、M=20、残差 0.35%/0.31%/0.17%）→ 不是采样预算、不是数据质量、不是 quick 档的问题。
- 三种待区分的解释：① 真实慢弛豫（峰略超出窗口）；② 扩散渐近响应（窗口内近似半无限 Warburg）；③ **两者不可区分**（窗口只能识别阻抗贡献，不能唯一确定物理来源）。
- **本案例采用 ③ 作为工作假设**，不替第二个分量赋予物理名称。特别注意：`φ≈0.508` 支持其具有接近半无限 Warburg 的渐近特征，但 **φ 的先验下界本来就是 0.5**（§3.2），因此不能单凭这个数值认定它就是扩散过程。

### 3.2 第二个分量的 `φ` / `ζ` / `φζ`

- `ζ` **被 `zeta_fixed=1.0` 钉死**，后验恒为 1（sd=0），因此 `φζ ≡ φ`，不是两个独立自由度。
- `φ ~ Uniform(0.5, 1.0)`，**0.5 是硬先验下界**。`K2_none` 慢分量 `φ` 的 `q05=0.5007`、`K2_Ws` 的 `q05=0.5017` —— 两者都**紧贴下界**，说明数据在把 φ 往下推但被先验截断。
- 因此「`φ≈0.508` 接近半无限 Warburg 的 0.5」这一观察**部分是参数化边界造成的**，不能单独作为「它就是扩散过程」的独立证据。这与审查意见「不能单凭这个数值认定它就是扩散过程」一致，且给出了更具体的理由。
- 两组 `φ` 都不跨越 0.5；`K2_Ws` 的区间更宽（0.5017–0.5686），慢分量形状在加扩散后**更不确定**。

> **更正上一轮的一处说法**：此前把 `Rw=0.0724 Ω` 当成 Ws 元件的幅值，据此说「Ws 几乎不起作用」，这是错的。`Rw` 只是采样参数，实际幅值由 `Aw = Rw·√ω_ref ≈ 1.02 Ω·s^(-1/2)` 给出（`ω_ref=2π√(f_min f_max)`），`Z_Ws = Aw/√(j·2πf)`：在 0.1 Hz 处为 `Re +0.910 / Im −0.910 Ω`（|Z|≈1.29 Ω），与慢 HN 分量同量级；`Aw` 后验 90% 区间 [0.359, 1.581] 也很宽。
> 加 Ws 后慢 HN 分量 `w` 9.77→6.12 Ω、`f0` 0.082→0.192 Hz，说明 **Ws 与慢 HN 分量在低频互相替代**，所以拟合指标几乎不变。`p_diff_small = 0.302`（`P(Rw < 1e-3·zmax)`），同样不能据此宣称"没有扩散"。

## 4. `out/_diag_*` 三组对照的诊断结果

### 4.1 `K1_cut1Hz`（低频截断 ≥1 Hz，40 点）

### 4.2 `K2_none`（`--krange 2,2`，强制 K=2，不加扩散）

- `rms 0.0840/0.1494 Ω`、acf 0.581、趋势 1.20σ（第 99.7 百分位）、PPC 0.920/0.940 —— 与 `K2_Ws` **几乎逐位一致**。
- 快分量 `f0=354.5 Hz, w=34.37 Ω, φ=0.689`；慢分量 `f0=0.0816 Hz, w=9.77 Ω, φ=0.508`。
- → **K=2 本身就是好模型**，被 `P(峰位出窗)>0.5` 误杀；不需要扩散项就能解释绝大部分残差。

### 4.3 `K2_Ws`（`--krange 1,2 --diffusion Ws`）

- K=1 的 `P_out=0`；K=2 的 `P_out,max` 从 0.892 降到 **0.049**，硬筛选**不再剔除** → 正常选到 **K=2**（`converged`）。
- K=2 的 `rms 0.0831/0.1466 Ω`、acf 0.537、趋势 1.14σ（第 99.6 百分位）、PPC 0.940/0.940。
- `diffusion_resolution` 报 `level=unknown`：「拿不到 τ_D 后验（模型里没有 tauD），无法判断 Ws/Wo 是否可分；不要用 elpd 差宣称有限长扩散」—— 这正是 P2 要做 `none/Ws/Wo` 对照的原因。
- → **Ws 的作用是让第二个分量回到窗内、绕过硬筛选**，而不是给出更好的拟合；拟合优度相对 `K2_none` 无实质增益。

## 5. 留给独立分析的问题（本案例不下结论）

1. 慢分量的 `φ` 紧贴先验下界 0.5 —— 这是"扩散渐近"的证据，还是参数化边界的伪影？
2. `ln w_2 ~ ln τ_2` ≈ +0.94/+0.95：慢分量能否算"可辨识"？还是只能报 `w_2·τ_2^{-1/2}` 一类的组合？
3. `K2_none` 的 `f0` 90% 区间跨过 `f_min`，中位数仅低 18%：这算"峰不可辨"还是"峰基本可定位、只是略出窗"？
4. Ws 与慢 HN 分量在低频互相替代（w 9.77→6.12、f0 0.082→0.192，`Aw` 区间宽）：是否支持"阻抗贡献可识别、物理来源不可识别"？
5. `R_inf↔w_1` 减弱但未消失、简并转移到 `w_1↔φ_1`：K=2 的参数报告应该怎么写才不误导？

**最终科学问题（原文）**：当真实 EIS 数据存在测量窗口之外的慢过程时，BM-DRT 能否区分**可识别的阻抗贡献**与**不可识别的物理弛豫峰**？这比简单调整 `p_peak_out` 阈值更重要。

## 8. P2 补充（2026-11-05 23:00 后）

独立分析已核对：从 NPZ 重算的 `B_2 = w_2 τ_2^{−φ_2}` 与给出的数值逐位一致（6.929 / 6.765、CV 4.03% / 6.18%），并扩展到 Wo（7.291、CV 5.77%）。按「三个模型家族具有相同比较结构」补齐了 2×3 网格（6 格，全部 `--krange K,K` 强制单 K、同输入/先验/seed/full 预算/同逐点似然）。

要点（详见 `P2_Wo对照与统一比较.md`）：

- K=2 家族内 `none / Ws / Wo` 的 `elpd_diff = 0.688 / 0.297`，**均小于各自 `dse`（1.596 / 0.610）**，总阻抗预测最大相对差仅 0.51% → 预测能力统计上不可分。
- 但物理参数大幅替代：`A_W` 4.584(K=1/Ws) → 1.020(K=2/Ws)、`R_W` 14.07 → 0.0645 Ω、`τ_D` 8.75 → 0.386 s；`P(峰出窗)` 0.892 / 0.049 / 0.290。
- Ws/Wo 可分性判断**随 K 翻转**：K=1/Wo 判「不可分」（`f_D=0.0182 Hz` 在窗口下），K=2/Wo 判「可分」（`f_D=0.413 Hz` 在窗口内），且 K=2/Wo 的扩散参数自身高度简并（`corr=+0.907`、垂直脊线 ±613%）。
- Pareto-k：6 组各最多 1 个频点 >0.7（2%，低于硬筛选 10%）；K=2/none 在 91 Hz 达 1.071，需标注但不改变整体排序。
- K=2 三族趋势仍在零分布 99.6–99.7 百分位、acf 0.537–0.581 → **K=2 是「目前测试模型中明显更好」，不是「已通过完整模型适切性检验」**。

**结论边界不变**：数据支持窗口内慢频阻抗贡献的存在，不足以唯一确定其物理来源。`K_SELECTION_AMBIGUOUS` 与 `select_k()` 修改**仍未实施**；HEAD 保持 `f745205`、工作区干净、未提交。
