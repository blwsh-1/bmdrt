## 1. P0-1：状态机机制判定（已修，纯函数）

新增 **`decide_mechanism(mech_diffs, controls_missing, controls_complete)`**，严格顺序：

```
if not mech_diffs                              -> not_tested
if any(Δ/dse 非有限 or dse<=0)                 -> comparison_incomplete
if controls_missing or not controls_complete   -> not_tested
显著比较 = [Δ for |Δ|>=dse]
    空           -> ambiguous
    方向集合>1    -> preference_conflict
    否则          -> evidence_for_model_preference
```

兼容 `(delta, dse, direction)` 三元组与旧 `(delta, dse)` 二元组；缺失优先于显著性判定，
即使同时 `controls_complete=False` 也先返回 `comparison_incomplete`。
`decide()` 不再保留旧的 `if/elif mech_diffs` 逻辑，统一调用该纯函数。

## 2. P0-2：逐 control 门控 fail-open（已修）

审查员指出的三处都成立：`None` 被 `all()` 跳过、`tree_cap or 0` 把缺失当通过、
`from_grid_log()` 依赖硬编码绝对路径。修复：

- `gate_of(js, row)` 改为 **fail-closed**：所有必要诊断
  （`kk.status` / `sample_grade` / `divergences` / `tree_cap` / `rhat_max` / `ess_bulk+ess_tail`）
  逐一经 `need()` 检查，缺失或非有限 → 记入 `missing_diagnostics` → `effective=False`。
  不再用 `isinstance(v, bool)` 过滤掉 `None`，也不再把缺字段默认成 0。
- 新增 **`control_diagnostics.csv`**（六组 R̂ / bulk / tail / div / tree_cap / grade / kk 的导出摘要，
  随包发布）。`replay_identifiability.py` 只依赖包内 CSV 与 `real_*.json`，
  **完全删除仓库绝对路径与 run.log 依赖**；`export_control_diagnostics.py` 只用于生成该 CSV，
  仓库路径由命令行显式传入，回放时不需要。
- `controls_complete` 现在 = 无 missing + 六组全 effective + `kk_all_ok`。
- **独立环境验证**：在不含仓库目录、不含 NPZ 的临时目录（49 个文件，仅 v5 包内容）中，
  `replay_identifiability.py` 成功输出六组门控，`test_state_machine.py` 通过 23/23。

`cd_relative_width()` 在缺 NPZ 时返回 `None`（不伪造通过），扩散参数简并仍由

## 3. P1：多 K 配对接口（已修）

`decide()` 参数由单一标量 `pair_dse` 改为 **`pairwise_comparisons[(K_best, K_lower*)]` 映射**：

- 确定 `best` 与 `lower_star` 后，按模型对读取该配对的 `delta / dse / thr /
  n_observations / comparison_type`，**直接使用配对记录的 Δ**，不再用两个汇总 ELPD 相减；
- 缺该配对记录 → `K_SELECTION_AMBIGUOUS`（不输出 `converged`）；
- `make_ref()` 增加 `role="prediction_reference_only"`，与 `replay_identifiability.py` 一致。

边界测试含 K=1,2,3 场景：验证取 `(3,2)` 配对而非 `(3,1)`，且 `k_reference` 指向 K=3。

## 4. Pareto-k 缺失值 fail-closed（已修）

`pareto_k_sensitivity.py` 不再用 `fillna(False)` 把缺失 Pareto-k 当低风险：
任一频点的 `pk` 缺失/非有限 → `sensitivity_incomplete=True`、
`verdict_kept="sensitivity_incomplete"`，并记录 `missing_pk_points`。

**机制层措辞按审查员原文定稿**，并写入 `replay_identifiability.csv`：

> 在完整频段的 PSIS-LOO 比较中，Ws、Wo 和 none 的预测差异均未超过配对 dse，暂时无法区分
> 其预测表现。对高 Pareto-k 频点进行删除敏感性分析后，Ws−Wo 比较发生判定翻转，说明机制层
> 结论对单个频点敏感。因此当前 `ambiguous` 属探索性判断，尚不能作为严格的机制不可区分结论。

新增字段 `mechanism_pareto_k_sensitive=true`、`mechanism_evidence_level="exploratory"`。
明确这是「删除高 k 点」复核，不是精确 LOO；下一步是 91.03 Hz 的 moment matching / 精确 LOO，
不是继续删点。K 选择侧三族去点后仍显著，强结论保留。

## 6. 本案例四层定稿（与审查员 §5 一致）

| 层级 | 最终工作判定 | 证据强度 |
|---|---|---|
| K 选择 | `converged`（K=2） | 较强：三家族均成立，去高 k 点后仍成立 |
| 机制可辨识性 | `ambiguous` | **探索性**：高 k 敏感，待精确 LOO |
| 扩散参数 | `shape_resolvable_params_degenerate` | 形状可分但参数简并 |
| 参考频率阻抗贡献 | `reference_frequency_dependent` | 两参考频率精确 HN 幅值结果不一致 |

保留审查员的关键表述：**K=2 是当前最合适的预测复杂度，但不等于第二个分量的物理来源已确定**。
