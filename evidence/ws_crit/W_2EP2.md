# 2EP-2_exp2_0500mA：加一个 W 值不值？

**结论：不加。** K=1 none 保持原样。加 Ws/Wo 带来的 elpd 增益全部落在配对噪声里，
10 组配对 **无一过线**；数据侧低频根本没有 45° 尾，图上也分不出来。
这不是"证明没有扩散"，而是**本频窗没有可辨识的扩散项**——按 A/B/C 记账属 **B 档
（数据无法判断）**，不是 C 档，更不是"无扩散"的物理结论。

> 性质：**单谱探索性诊断**。WP2 预注册只覆盖 `example_caseE` 与 `Blank_...` 两条谱，
> 本谱不在其中，这里的 `max(2, 1.5·dse)` 只借作量级尺子，**不是预注册判读**。
> **2E 七组 127 条冻结不变**：不追加 seed、不批量重跑、不改判据；本次结果不进
> 任何汇总表、不进 G8b、不算 TP/FP（`independence_status` 全为 `inferred`）。

## 3. 三条独立反证

**① 数据侧：低频不是 45° 尾。** 现有 KK `attribution` 原文：低频端 Nyquist 斜率
`−0.00`、`|Z|` 斜率 `−0.02` → **未达 45°，不判为扩散尾**；归因为窗口外端部效应。
实测 1–10 Hz 的 −Im 在 `0.0004…0.0071 Ω` 之间无单调趋势，3.55 Hz 甚至是
`−0.0022 Ω`（容性符号反过来）；而 Ws 要求 −Im 单调按 `f^(−1/2)` 上升。
Ws/Wo 的曲线只是穿过噪声云的中位，不是抓到了 `ω^(−1/2)` 规律。

**② 幅值与图分辨力都在噪声量级。** `Rw = 3.16e-4 Ω`（定义在窗口几何中心 316 Hz），
仅 `zmax=0.068 Ω` 的 0.46%；换算到 `f_min=1 Hz` 时 `|Z_Ws| = 0.0056 Ω`。
**噪声口径要分开**：本节曲线两两差用合成噪声
`σ = √(σ_re²+σ_im²) = 0.00371 Ω`；低频虚部残差用 `σ_im = 0.00274 Ω`。
按各自口径，`|Z_Ws(f_min)| = 1.5σ`，其虚部分量
`0.0056/√2 ≈ 0.0040 Ω = 1.5σ_im`——都只有噪声量级。后验 `cv(Rw)=0.26`
看着不塌，但那是被先验托住的小幅值，不是被数据定住的幅值。两两曲线最大差：

| 对比 | max\|ΔZ\|/σ（全窗 = 低频） | 低频落在 1σ 内 |
|---|---|---|
| k1_none vs k1_Ws | 1.14 | 83% |
| k1_none vs k1_Wo | 1.11 | 92% |
| k1_Ws vs k1_Wo | 0.63 | 100% |

四联图（Nyquist 全窗 / 低频放大 / 低频 −Im / 低频残差）见 `out/_w_2ep2/separability.png`。加 W 之后低频残差在 2.34 Hz 从
`+0.9σ` 变成 `−1.6σ`——**误差只是换了个位置，没消掉结构**。

**③ 加 W 是在跟 RC 抢同一段谱。** 同一个 K=1 弧：`f0` 787→905 Hz、
`φ` 0.821→0.899、`w` 0.0215→0.0195 Ω。加 W 改变的是对主弧的解释，
不是新识别出一个独立物理过程。K=2 两臂更说明问题：`k2_none` 的第二分量
`f0=0.3 Hz` **在窗外**（`f_min=1 Hz`）、`w=0.018 Ω`，与 KK 说的「低频端部效应」
是同一笔账；`k2_Ws` 的两个峰挤在 1005/648 Hz，属于简并，且 grade=0。

**Wo 单说一句**：`f_D=12.7 Hz` 落在窗内，`max_reldiff=0.999` → Ws/Wo 形状上
**可分**；但 `Rwo` 的 `cv=6.22`、q05/q95 跨 130 倍，幅值完全没定住。
按项目既有口径：**可分辨 ≠ 数据里真有有限长扩散**，更不能拿 elpd 差宣称 Wo。

## 4. 记什么、不记什么

- 记：`本频窗内加 Ws/Wo 与本模型不可区分（配对 LOO 未过线）；低频端部残差
  7.1% 归因为窗外效应`。档位 **B**：程序不单选，多模型并列交人挑。
- 不记：`没有扩散`、`无 Ws`（数据证不了）；`A_W=0.0141` 当结构证据；
  把这 5.8 分写成「Ws 更优」；把这批 2E 谱拿去估假阳性率。
- 还缺什么（`next_evidence_needed`）：① 频窗下延到 `<0.1 Hz`，让 `f_D` 与
  45° 段真正进窗；② 同一条件的独立重复谱（本组 `independence_status` 全
  `inferred`）；③ 低频端噪声的仪器标定，才能判断 `1.5σ_im` 是不是信号。

## 5. 顺带修掉的一个生产 bug（`bm_evidence.py`）

用 `--multi-model` 把这五臂过一遍证据卡生成器时，`k1_Wo` 被标成
「`f_D=12.7 Hz 在窗下（f_min=1）`」——**判反了**：12.7 Hz 明明在窗内。
根因是 `bm_diff.diffusion_resolution.below_fD` 的定义为
`bool(f.min() < f_D)`，True 表示「窗口里有点低于 f_D（转折可能进窗）」，
而生成器把它读成了「f_D 在窗口下界之下」。同一误读还让
`next_evidence_needed` 无条件建议「下移 f_min」。

修法：证据卡里不再用这个含混布尔，改为直接比较 `f_D` 与 `f_min/f_max`，
输出 `window_position = in_window | below_fmin | above_fmax`；出窗时按需给
「下移 f_min / 上移 f_max」；多模型表只在**真出窗**时打标记，窗内不打。
`freq_window` 台账的 `reads` / `need` 同步改准。

回归：`bm_evidence.py --selfcheck` **97/97**、
`evidence_card_check.py` **2889/2889**（合成 30 + 真实 3）、
`EVIDENCE_CARDS.md` 已用 `make_cards.py` 重生成。只动生成器，不动任何判据。
