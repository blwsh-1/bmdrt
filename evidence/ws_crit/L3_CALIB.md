# L3 简约闸门标定（2026-11-09）

**结论先行**：闸门改用 **`cv(A_W) = sd(A_W)/median(A_W) ≤ 0.15`**（后验相对不确定度），
**不再用份额**。已接入 `select_mechanism` 作为 guard `ws_amp_unidentified`。

份额口径被否证：真 `Ws`（`A_W=0.5`、0.01 Hz 窗）份额只有 **0.048**，
5% 阈值会把它误杀；而且它随窗口下限漂移（`A_W=2`：0.160 → 0.057）。

---

## 1. 为什么要重做

`bm_ws.ws_share_low` 的分母是 `Re Z_Ws(f_min) + R_p`，而 `Re Z_Ws ∝ f_min^(-1/2)`。
`L123_REPORT.md` §4 已实测：同一条真值 `A_W=2` 的谱，0.01 Hz 窗给 0.161、
0.1 Hz 窗给 0.057 —— **距 5% 阈值只剩 0.7 个百分点**，窄窗必误杀。
当时只能"只报不判"，闸门空着。

## 2. 标定设计

合成谱固定 `R∞=10 Ω`、`ZARC(R_p=30 Ω, f0=300 Hz, n=0.85)`、1% 相对噪声
（`σ = 0.01·|Z|`，与 `WS_DECISION_PROJECT.md` §3.1 的曲面同口径），51 个频点。

| 类 | 真值 | 期望 |
|---|---|---|
| `ws` | `R∞+ZARC+Ws(A_W)`，`A_W ∈ {0.5, 1, 2, 4}` | **应当**切 |
| `wo` | `R∞+ZARC+Wo(R_W=60, f_D=0.03)`（转折在窗内） | 不该切（错元件） |
| `wo_below` | 同上但 `f_D=1e-4`（转折在窗下） | 不该切（与 Ws 同形） |
| `hn` | `R∞+ZARC+ZARC(93.28, 1e-4, 0.518)`（K+1 宽弧） | 不该切（与 Ws 同形） |
| `none` | `R∞+ZARC`（无扩散，硬加 Ws） | **必须**拒 |

窗口下沿扫 `{0.01, 0.03, 0.1, 0.3} Hz`，上沿固定 `1e3 Hz`。
每条用 `--diffusion Ws --krange 1,1 --quick --kk off` 拟合，从后验样本算三个候选量：

    A share_low = Re Z_Ws(f_min) / (Re Z_Ws(f_min) + Σw)     [旧口径]
    B snr_ws    = Re Z_Ws(f_min) / σ_im                      [§3.1 同源]
    C cv_aw     = sd(A_W) / median(A_W)                      [后验可辨识性]

共 **32 条**（`ws` 4 幅度 × 4 窗 = 16，其余 4 类 × 4 窗 = 16），
`l3_calib.json`。

## 3. 结果

### 3.1 三个口径的跨窗口行为

| 类 | `cv(A_W)` 0.01→0.3 Hz | `share` 0.01→0.3 Hz | `snr` 0.01→0.3 Hz |
|---|---|---|---|
| `ws` A=0.5 | 0.080 → 0.449 | 0.048 → 0.010 | 4.9 → 0.9 |
| `ws` A=1 | 0.041 → 0.274 | 0.088 → 0.018 | 9.6 → 1.6 |
| `ws` A=2 | 0.022 → 0.152 | 0.160 → 0.033 | 18.4 → 3.2 |
| `ws` A=4 | 0.011 → 0.069 | 0.274 → 0.064 | 35.6 → 6.3 |
| `wo`（窗内） | 0.137 → 0.012 | 0.303 → 0.307 | 0.5 → 36.9 |
| `wo_below` | 0.028 → 0.182 | 0.126 → 0.026 | 14.0 → 2.4 |
| `hn` | 0.021 → 0.147 | 0.161 → 0.033 | 18.6 → 3.2 |
| `none` | **0.540 → 0.729** | **0.005 → 0.004** | 0.53 → 0.39 |

**`cv` 与 `snr` 严格反比**：32 条全部命中 `cv ≈ 0.40 / snr`（范围 0.39–0.41）。
两者是同一信息的两种写法，不是独立的判据。选 `cv` 的理由：

- 它是**后验量**，不需要假设噪声模型。生产里 `bm_real` 的噪声是**同方差**
  （`obs_im ~ Normal(Zt.imag, s_im)`，`s_im` 全局标量），而数据是按 `σ_rel·|Z|`
  生成的；`snr` 用 `s_im` 算，在这个口径差下含义会漂，`cv` 不受影响。
- 它直接回答"这个幅值能不能说清"，与 `p_diff_small`（比的是相对 `|Z|max` 的大小）
  覆盖不同侧面。

`share` 的漂移（同一真值 4.3–5.0×）与 `cv` 的漂移（5.6–7.1×）幅度相近，
但**方向相反且含义不同**：`share` 变小是"背景相对变大"（窗口变窄，`f_min` 抬高，
`Re Z_Ws` 变小而 `R_p` 不变），与"能不能定住"无关；`cv` 变大**正是**信息变少的
正确反映。

### 3.2 同窗口取值区间

`cv`（闸门线 0.15）：

| `f_min` | 真 Ws（4 个幅度） | `hn` | `wo` | `wo_below` | `none` |
|---|---|---|---|---|---|
| 0.01 | 0.011–0.080 | 0.021 | 0.137 | 0.028 | **0.540** |
| 0.03 | 0.021–0.166 | 0.040 | 0.038 | 0.057 | **0.678** |
| 0.1 | 0.040–0.290 | 0.076 | 0.010 | 0.108 | **0.639** |
| 0.3 | 0.069–0.449 | 0.147 | 0.012 | 0.182 | **0.729** |

`hn` / `wo_below` 与真 Ws 同区间是**已知不可分**（`Ws ≡ 窗外 R||CPE(0.5)`，
`WS_CRITERION_PLAN.md` §5.3），不是闸门失效——它们由 `Δ` 与
`diffusion_resolution.resolvable` 管。

`wo`（转折在窗内）的 `cv` 低到 0.010——**`cv` 不能判"元件选错"**：参数被
"很确定地"定在错误的值上（`A_W` 拟合成 24–28，而真值是 Wo）。这是本标定
最重要的边界。

## 4. 阈值 0.15 的依据

| 取值 | 含义 | 判定 |
|---|---|---|
| ≤ 0.08 | `snr ≥ 5`，`A_W` 偏差 < 4% | 切 |
| 0.10–0.15 | `snr ≈ 3`，`A_W` 偏差 5–8% | 切（勉强） |
| 0.15–0.30 | `snr ≈ 1.4–2.7`，`A_W` 偏差 7–16%（如 0.538 对真值 0.5） | **拒** |
| > 0.5 | `snr < 1`，`A_W` 与噪声同量级 | 拒 |

0.15 对应 `SNR_ws ≈ 2.7`，即"`A_W` 的相对不确定度不超过 15%"。
`none` 的最近值是 0.540，与阈值有 3.6× 空档，不存在"正好压线"的情况。

代价是**保守**：真 `Ws` 在信息不足时也会被拒（`ws_a0.5_f0.3`：真 `A_W=0.5`，
拟合 0.562 ± 0.25，`cv=0.449` → 拒）。这是设计选择：`A_W` 的相对误差 45%
时，宣称"存在扩散"没有意义，输出 `uncertain` 比给一个虚数好。

## 6. 边界（写死）

1. **`cv` 只挡"定不住"，不挡"选错"**：真 `Wo` 用 `Ws` 拟合 `cv=0.010–0.038`。
   错元件归 `Δ` 与 `diffusion_resolution.resolvable`。
2. **真 `Ws` 在信息不足时会被拒**（`cv > 0.15`），这是保守设计，不是漏判；
   这种情况下应报 `uncertain`，不得报"无扩散"。
3. **阈值不随窗口调整**：`cv` 的窗口依赖是**正确行为**（窗口窄 → 信息少 →
   不该切），不是需要归一化的伪影。这一点与 `share` 相反。
4. **不参与真假阳性统计**、不改 `G8b=pending`、不进结论表。
5. `cv ≈ 0.40/snr` 是**本标定条件**（1% 相对噪声、单峰 ZARC 背景）下的经验
   关系，不是普适常数；换了噪声口径要重测。
